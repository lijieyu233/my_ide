# 状态栏选中字符数

状态栏在光标位置后显示“选中 N 个字符”。空选区隐藏计数；切换文件、模式、关闭最后一个标签或进入独立工具页面时清除旧计数，返回文件后按实际选区恢复。

计数来自当前编辑器模型，支持代码编辑器、Markdown 实时预览/源码、分屏 textarea 和只读预览。CodeMirror 的文档或选区更新同时通知 Viewer；textarea 监听原生 select 事件；预览监听原生 DOM selectionchange。陈旧编辑器状态和非当前 textarea 不能更新当前状态栏。

按 Unicode 码点计数，不把普通 emoji 的 UTF-16 代理对算成两个字符，不创建逐字符数组，也不重新读盘。空格和换行计入；编辑模式统计选择的源文本，多个选区合计，Markdown 标记、表格转义及 br 编码都按源码范围计数。只读预览按选择的显示文本计数。组合 emoji 和组合附加符可包含多个码点，本功能不做字素簇或词数统计。

验证入口：

- 完整 DOM 测试补充中文/emoji/空格/换行、反向及多个选区、清除、切页/切文件恢复用例。
- `scripts/check-selection-count.js` 使用隔离配置的隐藏生产窗口，覆盖代码、Markdown、textarea、预览和页面切换，共 3 组通过；已查看深红主题截图，状态栏没有新增固定占位。
- 语法检查及既有 Markdown 快捷键测试通过。通用 UI 和全量 npm 检查中的已有 Git/排版失败不报告为通过。
