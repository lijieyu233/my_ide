# 保存结果与编辑版本保全（EDIT-01 第一包）

> 2026-10-01；实施前基线 `4f095ce`。依据 090-A，先处理编辑器内存保全与项目离开闸门。

## 本包合同

1. 标签用稳定 id 和 editRevision/savedRevision 标识内容版本，textarea、代码 CM6、Markdown CM6 共用编辑计数；缩进/替换也触发编辑事件，外部重载不计为用户编辑。
2. 保存固定标签对象、路径、正文、编码和 revision。同路径保存串行；成功回调不回写旧正文，只在当前 revision 与快照一致时清 dirty。失败、拒绝 Promise、非法返回值统一成可等待的结果。
3. saveAllDirty 固定本次标签集合，汇总 saved/failed/stillDirty。项目切换、移除当前项目必须先验证结果，再关闭标签或修改项目列表；保存期间继续输入会阻止离开，用户可 Ctrl+S 重试。
4. 项目切换与移除串行，关闭确认绑定标签对象，避免索引变化关闭其他标签。已关闭或路径已变化的排队写入不派发；在途回调不清除其他标签或新路径的 dirty。
5. 外部重载读盘后再次检查标签、路径和编辑 revision，避免等待期间的新输入被覆盖。

## 验证计划

后台 npm test 保留原套件；新增完整 Viewer/App 的受控延迟写入测试，断言正文、dirty、磁盘、项目 root 与标签保留，包括返回失败/Promise 拒绝、部分成功、同文件串行、关闭确认索引漂移、切换/移除失败、连续切换、迟到外部读取。

真实隐藏 Electron 使用独立 userData、home（设置镜像）和临时项目；真实 IPC 写入目录造成失败，验证失败后项目不变及改正路径后可保存/切换，另验证在途新输入。新增 UI 提示沿用现有 toast，运行 --check-ui 并检查截图。`npm run check:save` 的 Node 父进程在 Electron 退出后回收临时 profile/项目，报告/截图留在 `.ui-check-trash` 供本轮看图后清理。

## 明确后续边界

本包不宣称完整关闭 EDIT-01：主进程磁盘版本/原子替换/格式保护属于 FS-01；树操作已发出的 rename 与在途 IPC 写入需要 TREE-C 的路径协调协议。应用退出草稿和另存/冲突比较界面也属后续交付。已派发写入不能由渲染队列撤销，本包只保证迟到结果不误报新路径已保存。
