# 开发文档 030 —— 状态栏分支点击 + 快速打开最近文件

> 状态：已完成 · 体验打磨

## 一、需求

- 状态栏分支只是文本——点击应能切换分支（PyCharm 右下角习惯）
- 快速打开（Ctrl+P）无输入时显示最近打开的文件（高频回看）

## 二、设计

### 状态栏分支可点击
- `#sb-branch` 独立元素（可点击样式）→ 点击打开分支切换弹窗（复用 openBranchDialog）
- updateStatusbar 拆分：分支 → #sb-branch；文件/行数/编码 → #sb-info

### 快速打开最近文件
- viewer.openFile 记录 `myide-recent`（path + ts，去重限 10）
- quickopen 无输入时渲染最近列表（点击打开）

### 结构
```
app.js        updateStatusbar 拆分
git-panel.js  导出 openBranchDialog
viewer.js     最近文件记录
quickopen.js  最近列表渲染
```

## 三、测试计划

1. 状态栏分支点击 → 分支弹窗打开
2. 打开文件后 → 快速打开无输入显示最近文件
3. 点击最近项 → 打开对应文件
