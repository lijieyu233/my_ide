# 后台源码模块目录整理

日期：2026-10-15。

## 目的与范围

后台功能逐渐拆分后，根目录积累了 59 个 JS/CJS 文件。将其中 57 个功能模块按职责移入 `src/main/`，根目录保留 `main.js` 与 `preload.js` 两个入口。此次只整理代码位置及引用，不改变业务行为、用户配置路径或 DSH 会话存储位置。

## 目录职责

| 目录 | 职责与代表模块 |
| --- | --- |
| `src/main/ai/` | AI 请求、工具执行、权限与审批；`ai-service.js`、`ai-tool-execution.js`、`ai-approval-ui.js` |
| `src/main/dsh/` | DSH 运行时发现、原生连接、消息协议及桥接插件；`ai-dsh.js`、`dsh-runtime.js`、`dsh-native-plugin.cjs` |
| `src/main/git/` | Git 状态、提交、差异、队列与 Worker；`git-service.js`、`git-native.js`、`git-worker.js` |
| `src/main/browser/` | 网页深色、右键、全屏、字幕及 HTML 预览 |
| `src/main/files/` | 文件保存、复制、恢复记录、编码、路径迁移与 Windows 原生文件操作 |
| `src/main/launch/` | 启动面板进程管理、就绪状态、退出协调与快速启动 |
| `src/main/remote/` | SSH、远程文件、本地传输和 IPC 注册 |
| `src/main/db/` | 数据库连接与查询 |
| `src/main/search/` | 文件内容搜索 |
| `src/main/tasks/` | 任务文档保存与恢复 |
| `src/main/app/` | 应用单实例与窗口显示协调 |

`renderer/` 继续存放界面与前后端共享工具契约；`scripts/` 存放开发和验证脚本；`tests/` 存放自动化测试。历史开发文档中的旧路径保留为当时记录，查当前代码请使用上表。

## 引用与打包约定

1. `package.json.main` 仍指向根目录 `main.js`，主窗口 preload 仍为根目录 `preload.js`。保留入口位置使界面资源、插件和项目启动方式沿用原路径。
2. 同目录模块使用相对引用；跨模块引用明确写到对应功能目录。前后端共享契约仍从 `renderer/ai-*-tools.js` 加载。
3. Git Worker、路径 Worker、审批页独立 preload 和 DSH 插件都已同步迁移。审批 HTML 仍在 `renderer/`，不能按审批后台模块所在目录查找。
4. `package.json.build.files` 使用 `src/main/**` 收录后台模块；发行包检查继续检查实际归档中的依赖、Worker、preload、插件与资源，不能只看配置清单。
5. 语法检查递归覆盖 `src/main/`，新增后台模块不再手工追加到另一份语法文件列表。
6. `npm run test:layout` 检查根目录入口、全部后台本地依赖和打包路径，已加入 `npm test`。现有测试、脚本中的直接导入、源码读取、子进程脚本和包内注入路径均同步更新。
