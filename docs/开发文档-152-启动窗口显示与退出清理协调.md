# 启动窗口显示与退出清理协调

用户反馈 MyIDE 无法打开。现场主进程仍存活、没有窗口，重复启动被单实例锁转交后退出。仅检查进程存在不足以确认启动成功。

## 修复

- 正常窗口 ready-to-show 后显式 show，处理 Windows 隐藏启动对初始 show:true 的影响。隐藏自检不注册显示回调；窗口已销毁也不显示。
- DSH.dispose 由现有退出协调器在服务确认后、允许关闭窗口前等待。移除 will-quit 中取消退出再异步调用 app.quit 的独立流程，避免在窗口销毁后另行阻止进程退出。
- 正常退出与用户明确保留服务并退出均等待 DSH 清理。清理失败保持窗口并释放退出闸门；重复关闭共享一次清理。

## 验证

- 单实例及首帧显示 6 项、退出协调 10 项、92 文件语法通过。
- 隔离真实 Electron 隐藏启动 11 项通过，已看截图；首帧处理未使隐藏自检显示。
- 隔离真实主程序加载页面后正常 close，窗口销毁、will-quit、主进程退出，未强制 app.exit。
- 用户实际窗口在隐藏启动一次后显示 My IDE；正常关闭主进程耗时 158 ms，再次启动成功。未结束 DSH 或后台业务服务。
- npm test 在 Git 测试处停止：61 通过、1 失败，worker 临时目录清理 EPERM，与前一轮相同；未计为全量通过。
