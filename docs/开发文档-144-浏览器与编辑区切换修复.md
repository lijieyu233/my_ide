# 浏览器与编辑区切换修复

HTML 标签的“内置浏览器”入口此前直接调用面板 show，App.activeTool 仍指向旧页。打开文件无法命中浏览器让位分支，关闭按钮甚至会执行“打开浏览器”的切换动作。

现在 open、toggle 统一经过 App 的页面切换；点击已有文件标签也隐藏浏览器原生视图。关闭浏览器恢复打开前的工具、侧栏及收起状态，跨项目恢复时清除旧来源。

验证：DOM 覆盖 HTML 按钮、已有标签、打开文件及项目/启动/远程来源恢复；隐藏 Electron 生产窗口验证原生 WebContentsView 确实摘除，文件正文可以显示。保留网页实例，再打开时维持页面会话。
