# 开发文档 050 —— UI 样式优化（启动页 / 外壳 / 图标 / 一致性）

> 状态：已完成 · 体验打磨

## 一、需求

用户提供实际界面截图，要求优化 UI 样式，确认做四块：

1. **启动页（空状态）**：46px emoji + 若干灰字直接铺在整片空白中间，没有容器、没有虚实层级，主操作还不是主题色
2. **工具栏与状态栏层级**：功能按钮与窗口控制同权重挨在一起；状态栏左右两端各有一个字号控件，分不清改的是哪个
3. **左侧工具条图标**：`▤ ☰ ⑂ ⌥ ⛁` 是字符符号、`🌐 ☑` 是 emoji，大小/粗细/基线都不一致
4. **全局细节**：圆角 3/4/6/10 混用；`--border: #101010` 在深色底上几乎看不见；焦点态各处不一

## 二、设计

### 1. 启动页（`#empty-state`）

| 项 | 旧 | 新 |
|---|---|---|
| 容器 | 无，元素直接铺在空白中 | `.empty-card`：`max-width:400px` + 细边框 + 10px 圆角 + 面板底色 |
| 图标 | 46px emoji `🛠` | `.empty-mark`：36px accent 淡底方块 + 内联 SVG（`<>` 代码符号），随主题变色 |
| 标题区 | 20px 标题 + 两行灰字 | 图标 + 标题/副标题两行（15px/11px），左对齐 |
| 快捷键 | 与正文同样亮的灰字 | `.kbd-chip`：`<kbd>` 等宽胶囊（下边框 2px 做「键帽」感），弱化到提示层 |
| 主操作 | `.tb-btn.big` 灰按钮 | `.empty-cta`：整宽 accent 实心 + 文件夹图标（整屏唯一主按钮） |
| 最近项目 | 一行居中 chips（14 个项目必然横向溢出，同名项目分不清） | 纵向列表：文件夹图标 + 项目名（亮）+ 父目录（暗、右对齐、超长省略），最多 6 行 + 「还有 N 个…」/「全部 N」→ 复用「全部项目」下拉 |

**顺带修掉一个真 bug**：首次启动（从未打开过任何项目）时没有人初始化空状态 → 内容区全空。空状态可见性由 `renderView` 统一维护，启动时补一次 `Viewer.renderActive()`。

### 2. 工具栏 / 状态栏

- 工具栏插入 `.tb-sep` 分组分隔线：`打开项目 ｜ 项目栏 ｜（弹性空白）｜ 功能按钮组 ｜ 窗口控制组`
- 功能按钮（搜索/主题/设置/帮助）改 `.tb-btn.tb-ic` 定宽定高 + SVG
- 状态栏：两个字号控件加区域标签 **侧栏 / 编辑**（并在左侧控件后加分隔线），位置不变
  （左侧 `#sb-tool-font` 必须贴最左、`#sb-bgop` 必须在 `#sb-font` 右侧 —— 既有测试锁定了这两条布局约束）

### 3. 图标统一

- 左侧 8 个工具按钮 + 右侧 2 个 + 工具栏 5 个，全部换成**内联 SVG**
- 统一规格：`svg.ic { width:16px; height:16px; fill:none; stroke:currentColor; stroke-width:1.4; stroke-linecap/linejoin:round }`
- 侧栏收起箭头不再切字符（`⏴/⏵`）：改为 `#tool-sidebar.collapsed svg { transform: rotate(180deg) }`，`app.js` 只切 class

### 4. 全局一致性

- 圆角：`border-radius: 3px` → `4px`（9 处）；面板/卡片用 8~10px
- **新增 `--border-pane`**（`color-mix(in srgb, var(--text) 16%, transparent)`）替换 5 处结构分界线
  （工具栏下、工具条右/左、侧栏右、状态栏上）—— 由 `--text` 派生，所以自定义配色主题也跟着走；
  旧 `--border:#101010` 在深色底上等于看不见
- 焦点态统一：`:focus-visible { outline: 2px solid var(--accent); outline-offset: -1px }`（键盘才出现，编辑器排除以免和 CM6 光标打架）

## 三、结构

```
renderer/index.html    工具栏分隔线 + 5 个按钮换 SVG；工具条 10 个按钮换 SVG；空状态卡片结构；状态栏标签
renderer/styles.css    svg.ic 统一规格 / .tb-sep / 启动页全套 / .sb-font-tag / --border-pane / :focus-visible / 圆角归一
renderer/app.js        renderEmptyRecent 改纵向列表；侧栏箭头改 class；启动时 renderActive() 显示启动页
scripts/check-ui-steps.js  emptyState / chrome 两组页内步骤
main.js                --check-ui 增加「启动页」「外壳」两步 + 截图
tests/dom.test.js      空状态最近项目选择器改 .empty-item（+ 断言每行有父目录）
```

## 四、测试

### jsdom（`npm test` → 217 项全绿）
- 空状态最近项目：纵向列表出现 + 每行含父目录
- 其余回归：项目栏滚动收口、滚轮语义、mermaid 全屏、字号控件位置约束等

### 真实 Chromium（`electron . --check-ui` → **77 项全绿 + 11 张截图**）
新增两组断言：

| 组 | 覆盖 |
|---|---|
| 启动页 | 空状态可见 + 卡片宽度 240~440、图标是 SVG、**无 emoji 残留**、主按钮非透明背景、kbd 胶囊 ≥2、列表 ≤6 行、每行有父目录、溢出有「还有 N 个」、列表行左边界一致（左对齐而非居中 chips） |
| 外壳 | 10 个工具按钮全是 SVG 且无 emoji、4 个工具栏功能按钮是 SVG、分隔线 ≥3、图标尺寸一致(16px)、状态栏带「侧栏/编辑」标签 + 分隔线、`#sb-tool-font` 仍最左、`:focus-visible` 规则存在、主分界线不再是近黑 |
