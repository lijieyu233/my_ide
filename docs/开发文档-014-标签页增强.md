# 开发文档 014 —— 标签页增强（中键关闭 / 关闭其他 / 关闭全部）

> 状态：已完成 · 对应 ROADMAP P2

## 一、需求

- 浏览器习惯：**鼠标中键关闭标签**（PyCharm 也支持）
- 标签右键菜单扩充：关闭其他 / 关闭全部

## 二、设计

- `auxclick` 事件（button === 1）→ closeTab（中键）
- 右键菜单（已有：复制路径 / 关闭）追加：
  - 关闭其他（保留当前）
  - 关闭全部
- dirty 标签走原有确认逻辑

### 结构
```
viewer.js   auxclick + ctxTabMenu 扩充
```

## 三、测试计划

1. 中键点击标签 → 关闭
2. 右键「关闭其他」→ 只剩当前标签
3. 右键「关闭全部」→ 标签清空
