# 快速启动模块：需求与交互设计

> 日期：2026-10-02。状态：**方案已完成，实施待做**。
> 用户明确要求本次只提需求，不实现。本文是后续开发依据，不代表产品里已经有这个模块。统一入口：[改进进度总览](./改进进度总览.md)。

## 1. 目标与入口

在 MyIDE 中集中放置常用应用、快捷方式、文件、文件夹和网页，用分组卡片快速打开，减少到桌面、开始菜单和文件管理器来回寻找。

参考用户提供的 Windows 开始菜单截图，保留「工作 / 浏览 / 工具」分组、大图标和清晰名称；视觉沿用 MyIDE 当前主题、字体与线性工具图标。截图里的软件只是示例，不推测安装路径，也不默认写进用户配置。

模块统一命名 **快速启动**。左侧工具栏增加九宫格 SVG 图标，悬停说明「快速启动：应用、文件夹与网页」。点击打开主区，再点收起；无项目打开时也可使用。原来的 **启动面板** 继续管理终端和脚本，两个入口不复用名称和配置。

打开快速启动保留编辑器标签与内容；返回编辑器恢复之前文档和阅读位置。打开项目树里的文件时，快速启动让出主区。外部应用的退出与停止由用户及系统管理。

## 2. 首版布局

| 区域 | 内容与行为 |
|---|---|
| 顶部标题 | 「快速启动」、入口总数、返回编辑器 |
| 操作栏 | 搜索框、添加入口、添加分组、管理；加载失败时提供重新加载 |
| 分组区 | 默认工作、浏览、工具三个空分组；分组标题、数量、卡片网格 |
| 卡片 | 系统应用/文件图标或类型 SVG、名称；悬停提示完整名称与目标 |
| 状态区 | 保存失败、打开失败及处理建议，不显示内部技术日志 |

宽屏分组横向排列并自然换行；窄屏分组纵向排列。卡片建议宽112～140px、高120～140px，按界面字号适配；名称最多显示两行，并提供完整提示。内容区独立滚动，搜索框保持可见。浅色、深色、自定义主题使用已有主题变量。

普通模式以图标和名称为主；点击「管理」才显示分组改名/排序/删除和卡片编辑/移动/删除，点击「完成管理」退出。管理模式中仍保持明确的打开区域，不把同一次点击同时解释成编辑和启动。

## 3. 入口类型

| 类型 | 用户选择/填写 | 打开结果 | 图标 |
|---|---|---|---|
| 应用 / 快捷方式 | 应用文件或 .lnk 的绝对路径 | 系统方式启动；快捷方式自身参数和工作目录由系统处理 | 优先系统图标 |
| 文件 | 本地文件的绝对路径 | 使用系统关联应用打开 | 系统文件图标 |
| 文件夹 | 本地目录的绝对路径 | 系统文件管理器打开 | 系统图标或文件夹 SVG |
| 网页 | 完整 HTTP(S) 地址 | 系统默认浏览器打开 | 网页 SVG |

网页首版固定在系统默认浏览器打开，仅接受 HTTP(S)，拒绝脚本、文件协议、系统自定义协议及含账号密码的地址。应用图标提取失败回落到类型图标，不影响使用；不自动访问网站取图。

首版不增加自由命令字符串类型。需要参数的应用可选择已有快捷方式；自定义参数与工作目录列为后续独立需求。

## 4. 添加与编辑

弹窗包含名称、类型、目标和分组；本地类型提供「选择目标」，网页显示完整地址提示。

1. 选择目标后提取建议名称，已输入的名称不覆盖。分组内添加预选当前分组，顶部添加预选第一个分组。
2. 名称必填，去除首尾空白，最多100字；分组名称最多60字。路径保留原大小写与完整内容，不通过名称反推路径。
3. 本地目标必须为绝对路径并校验文件/目录类型；不存在时提示修正，不显示保存成功。
4. 相同类型和目标已存在时提示所属分组并允许定位已有入口，首版不静默生成重复项。
5. 保存前显示目标摘要，确认实际落盘后关闭弹窗并更新卡片；保存失败保留全部草稿。取消不改配置。
6. 保存期间禁用输入和重复提交，避免保存值与用户最后看到的值不同。
7. 编辑保留稳定标识，可改名称、目标和分组；目标变更后重新获取图标。

## 5. 分组、移动与排序

- 可添加、改名和调整分组顺序，新分组追加末尾；同名分组提示修改。
- 非空分组删除前要求先迁移或删除入口，至少保留一个分组；删除只影响配置。
- 卡片可拖到同组卡片前排序，也可拖入其他分组末尾或某卡片前。显示明确落点，无效落点不改配置。
- 编辑弹窗的分组选择支持跨组移动；「前移 / 后移」及分组排序按钮提供无需拖动的替代操作。
- 搜索状态禁用拖动排序并提示清空搜索，避免只看部分结果时误改整体顺序。
- 排序保存失败恢复原顺序并提示原因；重启和项目切换保持已保存顺序。

## 6. 搜索与键盘

搜索名称、目标路径和网页地址，忽略大小写；不扫描磁盘或搜索未添加的软件。过滤后保留原分组及顺序，隐藏无命中分组，显示结果数量。

| 操作 | 预期行为 |
|---|---|
| 输入搜索 | 即时过滤，中文输入法组合期间不触发打开 |
| 搜索框 Enter | 打开首个结果；无结果无动作 |
| 搜索框 Escape | 清空搜索并恢复完整列表 |
| Tab / Shift+Tab | 按视觉顺序遍历搜索、操作栏、卡片和管理动作 |
| 卡片 Enter / Space | 打开聚焦入口 |
| 弹窗 Escape | 取消并恢复触发按钮焦点，保存进行中不提前关闭 |

搜索、排序和管理切换尽量保留当前入口焦点；入口删除后转到相邻入口或添加按钮。首版不注册系统全局快捷键，应用内快捷键后续在设置中统一设计。

## 7. 状态与异常

| 情况 | 用户看到什么 | 数据行为 |
|---|---|---|
| 首次打开 | 三个空分组与添加提示 | 不预置软件、不自动启动 |
| 搜索无结果 | 无匹配提示及清空搜索操作 | 配置不变 |
| 正在打开 | 当前卡片禁用，显示正在打开 | 同一入口在途请求去重 |
| 系统接受打开 | 「已交给系统打开」 | 不误报应用已就绪或持续运行 |
| 目标已移动/删除 | 路径、失败原因、编辑入口 | 不自动删除入口 |
| 无关联程序/无权限 | 系统原因，可重试或修改目标 | 不把失败算成功 |
| 加载失败 | 重新加载、配置位置及失败原因 | 禁用修改，不用空配置覆盖原件 |
| 保存失败 | 保留弹窗草稿；排序恢复原状态 | 原配置完整 |
| 另一窗口修改 | 提示版本变化，重新加载后编辑 | 不覆盖较新配置 |

删除入口需要确认，并说明「只删除入口，不删除目标文件或卸载应用」。不尝试判断所有第三方应用是否已经运行；一次系统请求完成后允许再次打开。

## 8. 配置与开发约束（待实施）

机器级配置与项目、终端启动配置分开，拟独立保存为 quick-launch.json。分组、条目使用稳定标识；配置保存名称、类型、目标、所属分组、顺序和格式版本。建议首版最多64个分组、1000个入口。

读写严格校验，保存比较读取版本并使用同盘临时文件替换。损坏原件不能自动清空；保存须确认真实落盘，持久化位置须在目标机器验证实际可写。

打开时再次检查已存入口与目标类型，不能将用户路径拼入 shell 命令。图标异步获取、缓存有界，旧请求不能覆盖新目标的图标。不自动启动条目，关闭 MyIDE 不结束外部应用。

## 10. 后续验收清单

1. 无项目可发现入口；主区互斥，返回编辑器不丢标签和阅读位置。
2. 中文名称、含空格路径、应用/快捷方式/文件/目录/网页打开符合类型，图标失败有回落。
3. 创建/改名/排序分组，拖动与键盘移动卡片；重启后名称、目标、分组和顺序一致。
4. 中文与地址搜索、空结果、Enter/Escape/Tab及输入法组合输入符合约定。
5. 删除不删真实文件，取消不保存，重复目标与分组有提示。
6. 路径丢失、权限、无关联程序、磁盘写失败、配置损坏及外部修改均可解释和恢复。
7. 多主题与窄窗口无溢出、遮挡、不可达按钮，真实截图检查后确认视觉验收。
8. 自动化测试使用独立配置和临时目录；系统打开成功路径使用可控适配器，真实分派仅在用户明确授权的目标上验证。
