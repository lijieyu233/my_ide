# 开发文档 025 —— Git 日志分支视图

> 状态：已完成 · 体验打磨

## 一、需求

当前日志只看 HEAD 历史（单分支）。多分支工作流需要看其他分支/全部分支（PyCharm Log 默认行为）。
目标：**提交历史区加分支下拉**——当前分支 / 各本地分支 / 所有分支（合并按时间排序）。

## 二、设计

### 后端
- `git-service.log(dir, depth, ref)`：ref 参数透传（默认 HEAD）
- `git-service.logAll(dir, depth)`：遍历所有本地分支 log → 按时间降序合并去重（oid）

### UI（git 面板提交历史区）
- 下拉：当前分支（默认）· 各分支 · 所有分支
- 切换 → 重新拉取该 ref 历史 → 重渲染分支图
- HEAD 徽标：当前分支视图显示；其他分支视图显示该分支名徽标

### 结构
```
git-service.js   log(ref) / logAll
git-panel.js     分支下拉 + reloadLog
```

## 三、测试计划

1. 下拉出现（含当前分支名）
2. 选「所有分支」→ 列表刷新（fake logAll 被调）
3. 选具体分支 → log 收到 ref 参数
4. 切回默认 → 恢复 HEAD 视图
