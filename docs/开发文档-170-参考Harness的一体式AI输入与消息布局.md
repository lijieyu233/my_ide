# 参考 Harness 的一体式 AI 输入与消息布局

按用户提供的 Harness 截图重整消息与输入区，保留 MyIDE 当前主题。

输入卡片使用 17px 圆角、弱背景与轻边框，文本区和底部动作作为同一整体。左下为添加图片和权限，右下为模型、推理与圆形发送按钮；窄栏优先保留图标与模型选择。模式与连接/重连收进可展开的设置入口，移除输入框外常驻的三行辅助提示，快捷操作通过 placeholder 与 title 保留。

图片添加按钮使用系统文件选择，沿用现有图片读取、4MB 限制与待发送状态；图片缩略图位于输入卡片内，可单独移除，发送仍沿用原消息协议。

权限入口从标题栏移动到输入卡片，浮层从按钮上方展开；显示每次确认、自动执行、只读或自定义权限，原权限确认与保存逻辑不变。权限不会因 UI 调整被自动提升。

用户消息减少强调色描边与额外内边距，使用更轻的圆角气泡。复制按钮统一线性 SVG，“复制并继续”在悬停或键盘聚焦时显示，避免每条短消息下面常驻操作文案。工具记录与原生回复顺序不变。
