# 开发文档 044 —— 体验与可用性修复（PyCharm 式打磨）

> 本轮集中修复用户反馈的 11 项 bug 与体验问题，并补完「大项目卡顿修复」的遗留项。

## 一、需求

1. 切换项目 / 关闭全部文件后界面无法操作，只剩「打开文件夹」可点。
2. 文件名过长会换行，上下行重叠。
3. 所有弹窗（子窗口）有透明部分，背景透出。
4. 图片查看器背后密密麻麻的透明格子令人不适。
5. 效仿 PyCharm：一键收起 / 展开目录结构树。
6. 效仿 PyCharm：文件树按 Git 状态显示不同颜色。
7. Git 体验完善（放弃修改 / 手动刷新 / 扫描提示 / worker 集成测试）。
8. Ctrl+1 快捷键无效（改为始终显示工具窗口）。
9. 单击文件不再复制路径，仅快捷键复制。
10. 左侧目录区宽度可调整（拖拽 + 持久化）。
11. Markdown 支持「预览下修改」（编辑态实时分屏预览）。

## 二、设计

- 空状态 `#empty-state` 是 `position:absolute; inset:0`，其祖先 `#content` 原先未定位，
  导致空状态覆盖整个视口、挡住工具栏与侧边栏。给 `#content` 加 `position: relative`，
  把覆盖范围约束在内容区。
- 弹窗统一走 `Modal.show`，但 box 直接挂到 mask 下、丢失 `#modal-box` 的面板样式。
  给每个 box 加 `.modal-panel` 类，集中提供不透明背景 / 边框 / 圆角 / 阴影。
- 图片查看器去掉 conic-gradient 透明格，改为纯色背景 + 图片描边。
- 目录树新增 `collapseAll` / `expandAll`，`#tree-head` 加两个按钮。
- Git 状态着色：`GitPanel.refresh()` 构建「绝对路径 → 状态」映射交给 `Tree.setGitStatus`，
  行渲染时按 modified/added/deleted 加色类。
- Git 新增 `discard`（git-service + IPC + preload），放弃修改 = 已跟踪从 HEAD 恢复原始字节、
  未跟踪从磁盘删除。
- 快捷键 `Ctrl+1/2/3` 改用 `App.showTool`（始终显示，不再因已激活而收起）。
- 树单击与快速打开 pick 去掉自动复制；保留 Ctrl+Shift+C / 悬停「复制路径」等显式入口。
- 侧边栏加 `#sidebar-resizer` 拖拽手柄，宽度写入 localStorage。
- Markdown 编辑态渲染 `.md-split`（左编辑 + 右实时预览，200ms 防抖），提供分屏 / 单栏切换。
- 补完大项目卡顿遗留：`App.gitRefreshDelay`（默认 800ms）+ `tb-git`「⏳ 扫描中…」提示 +
  worker 集成测试。

## 三、测试

- `tests/dom.test.js`：新增 Bug1~Bug11 回归断言；修正单击复制断言与工具窗口切换语义；
  `App.gitRefreshDelay = 0`；修复「Git 刷新防抖」测试污染 `GitPanel.refresh` 的问题。
- `tests/git.test.js`：新增 `discard`（恢复 HEAD / 删除未跟踪）与 worker 调度链路测试。

## 四、验收

- `npm test` 全绿：语法 17 + git 28 + DOM 79 = 124 项。
- 空状态不再挡住侧栏 / 工具栏；文件名单行省略；弹窗不透明；图片无格子；
  目录树可一键收起展开并着色 Git 状态；Ctrl+1 稳定显示项目面板；单击不复制；
  侧栏可拖拽调宽；Markdown 编辑态实时预览。
