# 开发文档 024 —— 查看增强（PDF 预览 + Diff Hunk 导航）

> 状态：已完成 · 体验打磨

## 一、需求

- PDF 文件目前显示"二进制文件"——用 Chromium 内置 PDF 查看器直接预览（零依赖）
- 大 diff 多 hunk 时翻找困难——加「上一个/下一个 hunk」导航按钮

## 二、设计

### PDF 预览
- 内置渲染器：`['pdf']` → `<iframe src="file:///路径">`（Chromium 内置 PDF viewer）
- viewer 对 `.pdf` 跳过二进制读取（与图片同路径）
- CSP `frame-src` 增加 `file:`

### Diff Hunk 导航
- diff 头部（整页 diff + 提交详情双栏）加 `⤒ 上一个 / ⤓ 下一个` 按钮
- 点击滚动到相邻 `.diff-hunk-gap`（循环），按钮显示当前 hunk 序号

### 结构
```
plugin-loader.js   pdf 渲染器
viewer.js          PDF_EXTS 跳过读取
index.html         CSP frame-src file:
git-panel.js       两处 diff-head 加导航
```

## 三、测试计划

1. 打开 .pdf → iframe src 为 file:// 路径
2. diff 头部有导航按钮，点击切换 hunk（循环）
