# 开发文档 002 —— 会话记忆（恢复标签页/工具窗口）

> 状态：已完成 · 对应 ROADMAP P0-3

## 一、需求

每天打开 My IDE 都要重新：打开文件夹 → 逐个点开昨天看的文件。浪费 5 次点击。
目标：**启动恢复上次的标签页、活动标签、左侧工具窗口**（根目录已有 lastFolder 记忆）。

## 二、设计

- 存储：`localStorage`（渲染进程私有状态，无需 IPC；key = `myide-session-v1`）
- 触发保存：viewer 的 `renderTabs()`（标签增删/切换都会经过它），**400ms 防抖**
- 保存内容：
  - `tabs`：所有非 dirty 标签的完整路径（dirty = 有未保存修改，不恢复，避免误覆盖）
  - `active`：活动标签路径（若 dirty 则不恢复激活）
  - `tool`：当前工具窗口（project/outline/git/null）
- 恢复时机：`App.setRoot()` 成功之后（保证根目录就绪），逐标签 `Viewer.openFile`
- 工具窗口恢复：App 新增 `setTool(name)`（非切换语义），供恢复使用

### 结构
```
renderer/session.js   Session.save()/restore()（防抖保存 + 启动恢复）
viewer.js             renderTabs() 内挂 Session.save()
app.js                getTool/setTool + setRoot 后 Session.restore()
```

## 三、测试计划

1. 打开 2 个标签 + 切工具窗口 → 保存后清空标签 → restore → 标签恢复且活动标签正确
2. dirty 标签不恢复
3. 无会话数据时 restore 无异常

## 四、验收

- [x] npm test 全绿
