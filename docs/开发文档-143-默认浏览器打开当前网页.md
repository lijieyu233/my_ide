# 默认浏览器打开当前网页

内置浏览器地址栏右侧增加“用默认浏览器打开”线性 SVG 按钮，全屏模式下也可使用。没有 HTTP/HTTPS 网页时禁用；点击后保留内置浏览器当前页面。

主进程从真实 WebContentsView 获取当前 URL，不接受渲染层传入地址，因此正在编辑的地址栏草稿以及尚未同步的重定向前地址不会被误打开。使用 Electron `shell.openExternal` 交给系统默认浏览器，并等待调用结果；失败返回原错误，界面给出提示。打开期间防止重复派发。

验证包含未打开网页、实际导航后启用、草稿不影响目标、HTTP 重定向后打开最终地址及系统打开失败反馈。隐藏生产窗口测试通过真实按钮和 IPC，只替换系统打开适配器，不实际启动用户的外部浏览器或访问用户业务服务器；已查看暗红主题工具栏截图。

语法检查 85 个文件通过；DOM 521 项通过；`check:browser` 4 组真实窗口测试通过。全量测试仍出现既有 Git worker EPERM，不能算全部通过。
