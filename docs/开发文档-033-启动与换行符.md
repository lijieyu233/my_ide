# 开发文档 033 —— 启动不等待 Git + 换行符显示

> 状态：已完成 · 性能/体验

## 一、需求

- 打开大仓库时 setRoot 等 Git 全量扫描完成才显示树——首屏慢。改为**后台刷新，树先显示**
- 编辑文件时不知道换行符类型（CRLF/LF 混用隐患）——状态栏显示

## 二、设计

### 启动不等待
- `setRoot` 中 `await GitPanel.refresh()` → fire-and-forget（Git 状态就绪后自会更新状态栏/面板）
- 文件树/会话恢复不再被 Git 扫描阻塞

### 换行符显示
- loadTab 检测 `\\r\\n` → tab.eol；状态栏追加显示（仅 CRLF 时显示，LF 不显示——默认）

### 结构
```
app.js      setRoot 非阻塞
viewer.js   eol 检测 + 状态栏
```

## 三、测试计划

1. setRoot 立即返回（不等待）——树先渲染
2. CRLF 文件状态栏显示 CRLF
3. LF 文件不显示
