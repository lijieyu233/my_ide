## 1. 已有能力与本轮目标

当前已有 Ctrl+Alt+T 入口、编辑器/输入框/页面选区取文、无选区空框手填、选区预填自动翻译、Ctrl+Enter 手动翻译、原文编辑、复制译文、关闭弹窗，以及设置中的服务地址/模型/目标语言和连接测试。070的居中、可手填和空选区打开已落地，不能再列为待新增功能。

本轮目标：用户看得出译文对应哪一版原文和哪种语言；长段落可以对照阅读；关闭、重开、停止和重试不会串请求；失败不混进译文；临时换目标语言不用进设置。翻译仍是轻量工具，不发展成另一套AI聊天窗口。

## 4. 入口与布局

沿用快捷键入口，同时在后续105命令面板中登记「翻译选区 / 打开翻译」。阅读区有选区时可提供右键「翻译选区」，不再增加常驻主工具栏按钮。右键取的是打开菜单前的选区快照，不能等焦点丢失后重取。

弹窗头部只显示「翻译」和可聚焦的关闭按钮，图标使用现有SVG规范。服务入口为次级操作，不在头部显示Key。

| 区域 | 内容与行为 |
|---|---|
| 参数行 | 原文语言「自动」、本次目标语言、服务/模型摘要、配置入口；目标可临时切换 |
| 原文区 | 可编辑textarea、原文字数与来源「当前选区 / 手动输入」 |
| 译文区 | 可选择的纯文本、对应语言与版本摘要、独立空态/加载态/失败态/过期态 |
| 操作区 | 主动作翻译/重新翻译，进行中为停止；成功有效时可复制译文；关闭始终清晰可见 |

宽窗口建议约760～880px，原文与译文并排；窄窗口上下排列。最大宽度92vw、最大高度85vh，正文区域可独立滚动，操作区不被长文本挤出。原文和译文使用相同字号与行高，跟随已有界面字号设置。长词和URL合理换行，不让窗口横向溢出。

「自动」表示模型按原文处理，不能假装已有可信的源语言检测结果。目标语言提供中文、英文等常用选项并允许保留已有自定义名称；不能迁移时丢掉用户当前的自定义语言。更改本次目标立即更新显示，**不自动发送或改全局默认值**；默认值在设置中明确保存。

未配置服务时仍允许打开和编辑原文，提示「配置翻译服务」，发送不可用。去设置再返回应保留原文和本次目标，而不是丢失选区让用户重新复制。

## 5. 请求、原文与结果的交互合同

每次发送保存不可变快照：弹窗身份、请求身份、原文正文、目标语言、服务/模型身份与对应原文版本。响应只能影响仍存活且仍拥有该请求的弹窗；不能用共享busy表示所有历史弹窗的状态。

| 状态 | 译文区 | 翻译动作 | 复制动作 |
|---|---|---|---|
| 空原文 | 提示输入或粘贴 | 不可发送 | 不可用 |
| 有原文未翻译 | 译文占位 | 翻译 | 不可用 |
| 请求中 | 状态与发送快照摘要；先前结果可保留但注明上次 | 停止，重复发送去重 | 不将未完成/上次结果当当前译文复制 |
| 成功且快照匹配 | 正文及目标语言 | 重新翻译 | 可用，复制当前正文 |
| 原文/语言/服务已变 | 保留结果并标记「原文或设置已修改，请重新翻译」 | 翻译当前草稿 | 当前译文复制不可用 |
| 失败/空响应 | 独立错误提示，原文完整保留 | 重试 | 错误信息不可作为译文复制 |
| 已停止/超时 | 明确状态，草稿和上次成功结果仍在 | 重试 | 仍按结果版本决定是否可用 |

允许请求中继续改原文，但只更新草稿。原请求成功后若正文或参数不匹配，结果显示为上次快照的译文并注明过期；不覆盖原文，不假装翻译了后来输入的内容。停止旧请求后才允许新请求；旧完成事件不得解除新请求的忙状态。

空白只用于判断是否能发送；格式有意义的换行和缩进不能为了检测空输入被静默删除。输出为纯文本，不执行HTML或把模型正文当成操作指令。

停止和关闭需取消当前翻译请求，超时建议60秒并沿统一服务配置调整。不能调用AI聊天的全局abort来停止翻译，否则可能中断旁边的AI任务。即使服务端没有确认取消，也要阻止该旧响应改变新弹窗；界面不得承诺服务商一定停止生成或退回费用。换服务/模型后不自动重试，尤其不自动把原文发给另一家服务。

## 6. 复制、键盘与弹窗归属

复制成功后再显示「已复制」；剪贴板失败给出可重试提示，正文保持可选择。错误详情若需要复制，使用单独的「复制错误详情」，不复用「复制译文」。

Ctrl+Enter发送；输入法组合期间忽略。Enter保持textarea换行。请求中同一快捷键不产生第二次请求。Escape关闭当前翻译弹窗；关闭按钮必须是正常可聚焦控件。Tab顺序为参数、原文、有效结果操作和关闭，不陷入失效面板。

打开前记录触发控件/编辑器身份与选区，关闭恢复仍存在的原控件及阅读位置。若文档已关闭或控件被移除，转到当前编辑器或工具入口。弹窗栈中非顶层翻译被移除也必须移除对应栈项，关闭一个面板不误关上层设置，不留下遮罩。

用户主动快捷翻译选区时保留现有自动发送行为；无选区打开只聚焦空框，不自动读剪贴板、不自动翻译整个文件。为避免误发，改变参数和普通输入都不自动触发网络。

## 7. 失败信息与设置

提示区区分未配置、网络失败、超时、401/403认证、429限流、响应异常和空响应。提供当前适用的「配置服务 / 重试 / 复制错误详情」，保留草稿。重试使用当前显示的原文与参数；不默认循环重试，不把429错误正文当译文。

显示服务主机与模型，让用户知道这次发往哪儿；服务URL可能包含凭据，展示及诊断均须脱敏。只发送明确的原文快照，不附加整个文件、项目路径、AI会话或剪贴板历史。API Key显示、秘密迁移和设置保存确认继续沿098/116的既有需求，不因这轮弹窗设计声称已解决。
