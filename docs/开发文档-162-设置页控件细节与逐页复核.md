# 设置页控件细节与逐页复核

## 发现的问题

逐页截取快捷键、Markdown、外观、编辑器、Git、翻译、AI 助手、主题、本地设置的完整滚动内容，并检查 AI 的 Harness 配置分支。

- `.set-form input` 的 `width: 100%` 和底部间距应用到了复选框，导致复选框脱离标题、文字被挤到右边。
- 通用输入框 padding 应用到了颜色选择器，26px 高的色块内部被压成细线；滑杆也使用了文本框的间距。
- 主题选择器及恢复默认后的回填使用固定深色预设，与当前主题实际颜色不符。
- AI 配置缺少分组，Git 路径与三个操作按钮挤在同一行，设置操作使用了不随主题变化的绿色按钮。

## 处理

文本输入、复选框、滑杆、颜色选择器使用各自的尺寸规则。复选框为 16px，与标题左对齐，说明放在标题下方；整个说明区域可点击切换。

设置内容使用统一的小节标题和分组：外观分为字号、背景、玩偶；Git 分为提交作者和原生后端；AI 分为运行方式、模型与服务、操作权限；本地设置分为存储状态和备份恢复。翻译表单使用同样的字段、按钮间距。

主题卡片展示实际配色预览，逐项颜色选择器恢复正常面积；色块从当前主题 CSS 颜色读取，单项或全部恢复默认后重新读取当前配色。设置按钮使用主题强调色，长说明、路径和按钮组可以换行。

保留原有配置 ID、保存与权限逻辑。检查安装、导入导出等按钮未在取证流程里操作用户配置。
