# Harness 完整原生工作区

> 历史界面方案，已按用户反馈移除。当前使用 MyIDE 右侧对话框连接原生 ACP，见文档 148；不再嵌入 Web 页面或占据主编辑区。

## 用户入口

左侧活动栏新增 DeepSeek Harness。AI 面板选择“DeepSeek Harness（完整）”或在该模式下点 AI 入口，打开主区中的官方原生 Harness 界面；原生界面拥有自己的输入框、会话、工作区、模型/推理选项、权限、Agent 预设、插件和工具活动展示。

工具条提供刷新、浏览器打开、桌面版、普通助手和收起。切文件/收起只摘掉原生视图，再打开复用同一个页面和后台进程，不再每条消息新建 ACP 会话，也不把历史重新拼成伪用户消息。MyIDE 退出时关闭它自己启动的 Web 进程；需要原生桌面端的后台生命周期时使用“桌面版”。

## 原生运行方式

调用本机安装提供的公共 CLI，等价于：

```text
dsh --profile web --no-open --host 127.0.0.1 --port 0
```

使用 Harness 默认 home（本机为 `~/.dsh`）、官方 `web` profile 和用户原生配置。没有 `--patch`，没有工具禁用列表，没有 MyIDE persona、模型/API Key、上下文容量、输出长度、轮数或执行时限覆盖。原生文件/Shell、Skills、插件、子代理、PTC 等能力由 Harness 的原生预设与安装配置决定，MyIDE 不再删减。实验性扩展按官方 Plugins 页面启用，不声称未安装插件自动存在。

Web 与 Desktop 是官方不同的 profile。共享 Harness 支持的数据与凭据；各 profile 的插件依赖和配置遵循官方隔离边界，不修改或复制 desktop 的依赖图。嵌入的是完整官方 Web 界面；“桌面版”直接启动已有 `DeepSeek Harness.exe`，保留桌面登录、桌面专属桥接与已有 desktop 插件。Web 的模型由其原生设置管理，MyIDE 原先模型设置仍仅用于普通助手。

旧受限 ACP 模式的实现、协议客户端与专项脚本已移除；文档 146 仅保留为历史，不能再当当前功能说明。

## 集成边界

原生页面使用独立持久 WebContentsView 分区、sandbox、context isolation，无 Node integration 或 MyIDE preload。启动 URL 的一次性令牌只在主进程处理，不显示在工具条、返回状态或日志中。页面跨源导航与外链交系统浏览器，原生同源弹窗保留。启动地址只能是本机 127.0.0.1 和系统分配的端口。

主界面浮层出现时摘掉视图，关闭时恢复，避免原生层盖住 MyIDE 设置/确认框。尺寸按窗口缩放换算；切文件和标签恢复编辑区。Harness 作为独立页面，不自动把后台编辑器内容、选区或项目规则注入模型；工作区与文件上下文由原生 Harness 明确管理。普通助手的访问权限不替代 Harness 的原生权限。
