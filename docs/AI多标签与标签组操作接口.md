# AI 多标签与标签组操作接口

2026-10-16。接入上一批的浏览器多标签、自动恢复与手动标签组，沿用主进程权限、执行账本和 DSH / 普通助手共用的工具定义。

## 已完成接口

| 状态 | 工具 | 参数与行为 |
| --- | --- | --- |
| [x] | `browser_tabs` | 只读取得当前项目标签、活动 ID、关闭列表、标签组及管理快照 |
| [x] | `browser_tab_open` | `snapshot`、可选 `url`；新建网页或空白标签，不覆盖原页 |
| [x] | `browser_tab_select` | `snapshot`、`tab_id`；切到已有标签并显示浏览器 |
| [x] | `browser_tab_close` | `snapshot`、`tab_id`、可选 `mode=current/others/right`；按指定范围关闭 |
| [x] | `browser_tab_reopen` | `snapshot`；恢复最近关闭标签的网址与位置 |
| [x] | `browser_tab_move` | `snapshot`、`tab_id`、从 0 开始的 `index`；只调整顺序 |
| [x] | `browser_tab_group_save` | `snapshot`、`name`；另存当前非空白网页及顺序，不覆盖同名组 |
| [x] | `browser_tab_group_open` | `snapshot`、`group_id`；追加打开并按网址去重 |
| [x] | `browser_tab_group_rename` | `snapshot`、`group_id`、`name`；保留组内网址与顺序 |
| [x] | `browser_tab_group_delete` | `snapshot`、`group_id`；仅删除保存的组，已打开网页保留 |

原浏览器工具 13 个，本批增加 10 个，共 23 个。既有 `browser_open/read/click/fill` 等仍作用于活动网页；切换标签后必须重新读取网页，不能复用另一标签的元素快照。

## 使用顺序

1. `browser_tabs` 读取真实 ID 与 `snapshot`。
2. 使用该快照执行一个具体操作；修改操作沿用执行权限，关闭标签和删除组要求本次明确确认。
3. 页面导航受理后，用 `browser_state` 等待加载，再读取网页核对；继续管理标签前重新 `browser_tabs`，因为标题和网址可能已随导航更新。

确认面板展示涉及的标签、关闭范围、标签组及名称；关闭明确提示未提交表单可能丢失。恢复只保证网址和布局，不保证表单或脚本内存。

## 边界与错误

- 标签 ID 不可猜测；快照绑定项目、活动项、标签顺序、关闭列表与标签组内容。用户切换项目后再切回来，也会使旧快照失效。
- 主进程校验参数与审批，渲染端在真正执行前同步核对快照，没有“检查完成后再异步修改目标”的窗口。
- 未获批准、权限被撤销、运行被取消时不执行。相同调用 ID 沿用首次结果；首次未批准的失败也会记录，获批准后应使用新的调用 ID。
- 只打开 HTTP/HTTPS 页面；含账号密码的 URL、本地页面与不支持协议不经标签或标签组绕过。列表隐藏此类地址及标题，显示 `supported=false`。
- 列表最多返回 100 个标签、100 个组，并返回真实总数与截断标记。截断时不允许批量关闭、整组保存或排序，避免把未完整列出的目标当成全量。
- `BROWSER_TABS_CHANGED`：项目、标签或组已变化；重新读取后按用户意图操作。
- `BROWSER_TAB_NOT_FOUND` / `BROWSER_GROUP_NOT_FOUND`：ID 不属于本次读取结果或已不存在。
- `BROWSER_TAB_UNSUPPORTED`：不支持的地址，不执行打开或保存整组。
- `BROWSER_SAVE_FAILED`：如实报告本地保存失败；内存操作已发生时保留 `committed=true`，不假报全部失败或成功。
- 面板超过 5 秒未响应返回 `BROWSER_TIMEOUT`；修改操作报告结果未确认，不自动再次派发。模型工具回包保留结构化错误码和提交状态。
