## 4. 浏览、检索与范围

保留「项目」面板和当前排序/隐藏/Git视图。搜索框允许文件名与相对路径，空查询回到普通树。优先匹配完整文件名、文件名前缀、相对路径命中；模糊匹配为可选模式，不能把每次输入变成另一套不透明排序。

首版继续使用当前平铺结果，名称与相对路径同时显示；同名文件不能仅靠hover辨识。目录链保留的树内过滤列为后续模式，切换模式不改用户原展开集合。文件夹结果若加入检索，要区分「定位目录」与「打开文件」，不把目录交给文本Viewer。

| 状态 | 用户看到什么 |
|---|---|
| 查询中 | 查询词与范围、正在检索；原结果若保留，明确为上一查询且不可误打开 |
| 完整结果 | 匹配数量，按统一模型排序；可清空搜索 |
| 达上限/扫描未完成 | “当前显示200项，结果未完整”，继续加载或缩小范围 |
| 无结果 | 无匹配，可清空关键词或调整范围 |
| 读取失败 | 原因、重试；不能假装空目录或没有匹配 |
| 部分目录失败 | 已知结果继续可用，标记部分范围不可读取及查看详情 |

查询绑定项目、词、范围版本、请求身份。输入变化、取消、切项目、范围变化后旧响应不得写入缓存、画面、选择或忙状态。完整索引可以复用，但更新必须对应正确项目与扫描版本；退出搜索后先关闭请求接收，再恢复原树位置。

隐藏范围明确区分：应用内隐藏、系统点文件、Git跟踪过滤、默认不遍历的.git/node_modules。改视图不修改.gitignore，也不删除文件。搜索默认与当前可见规则一致；用户主动点“包含隐藏项”时显示范围提示，退出后恢复原设置。后端硬排除和截断要可解释，不能提示“项目全部文件”却偷偷漏范围。

Git清单未知时不能当空集合过滤整树，保留当前代码已有的“未知不等于空”保护；失败显示范围暂不可确认，不能把Git失败和无文件混在一起。完整清单状态由Git服务提供，不在文件树复制另一份状态扫描算法。

## 5. 定位当前文件与阅读关系

已有Tree.reveal和打开文档后的定位继续保留。新增可配置「跟随当前文件」，与手动「定位当前文件」区分；默认沿当前行为迁移，不突然关闭用户正在使用的定位。

定位应展开祖先、选择并滚动到实际节点；目标被过滤时说明“当前文件被过滤”，提供临时显示，不静默修改持久隐藏/Git设置。临时显示标记可见且可退出。目标在项目外说明不属于当前项目，提供系统显示或打开所属项目，不把近似路径当本项目节点。

用户正在多选整理时，普通编辑器激活不应清空整组选择；手动定位可明确转到目标。搜索未退出时定位行为必须明确：先询问/提供“返回树并定位”的动作，不用隐藏的主选中假装可见搜索行已定位。

展开/收起、排序、过滤和刷新保留仍有效的焦点与滚动锚点。节点已经消失则转到父目录或相邻节点。虚拟滚动需按数据索引定位再绘制目标，不能只在当前DOM中找节点后宣布定位完成。

## 6. 选择、键盘与可访问性

多选集合、主操作项、键盘焦点分别明确，所有菜单/键盘/拖动操作在开始时固定同一份路径快照。操作前显示“已选N项”；过滤隐藏其中部分时提示“包含M项当前不可见”，默认要求清除不可见选择或重新确认，不悄悄作用于用户看不到的对象。

| 操作 | 预期 |
|---|---|
| 普通点击 | 沿现有规则选择并打开文件/切目录，后续预览语义沿106 |
| Ctrl点击 | 只增减选择，不打开 |
| Shift点击 | 当前视图顺序的区间，虚拟节点也正确纳入 |
| ↑↓ / ←→ | 导航/展开/收起，焦点保持可见；Shift扩选采用同一模型 |
| Enter | 打开当前可见有效项；查询中或无结果不打开旧项 |
| Escape | 先结束当前搜索/拖动/编辑状态，不顺手清空其他面板 |
| F2 / Delete | 重命名或删除固定的选择快照，不能劫持输入框与组合输入 |

树提供tree/treeitem语义、展开/层级/选择状态与可达焦点；搜索平铺结果提供相应列表语义。读屏和真实OS焦点仍需专项验收，不只检查有role属性。排序菜单、范围菜单也要键盘可用。

## 7. 批量整理与操作反馈

创建/重命名/复制/移动/删除服务继续复用当前保全能力。界面预览不授予新的覆盖权限：目标版本变化仍须重新核对，路径变化与编辑缓冲沿112，复制/删除恢复来源沿115/122。

批量复制、移动和拖入先显示源项目、原选择、目标目录、去重后的实际项数、冲突与预计动作。父目录与其子项同时选中只形成一次实际操作，预览同时解释去重；不能显示选择数量却实际处理另一个集合。

冲突列表逐项选择跳过、使用新名称或明确覆盖；“应用到同类”只作用于本次明确列出的目标，不是全局永久覆盖。目录合并说明未选子项保持。移动到同目录、目录放入自身后代、目标权限不足和项目已切换都有明确结果，不只弹“操作失败”。

拖动悬停显示目标路径与复制/移动含义，无效目标不能给可放置高亮。外部拖入须验证实际Windows/Electron路径提取接口；不能把内存DataTransfer或旧file.path机制当真实系统拖放验收。

操作进行中显示阶段/已完成项数和可取消性。取消只能在服务支持的边界生效，已发布内容与未处理内容分别记录；不承诺“一键撤销所有动作”或把停止进度动画当停止磁盘写入。

完成后提供可回看的结果：成功、跳过、失败、待处理/可能已变更、恢复来源。部分失败不报全成功；失败项可在原路径/目标路径定位或重试，重试先核对外部变化。跨项目结果仍写明原项目，不把当前树刷新当原操作成功。

普通删除与系统回收站保持不同恢复文案；系统回收站不能显示应用Ctrl+Z可恢复。普通操作的恢复记录由当前服务提供，UI不另记一份“反向删除/反向移动”来冒充原字节恢复。

## 10. 验收矩阵

1. 保留C1/C2、懒加载/虚拟滚动、既有排序/隐藏/Git过滤及保全操作，不把UI整理当底层能力已回退。

3. 应用隐藏、点文件、Git未知/失败、默认排除、目录不可读和200/50000边界分别核对，空结果与不完整结果可区分。
4. 目标在树外、隐藏范围或虚拟窗口外时，定位可解释；多选、焦点与滚动恢复不作用于错误文件。
5. 批量父子选择、同目录、同名冲突、项目切换、确认期间外部变化、dirty输入、部分成功与重试均使用固定对象和真实服务回执。

7. 多主题、260/340/480侧栏、缩放与长中文/深路径截图检查名称和范围提示可读；真实读屏/OS焦点另验。
8. 10k/50k项目测输入、展开、索引、虚拟定位与全进程资源；按100测量合同报告冷/热和失败范围，不以9～10个夹具代替性能结果。
