# 开发文档 045 —— Git 完善与体验修复（第二轮）

> 本轮对照用户反馈，重点完善 Git 的 PyCharm 式体验，并修复文件树 / Markdown / 目录 / 性能等问题。

## 一、需求

1. 选中文件高亮错误。
2. Markdown 内链接不能跳转。
3. 目录操作会导致整个页面上移（工具栏被顶部遮住）；切换项目后目录展开结构丢失。
4. 目录中文件较多时明显卡顿 / 卡死。
5. 提交历史应可单独一个选项（PyCharm 的 Commit / Log 分页）。
6. 提交弹窗应只显示文件名，而非相对路径。
7. Git 整体与 PyCharm 差距大，需要重点调研并完善。

## 二、设计

- **选中高亮**：选中判定改为规范化路径比较（`\` → `/`），规避 Windows 大小写/分隔符差异；
  选中行的文件名强制白字，避免被 Git 状态色覆盖。
- **Markdown 链接**：外链（http/https/mailto）走 `shell.openExternal` 系统浏览器；
  相对路径按当前文件目录解析后 `Viewer.openFile` 打开；`#锚点` 页内滚动。
- **目录滚动**：给嵌套 flex 滚动容器（`#panel-*`、`#tree`、`#outline`、`#git-body`、`#viewer`）
  补 `min-height:0`，避免 flex 子项撑开导致 `scrollIntoView` 滚动到页面级容器。
- **目录展开持久化**：`Tree.getExpandedPaths/setExpandedPaths` + 会话按项目保存/恢复展开结构。
- **大目录性能**：`fs:readDir` 由同步 `readdirSync` 改为异步 `fs.promises.readdir`（线程池执行），
  排序由 `localeCompare` 改为字节序比较，避免主进程阻塞卡死。
- **Git 分页签**：`#git-body` 顶部加「本地修改 / 提交历史」两个页签，分别对应 PyCharm 的
  Local Changes 与 Log；两者始终渲染、用 `hidden` 切换可见性（兼容旧交互与测试）。
- **提交弹窗**：变更文件行只显示 basename，完整相对路径放入 `title` 悬浮提示。
- **新建分支**：`git-service.createBranch`（isomorphic-git `git.branch` + checkout），
  分支弹窗顶部加「新建分支」输入框，对应 PyCharm Branches → New Branch。

## 三、测试

- `tests/git.test.js`：新增 `createBranch` 集成测试。
- `tests/dom.test.js`：新增 Bug2 链接跳转、Bug3 目录展开持久化、Bug5 Git 分页签、
  Bug6 提交只显示文件名、Bug7 新建分支；「树定位」测试改为不依赖先前的展开状态。

## 四、验收

- `npm test` 全绿：语法 17 + git 29 + DOM 84 = 130 项。
- Git 面板与 PyCharm 一致：本地修改 / 提交历史分页、按目录分组、状态着色、放弃修改、
  新建/切换分支、提交弹窗只显示文件名。
