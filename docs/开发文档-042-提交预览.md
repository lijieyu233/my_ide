# 开发文档 042 —— 提交面板 Diff 预览

> 状态：已完成 · 体验打磨

## 一、需求

提交弹窗勾选文件时看不到改动内容——提交前无法快速确认。
目标：**点击变更文件行，弹窗底部预览该文件的工作区 diff**（复用 diff 表格 + hunk 折叠）。

## 二、实现

- 提交弹窗 body 加 `#commit-preview` 预览区（高 180px 滚动）
- 文件行点击 → diffWorkdir → buildDiffTable 渲染
- 默认预览第一个文件；勾选状态与预览互不影响

## 三、验收

- [x] npm test 全绿
- [x] 无新依赖
