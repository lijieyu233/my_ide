# AI 操作内置浏览器

> 长内容续读、字幕 JSON 自动解析、加载等待及浏览器轮次扩展已补齐，当前行为见 [文档 140](开发文档-140-浏览器长内容续读与字幕解析.md)。下文保留首版设计和验证记录。

## 功能

AI 助手可以操作 MyIDE 的单个内置网页视图，不依赖本地项目，不接管外部浏览器。

| 工具 | 行为 |
|---|---|
| browser_state | 查看真实地址、标题、加载状态、失败原因、导航能力和收藏 |
| browser_open | 打开完整 HTTP/HTTPS 地址，并显示浏览器页面 |
| browser_back / browser_forward / browser_reload / browser_stop | 后退、前进、刷新、停止加载 |
| browser_read | 按需读取正文与可操作元素，返回快照和元素 ID |
| browser_click / browser_fill | 点击已读取的元素、填写普通文本字段；填写不自动提交 |
| browser_scroll | 上下滚动一个视口，或到页面顶部/底部 |
| browser_favorite_add / browser_favorite_remove | 指定地址添加或删除收藏，可指定收藏文件夹 |

例如：“在内置浏览器打开这个地址，搜索安装说明，再把这个页面收藏到文档文件夹。”

当前页面信息包含浏览器地址和标题；位于浏览器页面时，继续排除本地项目文件上下文。

## 执行与结果

- 导航、点击、填写、滚动和收藏都走现有主进程应用工具授权。执行策略沿用 AI 执行权限；确认档显示本次地址、目标、填写文本及收藏信息，只批准本次调用。
- 只读状态与正文不申请副作用批准。网页和收藏中的文字仅是观察数据，不能代替用户指令。
- 点击和填写必须使用最新 `browser_read` 返回的快照、元素 ID。主进程绑定页面代次和视图身份；网页跳转、刷新、新读取、字段值/目标标签/可用性变化、元素替换后，旧操作被拒绝。
- 元素账本保存在独立 JavaScript world 999。网页自身拿不到该账本；AI 不能提供任意脚本或 CSS 选择器。
- 执行前重新核对运行、权限和页面；同一调用 ID 的重发沿用原结果，不重复产生副作用。
- 网页执行最多等待 5 秒。页面挂起时清除可操作快照；副作用超时报告结果未确认，不声称未执行，也不自动重试。
- 导航受理和点击派发不等于完成。AI 随后核对状态/正文；加载失败返回实际原因，不把错误页当成目标内容。
- 点击使用已批准的用户手势，真实导航历史可以前进后退。浏览器操作显示对应页面，并解除地址栏的延迟聚焦，保证导航后地址栏随真实地址更新。

## 边界

只支持 HTTP/HTTPS 导航，禁止地址内嵌账号密码。正文最多 20000 字符、元素最多 100 个；扫描也有预算，并返回截断标记。首版不分页读取超长正文，不读取 iframe 内部、Shadow DOM、密码、隐藏内容及输入框值，不提供上传、下拉选择或任意脚本执行。页面内原有登录状态仍由浏览器自身保持。

文本填写支持普通 input 与 textarea，使用原生 value setter 并派发 input/change；页面可能要求可信原生事件或特殊交互，此时应据实际结果反馈。网页异步事件监听器的行为无法仅凭元素描述证明，提交/删除/发送仍应符合用户明确要求。
