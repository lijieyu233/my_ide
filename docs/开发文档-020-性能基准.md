# 开发文档 020 —— 性能基准实测（对照开发大纲 §四）

## 一、需求

《开发大纲.md》性能基线目前是纸面目标：Git 状态扫描（1 万文件）< 1s。
需要**可复现的基准脚本**持续验证，防止性能回退。

## 二、设计

`scripts/bench.js`（npm run bench）：
- 构造测试仓库：多目录 + 5000 文件（写入计时不计入）
- 初始提交后修改 500 个文件（模拟真实工作区）
- 计时 `git-service.status()`（statusMatrix 全量扫描）
- 输出报告 + 对照基线（< 1s 通过 / 否则警告）

注：内存/启动速度需 GUI 实测（打包版用户验证时配合任务管理器观察）。
