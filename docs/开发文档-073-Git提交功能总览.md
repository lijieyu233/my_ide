# 开发文档-073 · Git 提交相关功能总览（现状清单）

> 用途：动手改/加 Git 功能前先看这份，避免重复实现、也避免踩"必须三处同改"的坑。
> 关联：`docs/开发文档-008-GitLog.md`、`042-提交预览.md`、`045-Git完善与体验修复.md`、
> `052-提交窗口对齐PyCharm.md`、`053-本机Git推送缺陷与修复.md`、`072-提交面板标题行与内嵌预览.md`；

## 0. 一张图：三层 + 一个约束

```
渲染层  renderer/git-panel.js（提交窗口）· git-log.js（历史窗口）· viewer/树/标签页右键
   ↓ IPC      preload.js  →  main.js（gitCall(...) + 各 git:* channel）
服务层      git-service.js（纯 Node，**isomorphic-git 1.41.4**，不是原生 git 命令行）
```

**约束**：新增任何 git 能力都要**同时改三处**（`git-service.js` 导出 → `main.js` 的 `ipcMain.handle('git:xxx')` →
`preload.js` 的 `window.myIDE.git.xxx`），并在 `tests/dom.test.js` 的 `myIDE.git` mock 里补一份，
否则自检/单测跑不起来。isomorphic-git **没有** `add -p` / `merge` / `rebase` / hooks / credential helper。

当前 IPC 通道（38 个，`grep -o "ipcMain.handle('git:[a-zA-Z]*'" main.js`）：

```
init status log logGraph commit diffWorkdir diffCommit compareRefs diffRefs commitFiles
branches checkout createBranch discard discardFiles getUserConfig setUserConfig
listRemotes addRemote removeRemote fetch pull push listPushCommits
shelveCreate shelveList shelveApply shelveDelete aheadBehind
listTags createTag revert cherryPick logFile blame
addToGitignore removeFromGitignore listIgnored
```

## 1. 入口与快捷键

| 快捷键 | 动作 |
|---|---|
| `Ctrl+K` / `Alt+I` | 打开提交窗口**并聚焦提交消息框** |
| `Alt+0` / `Ctrl+3` / `Ctrl+4` | 只打开提交工具窗口（不抢焦点） |
| `Ctrl+Shift+K` / `Alt+P` / `Ctrl+Alt+K` | 提交并推送 |
| `Alt+9` / `Ctrl+5` | Git 日志窗口 |
| `Shift+Esc` | 关闭日志窗口 |
| `Ctrl+R` | 刷新 Git 状态 |

其他入口：左侧工具条「提交」图标；状态栏分支名（点击 → 分支与标签弹窗）；
编辑器右键（Blame 注解 / 文件历史）；树与标签页右键（显示历史）。

## 2. 提交窗口（左侧工具窗口，独占侧栏）

### 2.1 标题行（30px，与标签栏等高）

`提交` · `分支名`（点击 → 分支与标签弹窗）· `↑N ↓M · K 处修改`（tooltip 带远程与是否已 fetch）· `拉取` `推送`。

- `↑↓` 数据来自 `aheadBehind`，**60 秒内不重复联网**，`拉取/推送` 会手动 force fetch。
- ⚠ 这一行的空间是算过的（约 313px / 可用 316px）：搁置、远程、日志、刷新都在下面的工具行里。
  加东西之前先读 `docs/开发文档-072`（标题被压成竖排就是这么来的）。

### 2.2 工具行（11 个纯图标按钮，文字进 tooltip）

`刷新` `回滚` `差异` `提交` `预览` ｜ `展开全部` `收起全部` `分组方式(按目录/平铺)` ｜ `搁置` `远程` `日志`

- **回滚**：放弃勾选文件的修改（未跟踪文件 = 删除），弹确认框并列出前 10 个文件。
- **差异**：把勾选文件的 diff 堆叠显示在主编辑区。
- **预览**：内嵌预览开关（默认关 = 点文件在编辑区看差异）。开着时框上写「面板内预览」，
  并带一枚「在编辑区打开」按钮。
- 未勾选任何文件时，回滚/差异/提交按钮是禁用态。

### 2.3 变更列表

分三节：**更改 N 个文件** / **未进行版本管理的文件 N 个文件** / **忽略的文件**（默认收起，展开才遍历工作区）。

| 能力 | 说明 |
|---|---|
| 状态徽章 | `新增 / 已修改 / 已删除` + 变体；`已暂存` 用实底、未暂存用描边（`matrixToStatus` 从 statusMatrix 推导） |
| 勾选 | **勾选集合是唯一权威**：取消勾选 = `resetIndex`（unstage）。`git add` 带 `force: true` |
| 三态复选框 | 分节标题、目录行、忽略节点都有：全选 / 半选 / 未选（`registerCheckNode` + `updateCheckUI`） |
| 目录树 ↔ 平铺 | 按目录（默认）/ 平铺（显示父目录列），偏好存 `myide-git-ui` |
| 展开 / 收起全部 | 走状态 + 重渲染（不是直接改 DOM），忽略节点会触发懒加载 |
| 悬停回滚 | 行内 `↺`：未跟踪=删除该文件，已跟踪=放弃修改 |
| 键盘导航 | `↑↓` 移动选中行，`Enter` 打开差异 |
| 忽略的文件 | 可勾选 → 强制加入提交；右键「不再忽略」把它从 `.gitignore` 移除 |
| 计数 | 底部 `N/M 个文件 · K 个已暂存` |

文件行右键菜单：`查看差异` / `打开文件` / `复制完整路径` / `显示历史` /
`添加到 .gitignore` / `不再忽略（从 .gitignore 移除）` / `搁置此更改（Shelve）`。

### 2.4 内嵌预览（可关）

工具栏「预览」开着时，选中文件的 unified diff 显示在列表下方的小框里（`@@` 行 + 逐行 `+/-`）。
框头有 `面板内预览` 标签、文件路径、`+增/-删` 统计、「在编辑区打开」、`✕`。

### 2.5 提交消息区

| 能力 | 说明 |
|---|---|
| 草稿 | **按项目**持久化，切项目自动换成该项目的草稿（用户改过就不再自动覆盖） |
| 消息历史 | 🕘 按钮 → 最近 20 条（`myide-commit-msgs`），点一条填进输入框 |
| Amend | 勾「修正上次提交 (Amend)」自动回填上次提交消息，取消勾选还原 |
| 提交 (I) | `Ctrl+Enter` / `Alt+I`；只提交**勾选**的文件 |
| 提交并推送 (P) | `Ctrl+Shift+K` / `Alt+P` |
| 提交并推送 ▾ | 下拉：其他远程 / 提交并强制推送（`--force`） |

## 3. 差异视图（主编辑区）

- 单文件：点文件行（预览关）→ 编辑区打开 `工作区 vs HEAD` 的 diff。
- 多文件：工具行「差异」→ 勾选的文件堆叠显示，头部 `+N/-M` 统计。
- hunk 导航：头部 `⤒`/`⤓` 跳到相邻 `@@`，循环，中间显示 `当前/总数`。
- 关闭：`✕` 或 `Esc`（`escCloseDiff`），`cancelDiff()` 防晚到的 diff 覆盖新画面。

## 4. 搁置（Shelve）

弹窗上下两段：**上**给当前更改起名 + 勾选文件 → 搁置；**下**是已搁置列表（恢复 / 删除）。
后端 `shelveCreate / shelveList / shelveApply / shelveDelete`：文件内容以 base64 存在
**`<repo>/.git/myide-shelves/`**（自实现，不依赖 git stash），搁置后会把工作区+暂存区回滚到 HEAD。
右键单个文件也能「搁置此更改」。

## 5. 分支与标签

弹窗「分支与标签」：分支列表（点击切换 `checkout`）、顶部新建分支（`createBranch`，建完即切）、
标签列表（点击检出到该标签 = detached HEAD）。切换后会刷新日志窗口。

## 6. 远程与凭证

- 弹窗：列出 `remote`（名 + URL）、新增、删除。
- 凭证**按主机**存 localStorage `myide-git-auth-map`：`{host: {username, password}}` ——
  多主机（GitHub / Gitea / 内网 GitLab）互不覆盖。
- 推送时优先用 map 里的凭证；`git-service.js` 另有代理/隧道与 `systemCredentialFill` 兜底。

## 7. 拉取 / 推送

- **拉取**：`fetch` + fast-forward 合并 origin。
- **推送**：先弹**推送预览**（待推送提交清单 `listPushCommits`），确认后才真正 push；
  支持指定其他远程与 `--force`（`pushRemote({remote, force})`）。
- 失败时给友好错误（`friendlyNetError`），并把实际远程与数据来源写在标题行 tooltip 里。

## 8. Git 日志窗口（`git-log.js`，`Alt+9`）

| 区域 | 内容 |
|---|---|
| 左：提交图 | gitk 式车道 SVG（`buildGraph` 状态机 + `buildGraphSvg`） |
| 左：列表 | 提交行（hash / 消息 / 作者 / 时间 / refs / tag），支持筛选 |
| 顶部 | refs 下拉：所有分支 / 当前分支 / 各分支（标签不在这里，标签在提交行的 ref 徽章与分支弹窗里）；`⇄` 进入分支对比模式 |
| 右：详情 | 提交头 + 变更文件列表 + 逐文件 diff（`diffCommit`） |
| 右键提交 | `还原此提交（Revert）` / `摘取此提交（Cherry-pick）` / `在此提交上新建标签` / `复制完整哈希` / `复制提交消息` |
| 分支对比 | 选两个 ref → `compareRefs` 出「只有 A / 只有 B / 两侧都有」，点文件看 `diffRefs` |
| 文件历史 | 树 / 标签页 / 文件行右键「显示历史」→ 过滤到该文件的提交（`logFile`），顶部 chip 可退出 |

## 9. 编辑器里的 Git

- **Blame 注解**：编辑器右键「Blame 注解」→ gutter 显示每行的 `hash 作者 时间`（`blame`），
  连续同提交只在首行标注；编辑文档后自动清空（行号会错位）。
- **文件历史**：编辑器右键 / 树右键 / 标签页右键 → 打开日志窗口并过滤到该文件。

## 10. 状态栏

`分支名`（点击 → 分支与标签弹窗）+ `N 处修改`。分支前缀用**内联 SVG**（不用 `⎇`：Windows 缺字形会 fallback）。

## 11. AI 助手集成

斜杠命令 **`/生成提交信息`**：把工作区改动（`status` + diff 摘要）作为上下文塞进对话，
并预填指令「按 `<类型>: <中文说明>` 格式写一条提交信息，类型用 feat/fix/docs/refactor/test/chore」，
只输出信息本身。

## 12. 明确还没做的（见 `docs/待办-提交窗口剩余项.md`）

Changelist（PyCharm 变更列表，体量最大）· hunk 级暂存/取消暂存（部分提交）·
合并冲突节点与解决 · 提交前检查（Before Commit）· Sign-off / 作者覆盖 · 若干小项。

> 这些没做的根因都在"用的是 isomorphic-git，没有原生 index 操作能力"——对象读写
> （`writeBlob/hashBlob/updateIndex/resetIndex/readBlob`）是有的，所以 hunk 暂存是**能做**的，
> 只是工作量在自研。
