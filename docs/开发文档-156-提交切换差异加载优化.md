# 提交切换差异加载优化

用户反馈日志列表中切换提交时，编辑区差异加载慢，提交消息浮层遮挡详情。浮层来自 .gl-msg 的原生 title，右侧详情本已显示完整消息，因此移除此处重复提示。

## 加载链路

- commitFiles 原先串行枚举父提交和当前提交的完整文件树。现在按 Git tree OID 递归比较，相同子树直接跳过；未改变的目录不遍历其中全部文件。保留第一父提交比较、首次提交、增改删和文件/目录转换语义。
- 文件清单按仓库绝对路径与完整提交 OID 缓存，32 条、单条不超过512 KiB；缓存结果每次独立反序列化。分支/HEAD 每次解析当前完整 OID，不会用旧引用命中缓存。
- 旧/新文件 blob 并行读取。渲染层缓存32条提交清单、最多16份差异，差异总预算8 MiB，单条上限4 MiB；切项目清除。
- 70 ms 合并快速连续提交选择，只派发最后一项；等待中的旧选择被唤醒后根据代次退出，避免堆积 Promise。
- 选择后立即显示所选提交与加载状态，不继续展示旧差异。文件列表错误、空提交和文件无差异在编辑区明确显示，不另弹只读提示。
- 提交代次之外，单文件差异使用独立请求代次，防止同一提交中先点文件 A 后点 B、A 较晚返回时覆盖 B。隐藏日志、切项目、进入分支比较或文件历史均使旧选择失效。

## 验证

- 文件树语义7组：首次提交、只变更子树、缓存对象隔离、删除、HEAD变化、文件/目录转换、合并第一父比较。
- 渲染选择5组：无重复标题提示、最后选择优先、同一提交文件竞态、缓存复用、隐藏后的旧响应不绘制。
- 实际仓库提交 767a29d 后台文件清单：修复前首次267 ms、再读225 ms；修复后首次27 ms、再读0–1 ms。仅表示该机器和该提交一次采样。
- 隐藏真实 Electron 窗口：该提交首次完整差异显示246 ms，缓存回切96 ms；包含IPC、70 ms选择合并与DOM绘制。已看深红主题截图，未触碰用户profile或项目文件。
- 94 文件语法、DOM 523 项通过。DOM 提交测试改为等待实际文件与差异完成，覆盖70 ms选择合并窗口；提交与后续HTML预览均通过。
- npm test 在 Git 测试处停止：56 通过、2 失败（worker临时目录清理EPERM、pull分叉策略）。通用隐藏 UI 460 通过、9 失败、3 跳过，含既有Git夹具日志/双区与Markdown颜色/流程图背景问题；未计为全量通过。实际仓库的独立真实日志走查通过。
