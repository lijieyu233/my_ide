# 覆盖粘贴与持久恢复记录

> 2026-10-01，基线9ec55a1；沿097-T-A可恢复覆盖/撤销合同实施。方案先写，专项与目录包验证后实施。

copyFile/cp直接覆盖，Tree把merge后的顶层目标也当作新副本删除，仍能复现097 F1/F9/F11。本包保留新目标复制、同名覆盖和目录合并；准备原字节恢复来源后才发布，按实际变更集合撤销，不删除未参与复制的keep。普通删除、跨卷移动和其他工具端继续按原合同分包。

## 合同

- 主进程接收项目、源集合、真实目的目录，后台准备一次逻辑操作。规范化/父子去重，拒绝链接别名、目标落入源后代、重复最终目标及文件/目录类型冲突。源与目标版本绑定到准备结果；确认覆盖后再次核对，不能把确认期间新出现的目标当成已批准对象。
- 独立userData/file-operations目录保存manifest、追加并fsync的逐项阶段日志、原字节备份及复制负载。文件含二进制/BOM/编码/行尾和NTFS数据流；备份/临时文件正文写入前设置来源/目标权限。新目录记录实际创建项，已有目录merge只改源中涉及的后代，原有keep及目录身份保留。
- 全部恢复来源准备成功后才修改目标。每文件同目录临时发布，目标缺席用排他发布；已有目标使用核对后原生替换，不直接截断、不降级copy+rm。单文件发布不是多文件天然原子；逐项记录准备/发布/完成，失败报告已完成、未执行与恢复来源，已完成部分可精确撤销。
- undo核对操作后对象/字节/元数据，后来修改或目标被重建时保留内容和记录。覆盖文件恢复备份，新文件只删除仍为本次版本的对象，新目录只删除已清空且仍为本次身份的目录。重复undo不重复破坏，失败先保留记录；重启核对阶段与原生发布对象身份，无法证明时标待核对并允许导出原副本，不猜测继续写。
- 复制/恢复协调打开文档的在途保存与读取；dirty正文始终保留。覆盖改变磁盘后dirty文档保留旧覆盖基线，提示比较/另存；干净文档只在仍属本次路径/输入代次时重读。等待期间新输入仍留标签。操作确认绑定原项目，迟到完成不打开到新项目。
- 恢复列表按项目展示操作/状态，可撤销已完成部分、导出恢复副本及明确确认后清理记录。进程内撤销栈丢弃不清理持久来源。起步预算最多10000项、恢复原字节总256MiB、50条记录；超限在修改前说明并保留来源，待重试/不确定操作不自动过期清理。保留期自动清理单独实施，不以7天静默删除唯一来源。

Windows核对与发布之间的外部最后窗口仍须如实说明，不能宣称全文件系统CAS。已有114的默认流/ADS共享边界同样适用；恢复来源与原生替换减小破坏范围，不替代后续完整特殊流并发合同。

## 实施证据

实现落在copy-journal/file-copy-win与路径worker，Tree/Viewer经专用IPC调用。manifest及每条事件带SHA-256校验，用于发现损坏；备份版本另核对身份、默认正文/全部ADS、属性及权限。正文复制前原生句柄绑定自己创建的暂存对象，允许自身复制写入但拒绝路径换名；缓存副本先保护原权限，发布后恢复目标原DACL/创建时间，来源正文/数据流与其他普通属性同源。覆盖文件撤销恢复原字节及原权限/时间，新副本不调用递归删除。旧fsCopy也接恢复服务，兼容入口的记录归属目标目录；文件树使用显式项目接口。

恢复入口在文件树右键「恢复文件操作」。已准备但用户取消、准备失败、部分发布及部分撤销记录都保留；仅明确清理后释放预算。日志尾部截断不猜测副作用，已知原副本可导出；清单/事件损坏只开放恢复目录人工核对。项目中的未知暂存项显示完整路径并阻止清理记录，不静默删除它或唯一恢复来源。导出中断报告部分副本所在目录。
