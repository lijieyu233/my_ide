# 开发文档 018 —— 文件树虚拟滚动

> 状态：已完成 · 对应 ROADMAP P1-10（最后一项）

## 一、需求

单个目录展开数百上千文件时，平铺渲染全部 DOM 节点会卡顿（滚动/展开）。
目标：**超过阈值（300 行）启用虚拟滚动**——只渲染可视窗口内的行，滚动即时更新。

## 二、设计

### 扁平行模型（重构渲染层）
- 放弃嵌套 `.tree-children` 结构，改为**扁平行列表**（缩进用 paddingLeft 表达）
- 展开状态：`expanded: Set<路径>`；目录懒加载缓存 `nodeCache: 路径 → items`
- `buildRows()`：从根 DFS，展开的目录递归进入，产出 `[{item, depth}]`

### 混合渲染
- 行数 ≤ 300：全量渲染（小树无感知差异，逻辑与现有一致）
- 行数 > 300：虚拟化——spacer 撑总高（行数 × 22px），绝对定位渲染可视窗口（±5 行缓冲），`onscroll` 重绘窗口

### 交互保持
- 点击/右键/复制/粘贴/中键等全部不变（行元素复用现有 makeRow 逻辑）
- 目录行点击 = 展开/收起（更新 expanded → 重建行列表）

### 结构
```
renderer/tree.js   重构渲染层（扁平 + 虚拟窗口）
```

## 三、测试计划

1. 现有树测试全部保持通过（渲染/点击/复制/右键/多项目）
2. 大目录（>300 文件）：只渲染可视窗口行数，spacer 高度 = 行数 × 22
3. 展开/收起大目录正常
