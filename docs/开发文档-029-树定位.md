# 开发文档 029 —— 树定位（打开文件自动展开并高亮）

> 状态：已完成 · 体验打磨

## 一、需求

从快速打开/搜索打开深层文件后，不知道它在树里什么位置。
目标：**打开文件后自动展开目录链 + 高亮该文件行**（PyCharm Scroll from Source）。

## 二、设计

- `Tree.reveal(filePath)`：
  - 路径归一化（分隔符无关）→ 逐层在已加载缓存中找目录 → 展开（懒加载）
  - 重建树 → 高亮目标行并滚动到可见
- `viewer.openFile` 末尾自动调用（树点击打开时无副作用：已展开/已选中）

### 结构
```
tree.js    reveal() + 导出
viewer.js  openFile 后调用
```

## 三、测试计划

1. 打开深层文件（src/app.js）→ 树中 src 自动展开 + 文件行出现
2. 树点击打开（已展开）无副作用
