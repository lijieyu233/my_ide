# 路径迁移与保存队列协调（097-T-B）

> 2026-10-01；产品基线659ecf9。实施前核对：目录改名只按字符串完全相等更新Viewer，移动/改名undo不发迁移，111的旧目标version阻止迁移后正常保存。

## 合同

- 路径按段与平台大小写规则映射；文件、目录后代、多标签、大小写改名、正向/undo使用同一迁移结果。保留文档id、正文、dirty、CM状态/光标，移动后只推进由原字节/对象证明的新磁盘版本，不重新读目标替旧dirty授权。
- 操作期间锁定相关源/目标范围；先等待已排队旧路径保存，后来Ctrl+S/自动保存不得派发旧路径写入。保存失败不暗中丢稿；源磁盘版本与相关文档基线不一致拒绝操作。加载/重新打开/外部读取迟到结果按路径代次失效。跨项目迟到操作不使用新root解释旧源。
- Windows采用已有原生无替换MoveFileExW，目的已存在不覆盖；move保留同名自动另取名，undo必须回到原完整路径且目标缺失，不自动另取名。重命名只接受单段名称。源/后代链接及不确定别名明确拒绝；跨卷不回落copy+rm。其它平台缺少已验证的目录排他移动能力时明确失败，不虚报跨平台支持。
- 源/目录内容版本、操作结果与相关文档新版本由主进程委派worker生成；目录递归摘要最多10000项/256MiB，按64KiB块读，不一次分配整个大文件。最多4个路径worker；主进程持有迁移范围锁，文本/二进制写入、创建、删除、复制入口在锁内拒绝。move自动另名时锁目标目录覆盖未知后缀。undo先peek，核对操作后版本，成功后推进记录；失败/目标冲突保留重试，不吐假成功。覆盖/merge与删除恢复journal按097-T-A/C另包。
- Viewer/会话（含已存状态）/最近文件/树选择与展开/AI上下文同源迁移；不因改目录名字丢失未保存正文。旧请求/AI工具参数不自动重写成新路径，防迁移后未经确认的执行。
- 完整DOM与真实临时文件/隐藏Electron覆盖等待保存→改名、目录后代/双项目/undo/冲突/失败保留、大小写/分隔符/路径边界/链接、迟到读；测试排后台，真实UI截图、打包加载及限定目录规模计时。

## 边界

文件系统摘要核对到原生移动仍有外部程序竞态窗口，不能宣称跨应用原子compare-and-swap。renderer等待与主进程范围锁用于协调既有fs入口的写入；Git后台工作、命令执行及独立配置写端仍可能改磁盘，需要后续统一操作合同。跨卷事务、目录覆盖/merge/删除恢复、任务/Git配置根重定位与AI请求隔离继续按原专项，不以本包关闭TREE-01/PROJECT-01。原生移动已成功但后续核对失败时仍同步真实新路径，清空授权基线并提示保存恢复，不谎报“源仍原位”。
