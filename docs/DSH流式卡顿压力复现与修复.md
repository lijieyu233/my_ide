# DSH 流式卡顿：压力复现与修复

2026-11-09。此前大历史切项目验收通过，不能代表持续输出也不阻塞。

## 可重复的负载

```sh
npm run check:ai-stream
node scripts/run-electron-check.js check-ai-stream-responsiveness.js --baseline
```

`--baseline` 从 Git 的 `95519c8` 读取旧版 AI renderer，测试窗口仅重定向这一份源码，不覆盖工作区文件。两个模式使用相同固定负载：

- 正文、思考各 64 KiB，每次 256 字节，共 512 条增量。
- 1500 条混合历史上，40 次各含 64 KiB 正文和思考的预览。
- 已有历史上，96 次含 32 KiB 工具输出的更新。

窗口始终隐藏；HOME、userData、剪贴板均隔离；HTTP/WS 禁止。模型和 DSH IPC 使用合成数据，没有连接真实模型、服务器或用户历史。

不把隐藏窗口的 RAF 当成 60Hz 帧率。分别记录真实 16ms 心跳、CodeMirror 修改事务、编辑调度间隔、IPC 消费延迟和最终 sentinel 的 DOM/layout 到达时间；各压力阶段阈值均为 250ms。

## 实测

不同运行会受机器负载影响；下表为一次旧版基线和最终顺序复验，不是对真实桌面所有场景的保证。

| 项目 | 旧版 | 修复后 |
|---|---:|---:|
| 连续正文/思考最大心跳间隔 | 15254.2ms | 120.3ms |
| 连续正文/思考最大 IPC 消费延迟 | 16735.6ms | 71.1ms |
| 连续正文/思考最后片段至 DOM/layout | 16009ms | 124ms |
| 大历史预览最大心跳间隔 | 6222.3ms | 21.1ms |
| 大历史预览最大 IPC 消费延迟 | 9185.7ms | 3.0ms |

另一次修复后复验：正文/思考心跳 123.9ms，预览 29.8ms。正文与思考的最终标记、原历史首尾、24 个工具完成态、后台隔离均有单独断言。

主进程的独立合成基准还发现：1500 工具历史叠加 120 对不可见 durable/status 事件，旧版折叠 121 次，0ms timer 实延约 1028ms；修复后只折叠一次，timer 实延约 9.36ms。该数据为 Node 合成基准，不是双真实 Electron 的端到端测量。

## 根因与改动

1. **累计全文反复处理**：每个小 chunk 都 Markdown 解析、代码自动识别、替换 DOM，再读取 scrollHeight 强制布局。长流改为 40ms 合并原文预览，段落结束恢复 Markdown；滚动测量最多每 16ms 合并一次。
2. **结束处理不幂等**：每个思考 chunk 都封口上一段回复，导致同一份 64 KiB 正文被反复做最终解析。封口和最终渲染现在按段落内容幂等，停止前的最后片段也会结算。
3. **预览反复拆建**：旁听每帧删除并重建思考和正文节点。现在更新原节点，保留内外折叠状态及最新复制内容。
4. **高亮预算无界**：只对明确且支持的语言高亮；单代码块 4000 字符、每次渲染总计 16000 字符预算。超过预算仍显示完整代码，不再自动猜语言。
5. **不可见事件重折全历史**：保留事件与游标，但仅可见变更触发历史重算。运行、队列、权限和时钟继续实时发布；旁听事件泵定量让出主线程。
6. **工具结果平方查找**：当前轮建立调用 ID 索引；同 ID 的最后调用及跨轮隔离语义不变。
7. **分片帧反复扫描**：follow/observe 都只扫描新片段，最终一帧合并一次。保留 follow 16MiB、observe 32MiB 单帧预算；合法多帧同一次 read 不因总量被误拒。

## 不改变的边界

- 不停止 DSH，不改变模型、权限、MCP 激活或排队/插入的消费顺序。
- 实时正文、思考原文和复制内容不因这次优化截断；摘要限制不影响展开详情。
- 旧工具历史自身的输出裁剪策略未在本次扩大或冒充恢复。
- 可见 durable 变更仍可能触发全历史折叠与 IPC；特别巨大单条 Markdown 的完成渲染仍在主线程，不能据这三项压力负载声称所有极端输入均无阻塞。
- 独立 AI、原生桥、切项目、权限、打包和完整 UI 验收仍应分别运行；不能以性能数字代替内容和权限断言。
