# 开发文档 013 —— Git 用户配置（设置页）

> 状态：已完成 · 对应 ROADMAP P2

## 一、需求

提交作者目前是兜底值 `me <me@localhost>`（未配置 user.name/email 时）。
目标：设置页新增「Git」分类，配置提交用户名/邮箱，写入仓库 `.git/config`，下次提交生效。

## 二、设计

### 后端
- `git-service.getUserConfig(dir)`：读 user.name / user.email（isomorphic-git getConfig）
- `git-service.setUserConfig(dir, {name, email})`：setConfig 写入仓库配置
- main IPC + preload 桥接

### 设置页（PyCharm Settings 多分类）
- 左侧分类：⌨️ 快捷键 / 🔀 Git（点击切换右侧内容）
- Git 视图：用户名 + 邮箱输入框 → 「保存」→ toast「下次提交生效」
- 打开时预填当前仓库配置；非 Git 仓库提示先初始化

### 结构
```
git-service.js   getUserConfig/setUserConfig
main.js/preload  IPC
settings.js      分类切换 + Git 表单
styles.css       表单样式
```

## 三、测试计划

2. 保存 → setUserConfig 收到 {name, email}
3. 快捷键分类仍可用（切换回来列表正常）
