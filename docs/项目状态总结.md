## 二、功能全景（已实现并测试）

### 2.1 浏览与文件管理
- 文件树：懒加载、展开状态记忆（刷新/粘贴后保持）、**虚拟滚动**（>300 行只渲染可视窗口）、隐藏文件开关
- **单击文件 = 打开 + 自动复制完整路径**（核心需求）；复制路径共 5 个入口（单击/快捷键 Ctrl+Shift+C/工具栏/右键/状态栏点击）
- **树定位**：从快速打开/搜索打开文件后自动展开目录链并高亮
- 多标签：中键关闭、右键关闭其他/全部、**拖拽排序**（顺序持久化）
- 右键菜单：新建文件/文件夹、重命名、删除、复制文件、粘贴到此处、在文件夹中显示
- **文件复制粘贴与系统剪贴板互通**（FileNameW 格式，资源管理器双向）
- **多项目**：顶部项目栏切换（当前高亮、右键移除、持久化）；每个项目**独立标签会话**；空状态显示最近项目
- 快速打开（Ctrl+P）：模糊评分匹配、最近打开文件列表

### 2.2 编辑器
- 行号 gutter（滚动同步、行数实时更新）
- 查找/替换（Ctrl+F / Ctrl+H）：计数、循环跳转、替换当前/全部
- **括号/引号配对自动补全**（自动配对、包裹选中、跳过重复、退格删配对）
- 字号缩放（Ctrl+= / Ctrl+-，9-24px，持久化）
- **GBK/UTF-16 编码自动识别与回写**（BOM → UTF-8 严格 → GBK 兜底；保存按原编码，不破坏文件）
- 状态栏：分支（可点击切换）、文件（点击复制）、行数、行列号、编码、换行符（CRLF）、版本号
- 快捷键体系：动作注册表（可自定义、冲突检测、恢复默认、持久化）

### 2.3 渲染（插件机制）
- 内置：Markdown（marked + 代码高亮 + 复制代码块）、HTML（沙箱 iframe）、CSV 表格、JSON 美化、图片、**PDF**（Chromium 内置查看器）
- **插件机制**：`plugins/` 目录放一个 JS 文件注册新格式（`api.registerRenderer`）；**热重载**（目录变更自动重新加载，开发版）
- CSP 精细控制（frame-src 含 about:/file:、img-src 含 file:）

### 2.4 Git（纯 JS 实现，无需安装 git）
- 日志：分支图（列状态机）、分支视图下拉（当前/指定/所有分支合并）、过滤、HEAD 徽标、**分页加载更多**
- 提交（Ctrl+K）：勾选文件、amend、**diff 预览**（点击文件行预览工作区改动）、作者配置
- Diff：左右分栏、hunk 折叠（>30 行默认折叠）、⤒⤓ 导航（按钮 + Alt+↑↓）、**旧版/新版内容一键复制**
- 分支切换（git 面板与状态栏双入口）
- 本地修改按目录分组折叠
- 状态刷新 500ms 防抖；**打开项目 Git 扫描延迟 800ms**（见 §五 进行中）

### 2.5 其他
- 主题：深/浅双主题（设置页选择 + Ctrl+Shift+T），全部颜色走 CSS 变量
- 内容搜索（Ctrl+Shift+F）：异步遍历不卡 UI、200 条上限 + 10s 超时
- 设置页（Ctrl+Alt+S）：快捷键（搜索/修改/冲突/恢复）、Git（作者配置）、主题
- 帮助页（F1）：快捷键速查（动态反映自定义、可过滤）+ 版本信息
- 会话记忆：标签/活动标签/工具窗口，**按项目隔离**，dirty 标签不恢复
- 任务列表（Ctrl+9，左侧停靠）：清单为主视图（增删改勾 / 优先级 / 三态分组），任务间可声明依赖并显示阻塞徽章 ⛓N（tooltip 列出阻塞方），一键在主区打开 DAG 依赖图（分层 SVG 自绘）；存储在项目根 `.myide/tasks.json`（可进 git），写失败降级 localStorage，载入时自愈（清洗悬空引用 + 断环）。见 `docs/开发文档-047-任务列表DAG.md`
- 错误处理：主进程 uncaughtException/unhandledRejection 落盘 `userData/my-ide-error.log`

## 三、架构与技术要点

```
main.js           Electron 主进程：窗口 + 全部 IPC + Git worker 调度 + 编码检测 + 错误日志
git-worker.js     worker_threads 执行全部 git 操作（主进程不阻塞，异常回退主进程）
git-service.js    纯 Node Git 封装（isomorphic-git）+ 自研 Myers 行级 diff + statusMatrix 批量状态
preload.js        contextBridge 安全桥（window.myIDE）
renderer/         渲染进程 16 个原生 JS 模块（无构建）：
  app.js          应用入口/工具窗口/多项目/状态栏/Modal
  tree.js         文件树（扁平虚拟滚动/复制粘贴/新建/右键）
  viewer.js       标签/编辑器（行号/查找替换/配对/编码/字号）
  git-panel.js    Git 面板（日志图/提交/diff/分支/分页）
  shortcuts.js    快捷键注册表（可自定义）
  settings.js/help.js/quickopen.js/search.js/outline.js/session.js/theme.js/plugin-loader.js
plugins/          用户插件目录（csv.js 示例）
scripts/          bench（性能基准）/ make-demo / git-commit / vendor / make-icon / syntax-check
tests/            26 项 git 逻辑测试 + 70 项渲染层 DOM 测试（jsdom + 真实样式注入）
docs/             42 份开发文档 + 本总结
```

**关键设计决策**：
- 渲染层模块通过 `window.App/Viewer/Tree/...` 协作，解耦清晰
- 文件树 render 串行化（防并发竞态）+ 目录缓存失效机制（粘贴/重命名/删除后）
- 会话按项目 key 隔离（`myide-session:<路径>`），保存时过滤非本项目文件
- 文本编辑豁免：仅输入框可见时 Ctrl+C/V 留给文本操作

## 七、环境限制与踩坑记录（重要）

1. **本执行环境无法启动 Electron GUI**（沙箱限制 electron.exe 写文件）——UI 靠 jsdom 测试验证，最终 GUI 需用户本机确认
2. **makensis 子进程被沙箱限制** → `npm run build` 的 portable 目标会卡住；绕过：`npx electron-builder --win --dir`（win-unpacked 目录版，`signExecutable: false` 已配置，保留图标）
3. **write/edit 工具有 bug**（EISDIR）→ 用 pwsh here-string 写文件；**PowerShell 5.1**：无 Join-String、here-string 嵌套易错、双引号内 `$` 需转义
4. **写补丁脚本时 JS 字符串里的 `\n` 必须写成 `\\n`**——否则真实换行写入代码造成语法碎片（曾导致 exe 启动 JS 错误，潜伏多轮才发现，教训深刻）
5. 推荐改代码方式：写 `patch.js` 脚本文件 → `node patch.js`（避免命令行转义地狱）；每次改完跑 `node -e "new Function(...)"` 语法检查 + `npm test`
6. `git-commit.js` 提交脚本用 statusMatrix 收集改动（自动尊重 .gitignore + SKIP 列表：node_modules/demo/dist/.git/.idea/smoke.log）
