# 编辑区左右与上下分屏

## 使用

- 点击“向右拆分”“向下拆分”或标签同名右键操作，两栏先显示同一文档，不移动原页，也不产生空白栏。两栏之后可以各自打开和切换文档。右键另外保留“拆分并移动”操作，与复制视图明确区分。
- 把标签拖到编辑区右侧或下侧的高亮区域可创建分屏；拖到另一组可转移标签，拖动中按Esc取消。组内拖动标签可排序。
- 每个编辑组有自己的标签栏，不再使用“全局标签栏＋每组文件下拉框”。新文件加入当前组；已经打开的文件也能加入当前组，同一文档可同时显示在两组。
- 两栏保留各自光标、滚动和Markdown显示模式；同文档共用正文、dirty状态及保存队列，一栏编辑或撤销后另一栏同步。保存、查找、大纲、选区和AI上下文跟随当前组。
- 拖动分隔线调整比例，双击均分；聚焦分隔线可用方向键调整。比例不设置20%–80%限制。
- 关闭标签优先选择本组后继；关闭或移走组内最后一个标签会收起空组。合并按钮保留当前组，组标题关闭按钮保留另一组，文件及未保存内容仍在标签中。
- 每组工具栏固定在各自标签栏右侧；切焦点只改变活动提示，不挪工具栏，不改变正文宽度、边距、字号。Markdown模式使用紧凑菜单，“源码对照”仍是同一文件的源码与预览。

## 文档与会话边界

目前支持两个编辑组，不递归拆成四组。同一文件可以拥有两个编辑视图，共用一个文档身份及保存队列；每组分别保留编辑状态。正文同步映射另一视图的选区及撤销状态，防止切栏覆盖新输入。关闭共享标签只移除本组引用，最后一份引用关闭时才执行未保存决策。阅读器沿用独立页面，进入阅读时合并编辑区，编辑文档保留为标签。

项目会话保存方向、两组全部标签、各组当前文件和当前组，比例全局记忆。沿用原规则：dirty正文不写入会话快照，对应文件不写入布局；切项目仍需经过未保存决策。兼容上一版只有当前文件路径的分屏记录。

## AI接口

- `editor_state.layout`包含`orientation`（horizontal/vertical/null）、`active`及每组当前`path`和`tabs`路径列表。
- `editor_control`支持`split_horizontal`、`split_vertical`、`unsplit`、`focus_group`、`move_to_group`。后两者传`group:0`或`1`，移动可传`tab`指定标签。首次拆分复制当前文档视图，已经分屏时调整方向。
- 操作沿用写授权与状态快照，标签归属或组焦点变化使旧快照失效。
- 命令与快捷键设置可搜索“向右拆分”“向下拆分”“合并分屏”“切换编辑组”，默认不占用已有快捷键。
