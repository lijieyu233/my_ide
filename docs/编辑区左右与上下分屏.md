# 编辑区左右与上下分屏

## 使用

- 标签右键选择“向右拆分并移动”或“向下拆分并移动”：选中的文件进入新组，焦点跟随。原组继续显示其余标签，只有一篇时保留空组以便打开第二份文件。
- 把标签拖到编辑区右侧或下侧的高亮区域可创建分屏；拖到另一组可转移标签，拖动中按Esc取消。组内拖动标签可排序。
- 每个编辑组有自己的标签栏，不再使用“全局标签栏＋每组文件下拉框”。新文件加入当前组；已经打开的文件回到其所属组。
- 两栏分别保留光标、滚动、撤销历史和未保存内容。保存、查找、大纲、选区和AI上下文跟随当前组。
- 拖动分隔线调整比例，双击均分；聚焦分隔线可用方向键调整。比例不设置20%–80%限制。
- 关闭标签优先选择本组后继；关闭或移走组内最后一个标签会收起空组。合并按钮保留当前组，组标题关闭按钮保留另一组，文件及未保存内容仍在标签中。
- 工具按钮位于当前组标签栏右侧，Markdown模式使用紧凑菜单；Markdown“源码对照”仍是同一文件的源码与预览。

## 文档与会话边界

目前支持两个编辑组，不递归拆成四组。这里采用“拆分并移动”语义，一份文件保留一个文档身份及一份保存队列；暂不支持同一文件的两个独立视图。移动时复用CM状态以保留撤销记录，读取中的文件仍使用原异步身份校验。阅读器沿用独立页面，进入阅读时合并编辑区，编辑文档保留为标签。

项目会话保存方向、两组全部标签、各组当前文件和当前组，比例全局记忆。沿用原规则：dirty正文不写入会话快照，对应文件不写入布局；切项目仍需经过未保存决策。兼容上一版只有当前文件路径的分屏记录。

## AI接口

- `editor_state.layout`包含`orientation`（horizontal/vertical/null）、`active`及每组当前`path`和`tabs`路径列表。
- `editor_control`支持`split_horizontal`、`split_vertical`、`unsplit`、`focus_group`、`move_to_group`。后两者传`group:0`或`1`，移动可传`tab`指定标签。首次拆分移动当前文件，已经分屏时调整方向。
- 操作沿用写授权与状态快照，标签归属或组焦点变化使旧快照失效。
- 命令与快捷键设置可搜索“向右拆分并移动”“向下拆分并移动”“合并分屏”“切换编辑组”，默认不占用已有快捷键。
