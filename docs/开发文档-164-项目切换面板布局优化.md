# 项目切换面板布局优化

## 问题与处理

原面板把搜索、结果和底部动作放在同一个滚动容器内。项目较多或字号增大时，操作按钮被推到视口外；项目名称、路径与“当前/已打开”混排，分组也不易辨认。

保留主题配色，将面板分为标题、搜索、结果状态、项目列表和底部动作。仅列表滚动，搜索与打开/复制路径/资源管理器动作始终留在面板内。外层限高，列表允许收缩，不依赖绝对定位把按钮叠在结果上。

已打开项目使用文件夹 SVG，最近项目使用时钟 SVG；名称和状态分开，当前项目有弱强调标签，分组显示数量。路径最多显示两行，按钮 title 和可访问性名称仍保留完整路径。长名称可换行，关闭按钮使用统一的尺寸与间距，行选中背景覆盖整行。

底部提供方向键选择与 Enter 打开提示，标题旁显示 Esc 关闭。保留项目搜索、焦点归位、中文组合输入、在途去重、保存失败保全、重试和共享菜单关闭逻辑。
