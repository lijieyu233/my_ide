# 界面控件与设置布局优化

保留当前主题，统一工作区共享控件的层次，并解决设置窗口分类换行、快捷键挤成一串和长动作名称与按钮争抢宽度的问题。

## 设置窗口

- 分类使用统一线性 SVG 和可键盘激活的按钮；当前分类有选中提示。
- 标题、搜索、列表、底部提示分区，窗口宽度上限 980px，列表独立滚动。
- 动作名称、快捷键、恢复/取消绑定分列；每套组合键作为一个完整单元换行。
- 860px 以下布局收拢操作区，560px 以下纵向排列，避免横向溢出。
- 搜索无结果有明确反馈，关闭按钮和搜索框有辅助技术标签。
- 移除 `quick-launch.css` 中旧的设置行 flex-basis，否则纵向布局会把动作信息撑到 16em 高。

## 共享控件

工具栏、项目切换按钮、工具窗口、标签关闭按钮、右键菜单、弹窗和表单统一圆角、分隔线、悬停、选中和焦点状态。颜色通过 body 上的主题变量派生，暗红与浅色均使用各自的面板和文本颜色。

保留停靠尺寸、编辑器字号和 Markdown 排版，不增加背景模糊、全局布局动画或运行期轮询。低动态效果偏好会关闭新增控件过渡与改键闪烁。
