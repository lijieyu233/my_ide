# 远程服务器 SSH 与 SFTP 第一版

左侧显示器图标进入「远程服务器」，点击标题旁的＋新建配置。填写主机、端口、用户名，选择密码或本地私钥认证。连接时会显示主机 SHA256 指纹，核对后才建立连接。已记住的指纹变化会阻止连接；确认服务器合法换钥后，可在编辑配置中主动清除旧指纹。

## 使用范围

- 支持多个服务器、多个连接会话、每个连接最多 16 个终端标签。
- 终端由 xterm.js 渲染，支持 ANSI 颜色、中文、PTY 尺寸同步；Ctrl+C 发中断，Ctrl+Shift+C/V 复制粘贴。
- 文件页显示本地和远程两栏，双击目录进入，支持路径跳转、上级目录、刷新、新建目录、重命名、删除文件及空目录。
- 选中文件可上传或下载，Ctrl+点击多选；支持跨栏拖拽，亦可将资源管理器中的文件拖到远程栏。
- 传输队列显示字节进度，支持取消、失败重试、清理完成项。同名文件覆盖需确认。

第一版逐文件传输，不递归传输目录，不跟随符号链接，不包含跳板机、端口转发、自动重连和远程编辑保存。退出 MyIDE 会关闭 SSH 连接；需要断线后持续运行的远程任务，应由 tmux、systemd 等服务器工具管理。

## 凭据与本机环境

配置在 `~/.myide/remote.json`。记住密码和私钥口令使用 Electron safeStorage；公开配置、日志和会话事件不返回密码。取消记住会删除已保存的凭据，连接时临时输入。私钥文件留在原位置，不复制进配置。

本机绿盾会对 Node 和 Electron 呈现不同文件内容，因此本地目录元数据、上传内容和私钥通过独立受信 Node 读取。运行环境需要 PATH 中存在 Node.js；源码开发环境已有该依赖。读取仍返回绿盾文件头时，上传失败并提示先解密。没有增加自动解密或绕过绿盾的行为。

上传和下载先写同目录临时文件，检查目标在传输期间是否变化，再发布。服务器覆盖已有文件要求 OpenSSH `posix-rename` 原子覆盖扩展；不支持时报告失败并保留原文件。取消、写入失败会尝试删除临时文件。连接已断时无法保证远程临时文件清理成功，应在恢复连接后检查 `.myide-*.part` 文件。

文件发布期间等待服务器确认，不能再取消发布。网络在发布后、回复前断开时，客户端可能无法确认最终结果，应刷新目标目录核实后再重试。

## 验证

`npm run test:remote` 使用回环地址真实 SSH/SFTP 夹具，验证凭据保密、版本冲突、首次拒绝和主机换钥、加密私钥签名、中文分片、PTY/Ctrl+C、文件传输、冲突保护、失败重试、取消和密文拒绝。

`npm run check:remote` 使用隔离配置的隐藏 Electron 实例，通过生产 preload/IPC 和真实 xterm 验证新建连接、系统凭据加密、多终端、Ctrl+C、文件选择上传下载、目录导航、窄窗布局、断开重连，生成临时截图供人工检查。夹具只监听 `127.0.0.1`，不连接真实业务服务器。

打包文件清单包含三个远程服务模块，包资源检查覆盖 xterm JS/CSS 和生产依赖。此次没有生成或交付安装包。

2026-10-10 验证结果：远程协议测试 23 通过、真实窗口检查 13 通过、DOM 回归 517 通过、包资源检查 76 通过。`npm test` 在原有 Git 集成测试处结束（60 通过、2 失败）：worker 调度初始化、hunk 回退的 Git 属性读取失败；此次没有修改这两个模块。
