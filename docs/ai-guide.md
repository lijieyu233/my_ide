# MyIDE AI 使用指南 / AI guide

AI 面板连接模型与工作台工具：从已有资料中读取上下文，执行授权动作，再检查实际结果。使用入口在右侧 AI 助手面板及设置中的 AI 助手分类。

## 选择运行方式

| 方式 | 需要准备什么 | 适合的使用方式 |
| --- | --- | --- |
| 普通助手 | OpenAI 兼容 Base URL、模型名及服务需要的 API Key | 在 MyIDE 中直接对话、引用文件并调用已接入工具 |
| DeepSeek Harness（DSH） | 本机 DSH 安装、可用启动器及其运行配置 | 在侧栏连接 Harness，保留项目会话和后台任务归属 |

打开设置的 AI 助手页，选择方式并填写对应配置。普通助手配置不等于 DSH 配置；支持的模型、推理强度和多模态能力以当前服务实际提供的选项为准。翻译在独立设置页维护厂商配置。

## 从一个可检查的小任务开始

1. 打开项目与目标文件，选中需要解释的段落或代码。
2. 在 AI 输入框用 @ 选择文件、选区等上下文，或使用斜杠命令。
3. 说明任务目标和范围，例如“解释引用内容，列出依据，先不修改”。
4. 查看回答及工具结果；需要修改时明确目标文件和验收方式。

跨项目工作时，检查当前项目、会话与附件。DSH 原项目的后台任务可以继续运行，回到原项目查看结果；这不表示它应操作后来切换到的新项目。

## AI 能操作什么

- **资料与编辑**：读文件和缓冲区、搜索、定位、修改文本、操作大纲、保存并检查结果。
- **网页资料**：读取页面与选区、导航、可用元素交互、收藏与标签组；范围见浏览器专项说明。
- **开发排查**：Git、任务、程序启动与日志、SSH/SFTP、数据库查询等已接入模块。
- **工作台设置**：读取布局与允许项，修改受支持设置，管理会话与工具任务。

工具参数与示例见 [AI 接口指南](ai-api.md)，逐模块进度见[接口清单](开发文档-171-AI操作接口模块清单.md)。这是应用内能力，不是外部客户端可直接连接的公共 HTTP/MCP 服务。

## 权限与结果

工具调用需要符合当前项目/会话归属、快照与权限。确认框、拒绝、过期状态或未保存内容都可能中断操作。一次成功调用不代表整个任务完成，最后应核对实际文件、运行日志或页面。

API Key 在本机配置，勿写入项目文档、示例、Issue 或截图。远程模型与翻译服务会收到本次提交的相关内容；发送前检查附件与上下文范围。

连接失败时先检查当前方式、地址、模型、认证与服务状态。DSH 重连后核对任务是否仍在运行，避免盲目重发产生重复执行。
