# 开发文档 038 —— Git 日志分页加载

> 状态：已完成 · 体验打磨

## 一、需求

日志固定 depth 100，长历史仓库只能看到最近 100 条。
目标：**「加载更多」按钮**——点击追加 100 条（depth 递增），其他分支视图同样生效。

## 二、实现

- git-panel 维护 `logDepth`（默认 100），reloadLog 使用
- 渲染列表尾部：当前提交数 ≥ depth 时显示「加载更多」→ depth+100 重拉
- logAll（所有分支）保持 depth 50
