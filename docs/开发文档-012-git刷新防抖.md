# 开发文档 012 —— Git 状态刷新防抖

> 状态：已完成 · 对应 ROADMAP P1-9

## 一、需求

保存文件后触发 Git 面板全量刷新（statusMatrix + log）。连续保存 N 个文件会刷新 N 次，大仓库下明显卡顿。
目标：**500ms 节流合并**，连续保存只刷一次。

## 二、设计

- `App.refreshGit()` 加 500ms 防抖（内部 timer）
- 立即刷新场景不受影响：`setRoot`、提交成功后直接调 `GitPanel.refresh()`
- 保存（saveTab）场景走防抖版

### 结构
```
app.js   refreshGit 防抖
```

## 三、测试计划

1. 连续保存两次 → 防抖窗口内只触发一次 GitPanel.refresh
2. 立即刷新路径（提交后）不受影响
