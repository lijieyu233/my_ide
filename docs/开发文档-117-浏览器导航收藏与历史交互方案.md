# 浏览器导航、收藏与历史交互方案

> 2026-10-01；基线 `8372971`，MyIDE 0.8.5。响应“UI设计、交互和添加功能”的改进方向；本文交付具体方案和当前行为取证，未实现产品功能。
> 总入口：[103 UI、交互与新增功能方案](./开发文档-103-UI交互与新增功能改进方案.md)。权限、协议、原生层与持久化边界继续按[096](./开发文档-096-内置浏览器权限导航与生命周期取证.md)，不重复计为新增能力。

## 1. 现状与用户任务

浏览器已有：后退/前进/刷新/主页、地址与关键词输入、混合收藏/历史建议、最多50条去重历史、首页最近8条、收藏位置选择/分组/重命名/拖拽、根目录落点、深色/浅色/跟随系统、登录会话复用，以及网页内转发的导航快捷键。不能把这些重新列成“待新增”。

本轮优化三个日常任务：快速找回看过的文档；整理收藏而不误删；看清正在打开什么、失败后如何继续。当前只有一个原生页面，本方案保持这一范围；多标签、云同步、密码管理、完整下载中心不进首版。

布局建议：顶部保留导航与地址栏；加载时同一位置的刷新切为“停止”，站点权限入口沿096；侧栏标题统一“收藏”，附搜索及新建文件夹，更多菜单容纳历史和导入/导出；中部承载网页/首页/历史视图，失败状态显示请求地址及下一步。原生网页与HTML管理页切换必须走统一挂载策略，不能只靠z-index。

## 4. 分包实施

### 117-B-A：地址与导航反馈（P1）

用户路径：Ctrl+L→输入Guide→↓选建议→Enter打开→加载状态可见→需要时停止；失败后能看见目标并重试。

1. 地址输入保留draft、submittedRequest与committedURL；接096的viewId/navigationId。导航期间地址显示请求值，重定向提交后更新；用户正在输入时不得被回推抢走草稿，Esc恢复已提交URL。错误显式绑定失败请求，旧错误无效。
2. 下拉使用combobox/listbox/option及aria-expanded/controls/activedescendant；输入保持焦点，↑↓改变活动项，Enter在有活动项时提交该URL，否则按原规则网址/搜索。Esc先关闭建议并恢复既定草稿策略；不要让方向键触发IDE其他操作。输入改变清活动项，中文组合输入期间Enter不能导航。
3. 建议两行：名称/来源标记，完整地址或有意义路径；8条上限先保留，长地址可截断但可查看完整值。不强制favicon网络请求；来源图标采用仓库SVG。相同URL合并保留来源标记，历史清理后仍可出现收藏来源。
4. loading阶段刷新按钮为停止，桥接主进程wc.stop；加载结束还原刷新。进度无真实测量时只作不定进度，不把35%/100%写成可靠下载百分比。取消与失败分别显示。
5. 错误页呈现目标URL、简短原因/可展开技术信息、重试及返回上一页（确实可后退才可用）；重试携带当前失败request而不是只推测currentUrl。TLS错误不自动忽略、不静默改协议。原生层显隐沿096真实验证。

验收：R1由活动建议URL提交，C1仍通过；IME、空输入、中文/长URL、无建议、连续导航与Esc均可完成。原生测试覆盖失败前/后commit、重定向、back/forward、停止和旧失败乱序；记录重试实际收到的请求URL。125/150%和窄侧栏截图检查下拉定位、按钮与错误层遮挡。

### 117-B-B：收藏发现与整理（P1）

用户路径：打开收藏→搜索标题/URL→定位所在分组→编辑名称/地址/位置→保存；纯键盘也可完成。

1. 侧栏顶部搜索，仅过滤收藏标题/URL，匹配时展示所属文件夹；显示条目数、无收藏与无匹配两个空态。清除搜索恢复原折叠状态。无收藏时仍绘制已有空文件夹和新建入口，修复R3，不增另一套文件夹数据。
2. 收藏条目及组头有明确键盘焦点，↑↓移动、←→折叠组、Enter打开，菜单可用键盘访问；焦点与当前网页/选中项分别表示，拖动换位置仍保留。列表结构采用一致语义，不随意混用tree/listbox导致操作预期混乱。
3. 先给右键/更多菜单加“编辑收藏…”：名称、URL、位置放在同一小面板；取消不写入，保存校验URL政策和重复地址，失败保留输入。R4当前星标取消行为保留；若后续改亮星标为编辑，须同时改tooltip/快捷键说明、提供面板内取消收藏，独立提交与验收。
4. 收藏和历史菜单职责分清；现有“收藏夹”tooltip改为“收藏”，首页新窗口说明与当前主进程策略一致。工具栏/列表图标用1.4px内联SVG，右键菜单emoji沿现约定；不为统一外观改动网页内容。
5. 单项取消收藏可提供短时撤销，但写确认必须接096-D/091，不能存储失败仍toast成功。撤销只恢复本次条目/位置，不回滚整个旧数组覆盖期间新收藏；文件夹删除仍把内容移根，C2必须保留。

验收：零收藏建空组可见；跨组搜索/取消搜索保持位置和折叠；鼠标拖动、键盘移动、名称custom、重名URL、空值/存储失败有明确结果。多主题长中文/窄栏截图和读屏实测分别记录，不能以R6属性检查代替。

### 117-B-C：历史管理页（P2，新增能力）

“历史”作为更多菜单和首页明确入口，页面标题、搜索、按日期分组、清除筛选与条目操作集中呈现。打开历史摘下原生网页并保留实例；“返回网页”恢复原页/导航栈，不打开HOME替代。

首版显示全部已保留的50条去重记录，标题/URL/访问时间，支持打开、复制地址、删除选中项；保留当前去重逻辑，不伪造为每次访问事件日志。新增记录id用于选择/删除归属，不能以过滤后的index删全量数组。首次迁移旧数据稳定补id，坏项沿096隔离。

“清空历史”确认写明范围与数量：“删除本机保存的浏览历史；收藏、Cookie和登录状态保留”。单项/选择删除可直接执行并刷新结果；明确清空不提供永久恢复记录，不把删除内容藏进默认备份。请求失败保留原记录与选中范围，历史页打开期间新导航到来不漂移已选条目。时间范围清理作为下一小包，不与首版混入。

验收：9–50条都可搜索定位；删除过滤后的两条只删对应id；重复URL/日期边界/无匹配/新记录到来；清空取消无变动、确认后不影响C2收藏和真实登录会话。当前仅50条没有必要先上虚拟列表、统计后台或搜索服务。
