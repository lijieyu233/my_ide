# 开发文档 019 —— electron-builder 打包分发（便携版）

> 状态：已完成 · 对应 ROADMAP P2 最后一项

## 一、需求

目前运行依赖 `npm start` / bat 脚本 + node_modules（500MB+），不能分发。
目标：**单文件便携版 exe**——拷贝即用，符合"私人定制工具"定位。

## 二、设计

- 打包工具：electron-builder（`--win portable`）
- `build` 配置（package.json）：
  - `productName: MyIDE`、`appId: local.myide.app`
  - `files`：仅包含运行时必需（main.js/preload.js/git-service.js/renderer/plugins/package.json），排除 tests/docs/scripts/README/开发文档（减小体积）
  - `win.target: portable`
- 打包后应用内版本显示：读不到 `.git` 时自动降级（仅版本号）——已有逻辑 ✓
- 产物：`dist/MyIDE <version>.exe`（gitignore 掉，产物不入库）

### 验证
- 构建成功 + 产物存在（本环境可验证）
- GUI 启动验证：需用户本机双击确认（本环境沙箱限制）

## 三、结构
```
package.json      build 段 + devDep electron-builder
.gitignore        dist/
```
