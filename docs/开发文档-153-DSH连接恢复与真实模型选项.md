# DSH 连接恢复与真实模型选项

用户反馈模型与推理被显示成“原生默认”，随后连接失败。占位文案把目录未加载误表达成选中了默认模型；旧连接发现信息、地址或授权变化时也缺少完整恢复。

## 修复

- DSH 发现与授权握手放在同一有界重试循环中，每次重读发现文件；旧地址未响应或旧授权不成立时等待新信息。错误区分未发现、宿主未运行、本机未响应和授权失败，不显示内部 ACP 回退说明。
- Windows 无权查询其他进程存活时，不直接判为 DSH 未运行；仍通过仅接受 127.0.0.1 的真实授权握手验证。
- 正常消息流意外结束、请求超时使旧连接失效；后续发送重新发现宿主并恢复会话。用户停止不关闭健康宿主连接。
- 读取模型选项会向宿主读取最新目录和会话选择，不把缓存当作连接成功。发现旧连接失效后只重试一次读取，恢复原会话，不重发聊天或工具操作。
- 侧栏显示实际模型和实际推理选项；未连接时明确禁用选项，有目录前不展示虚构默认。增加“重新连接”，保持会话，运行中禁用重连。
- DSH 欢迎页不再提示填写普通助手的服务地址。记录连接成功或失败用于定位，日志不写授权令牌。
