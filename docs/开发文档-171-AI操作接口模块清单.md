# AI 操作接口模块清单

核对日期：2026-10-17。此文档用于后续开发与验收，按模块持续更新。

- `[x]`：已有专门的 AI 调用接口，并已接入执行链路；条目附当前工具名。
- `[ ]`：尚未提供专门接口，或只完成部分能力。已有界面、快捷键、内部 IPC，不等于 AI 已接入。
- 通用命令、文件读写或临时脚本能间接完成的操作，不作为对应模块接口已完成的依据。
- “会话与上下文基础能力”单独记录已实现的运行机制，不表示已有同名 AI 工具。
- P0 优先补齐日常操作闭环；P1 扩展工作流；P2 补齐配置与管理。优先级不代表承诺完成日期。

- [x] 发送消息及工具续跑时提供当前页面、工具窗口、项目根和当前文件路径（`App.getPageContext()` 自动注入）。
- [x] 远程页面提供当前服务器与终端标识，不自动注入密码、私钥或终端正文（页面上下文机制）。
- [x] 提供 AI 可主动调用的统一界面状态接口：当前页面、面板、焦点、选区、弹窗和可用操作。（2026-10-15：工作台接口第一批；工具与验证见文档173。）
- [x] 读取当前选中文本及其来源：编辑器、网页或终端。（2026-10-15：工作台接口第一批；工具与验证见文档173。）
- [x] 列出当前弹窗及按钮，并按明确标识确认、取消或关闭。（2026-10-15：工作台接口第一批；工具与验证见文档173。）
- [x] 操作后读取实际状态，确认目标页面、文件或控件已生效。（2026-10-15：工作台接口第一批；工具与验证见文档173。）

依据：[页面感知与项目上下文隔离](./开发文档-135-AI页面感知与项目上下文隔离.md)。

- [x] 扩展可见 HTTP/HTTPS iframe 与开放 Shadow DOM 的正文和元素读取（`browser_frames`、`browser_frame_read`、`browser_read`；2026-10-16；同源/跨源框架读写与隐藏框架拒绝已验证，关闭 Shadow DOM 和不可访问的隔离框架明确不支持）。

现有读取能力不等于完整浏览器自动化。字幕接口仅对支持来源生效。上传下载及弹窗现有专门接口；密码、关闭Shadow根和Electron原生prompt仍不开放，不通过任意脚本绕过。

## 17. 接口共通验收要求

以下是新增接口的验收条件，不计入模块完成数量。

1. 先读实际状态，再执行操作，最后读取结果；请求被接收不等于操作成功。
2. 使用项目、会话、文件、程序等稳定标识；不要靠显示名称猜测目标。
3. 返回明确的成功、失败、取消、超时、待授权状态，以及是否可以重试；避免重复执行已成功的副作用。
4. 涉及项目切换或后台任务时，绑定原项目与会话，不把输出和操作派发到当前新项目。
5. 保护未保存输入、独立厂商配置与密钥；不要通过修改源码实现本应由设置接口完成的操作。
6. 标准助手与 DSH 接入同一套能力与权限检查；按实际执行链路验证，不能只检查 schema 存在。
7. 完成开发并通过对应验证后，将具体条目改为 `[x]`，补充工具名、验证记录和完成日期；部分完成时拆分条目。
