# 开发文档 021 —— 帮助页（F1 快捷键速查）

> 状态：已完成 · 体验打磨

## 一、需求

新用户/自己久了都会忘记快捷键。目标：**F1 打开帮助弹窗**——快捷键表动态生成（**反映自定义按键**）+ 版本信息 + 常用技巧。

## 二、设计

- `help.js`：模态弹窗，表格来自 `Shortcuts.bindings()`（自定义后表格同步变化）
- 入口：F1 + 工具栏 ❓ 按钮
- 底部技巧提示（单击复制路径/中键关标签等）

### 结构
```
renderer/help.js   弹窗 + 动态表格
shortcuts.js       注册 F1
index.html         ❓ 按钮
```

## 三、测试计划

1. F1 打开帮助弹窗，表格含"快速打开文件"
2. 自定义快捷键后表格显示新按键（与设置页一致）
3. Esc 关闭

- [x] npm test 全绿
