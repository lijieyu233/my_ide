# 浏览器视频字幕专用工具

## 实际故障与改动

用户在 Harness 侧栏要求提取 B 站视频字幕时，模型反复导航接口、使用未登录的 web_fetch，且旧播放器接口多次返回不匹配的字幕。目标 BV1d1pR6zEBM、CID 42686482429、视频 120 秒；会话中的字幕却到 351.56 或 423.02 秒，不能作为目标视频内容交付。

新增 browser_subtitles，普通助手与原生 Harness 的 MyIDE MCP 桥共用。原生 Harness 工具、Agent 循环、会话仍保留；只对 B 站 BV 字幕任务提示优先使用专用工具，不接管其他网站工具策略。

## 数据链路

当前内置浏览器 Session → 视频 view 元数据 → nav 的 WBI 签名材料 → 签名播放器 wbi/v2 → 平台字幕 CDN → 视频/分P身份与时间轴检查 → 分页字幕正文。

- 可读当前 BV 视频或参数 url 指定的视频，p 决定分P；不会把当前网页导航到 JSON 接口。
- 登录态、代理由同一个 Electron Session 管理；不把 Cookie、用户账号或签名字幕地址发给模型。
- 使用 Fetch referrer 选项。实站证实手工设置 Referer 请求头会使 Chromium 返回 ERR_BLOCKED_BY_CLIENT；相同请求去掉该头后 HTTP 200。
- 只接受 B 站视频域名、受支持的 hdslb 字幕路径；拒绝凭据、本地目标和重定向。
- 播放器 bvid/cid 必须匹配；字幕时间轴不得超过目标时长的容差。CDN 正文本身没有视频 ID，身份/时长检查不能保证语义正确，工具输出明确说明这一限制。
- 正文按最多 20000 字符返回，使用 snapshot/nextCursor 续读到 complete=true；2 MB 完整读取预算，不把超预算数据当全文。
- 切换页面、刷新、取消任务及撤销权限会中止读取或使快照失效；请求和总提取时间有界。
- 登录要求、无字幕、语种不可用、平台错误、视频不匹配以结构化 errorCode 返回。侧栏不会把这些字段压扁成只有一句错误文字。

不支持烧录硬字幕 OCR、音频转写或无字幕视频的自动补录；不能将章节、评论或弹幕冒充逐句字幕。

- 字幕服务 9 项通过，浏览器执行链路 18 项通过；包括视频身份、超长错误字幕、分页、取消、预算与签名地址不泄漏。

- 隐藏窗口 UI 检查 458 通过 / 11 失败 / 3 跳过；失败为 Git 日志/暂存区 9 项与 Markdown 亮度/流程图 2 项。本次未修改这些模块；已查看普通助手与 Harness 侧栏截图，字幕专项 UI 链路通过。
