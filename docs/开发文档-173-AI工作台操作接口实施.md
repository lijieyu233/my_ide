# AI 工作台操作接口实施

## 第一批：界面、项目、编辑器与 Markdown（2026-10-15）

共用工具契约在 `renderer/ai-workbench-tools.js`，主进程适配器在 `src/main/ai/ai-workbench-tools.js`。标准助手与 DSH 均从原有 TOOLS 清单取得工具，复用已有权限审批、任务归属和单次执行账本；没有单独放行通道。

| 模块 | 工具 |
| --- | --- |
| 界面 | `ui_state`、`workbench_state`、`ui_selection`、`ui_dialogs`、`ui_dialog_action` |
| 项目 | `project_control`：打开、关闭、新建、重命名、移动、复制、可恢复删除 |
| 编辑器 | `editor_state`、`editor_control`：标签、未保存缓冲区、选区、定位、替换、保存、撤销重做 |
| 大纲 | `outline_change`：修改标题、层级、整章移动 |
| Markdown | `markdown_state`、`markdown_control`：模式、刷新、标题定位、阅读样式、HTML浏览器打开 |

先读取对应模块状态取得 snapshot，再携带 snapshot 调用修改工具。`workbench_state({module:"project"})` 用于没有单独读取工具的模块。快照包含项目、模块、状态摘要与五分钟有效期，最多缓存128条；正文、选区或目标状态变化后拒绝旧快照。参数、实际目标与主进程批准绑定，同一工具调用ID重发不重复执行副作用。

未保存标签默认拒绝关闭并返回 save/keep 选项，指定 save=true 时也必须保存成功。文件操作复用现有路径 Worker、标签联动和撤销记录；复制遇同名目标拒绝覆盖。AI不能通过通用弹窗按钮批准自身权限。后台所属项目与当前项目不符时拒绝执行，不把操作转移到新项目。

阅读字号使用现有编辑器允许的10–20px，标题颜色、行距和阅读宽度写入独立设置，实时预览与只读预览共用变量。界面操作返回实际状态；系统浏览器打开仅能确认请求已派发，不能证明外部窗口已经显示。

验证：`npm run test:workbench` 6组通过；隐藏生产窗口 `npm run check:workbench` 6组通过，覆盖未经批准拒绝、真实CM6选区替换、撤销重做、dirty保全、旧快照失效、保存、新建/改名与Markdown设置。`npm test` 已后台运行；全量Git基线中的临时目录EPERM失败单独记录，不放宽断言。

其他模块尚未发布时不对模型公布对应工具；后续批次分别补充工具、验证记录与清单勾选。

## 第二批：翻译、启动、远程与快速启动（2026-10-15）

- translation_state / translation_start / translation_job / translation_config：独立厂商配置、语言、模型与Key、异步任务、结果、取消、重试与复制。读取和审批脱敏；跨厂商切换保留各自Key。翻译网络请求带任务ID和60秒上限，取消真实网络请求。
- launch_batch / launch_wait / launch_diagnose / launch_config_control：批量启停、最多30秒等待、进程归属/端口/日志诊断、删除/排序/后台保留设置。复用现有进程身份校验。
- remote_state / remote_profile / remote_connect / remote_file_control / remote_transfer / remote_job_control：服务器、连接、文件、传输与取消。首次及变化指纹仍由原有可信对话框处理，AI不能批准。配置不回传认证秘密。
- quick_launch_state / quick_launch_control：入口和分组、顺序、打开、JSON配置导入导出。同名目标不默默覆盖，配置版本变化拒绝旧修改。系统打开仅确认请求受理。

后续异步副作用派发前通过 workbenchVerify 再次核对主进程任务与批准，避免取消后继续批量启动或连接。

验证：工作台服务4组通过，包含真实回环SSH/SFTP移动与上传；原远程服务23组、目录7组、本地目录13组通过。生产隐藏窗口检查累计9组通过，覆盖真实配置保存、脱敏、快速启动导出，以及真实Windows进程批量启动/诊断/停止。
