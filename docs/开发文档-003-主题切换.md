# 开发文档 003 —— 主题切换（深色 / 浅色）

> 状态：已完成 · 对应 ROADMAP P0-2

## 一、需求

当前只有深色主题。用户全天使用，白天浅色更护眼（对齐 PyCharm 的 Darcula / Light 双主题）。

## 二、设计

- **CSS 变量体系**：styles.css 已有 `:root` 变量，本次把残留的硬编码颜色（按钮/滚动条/代码块等）全部提取为变量
- **浅色主题**：`body.theme-light` 类覆盖全部变量（PyCharm Light 风格：白底、浅蓝选中、深灰文字）
- **切换**：工具栏 🌓 按钮（`Ctrl+Shift+T`）循环切换，写入 localStorage（`myide-theme`）
- **防闪烁**：`theme.js` 在页面脚本最前加载，立即应用已保存的主题

### 结构
```
renderer/theme.js      init/toggle/current + 立即应用
styles.css             硬编码色 → 变量 + .theme-light 覆盖块
index.html             工具栏按钮 + theme.js 最先加载
shortcuts.js           Ctrl+Shift+T
```

## 三、测试计划

1. 默认深色（body 无 theme-light）
2. toggle → light：body 有类 + localStorage = light
3. 再 toggle → 回深色
4. Ctrl+Shift+T 快捷键生效

## 四、验收
