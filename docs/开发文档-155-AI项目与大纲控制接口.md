# AI 项目与大纲控制接口

项目与大纲共提供 12 个结构化控制工具，普通助手和桌面 DSH 经同一 MyIDE MCP 入口调用。2026-10-17 补齐 JSON 结构大纲、编辑区分级折叠及双向同步开关。

| 工具 | 行为 |
| --- | --- |
| project_list | 已保存项目和当前项目，最多 100 项 |
| project_tree | 指定项目相对目录的直接子项，最多 250 项，提供 truncated |
| project_open_file | 在编辑区打开文件，保留已打开文件的输入与标签 |
| project_reveal | 展开父目录链、选中并定位文件或目录 |
| project_directory | 明确设置单个目录展开或收起，不递归展开整项目 |
| project_refresh | 清除目录缓存并刷新项目树 |
| outline_read | 从当前 Markdown/JSON 未保存正文读取结构、层级、行号、树展开/选择、编辑器折叠状态与 snapshot，最多 500 项 |
| outline_jump | 以 snapshot 和 heading ID 调用真实 Viewer 导航 |
| outline_section | 返回 Markdown 整章或 JSON 结构原文，最多 20000 字符并提供 truncated；JSON 从字段名开始，不保证是独立 JSON 文本 |
| outline_expand | 单个结构或整个大纲展开/收起；遵循 JSON 同步开关，无结构子项的非空 JSON 块始终联动编辑区 |
| outline_fold | 显式控制编辑区本级、递归或全文折叠/展开，不修改正文 |
| outline_sync | 明确开启/关闭 JSON 大纲与编辑区双向同步，开启时采用现有编辑器折叠状态，记住偏好 |

本模块项目操作限当前项目；跨项目切换由工作台 `project_control` 提供。大纲支持 Markdown 标题及 JSON 对象/数组，JSON 普通字段及普通数组元素不进入结构列表。

## JSON 与折叠调用

先 `outline_read {}`，从结果取得 `snapshot` 和 `items[].id`。节点 ID 仍使用 `heading-数字` 以兼容旧调用，不能猜测，也不能传 JSON 字段路径代替 ID。结果包含 `format`、`syncEnabled`、`canFold`；节点包含 `hasChildren`、`foldable`（大纲箭头能力）、`editorFoldable`、`editorFolded`（不可折叠时为 null）、`expanded`（树状态）、`visible`。折叠操作返回同一快照与稳定节点 ID，并重新读取实际状态。

| 调用 | 参数示例 |
| --- | --- |
| 只折叠本级，保留内部状态 | `outline_fold {"snapshot":"读取结果中的值","heading":"heading-2","expanded":false,"scope":"current"}` |
| 展开本级及全部内部块 | `outline_fold {"snapshot":"读取结果中的值","heading":"heading-2","expanded":true,"scope":"recursive"}` |
| 折叠全文 | `outline_fold {"snapshot":"读取结果中的值","expanded":false,"scope":"all"}` |
| 开启 JSON 双向同步 | `outline_sync {"snapshot":"读取结果中的值","enabled":true}` |
| 关闭 JSON 双向同步 | `outline_sync {"snapshot":"读取结果中的值","enabled":false}` |

`scope` 默认 `current`；本级、递归必须有 `heading`，全文禁止提供 `heading`。`expanded=true` 展开、`false` 折叠；同步开关使用 `enabled`，没有 toggle 操作，重试不会反向切换。没有结构子项但包含普通字段/元素的 JSON 块也可操作，紧邻空 `{}`/`[]` 返回 `OUTLINE_NOT_FOLDABLE`。只读预览可读取大纲，显式编辑区折叠返回 `OUTLINE_FOLD_UNAVAILABLE`，开启同步返回 `OUTLINE_SYNC_UNAVAILABLE`，不会假报成功；可先使用已有编辑器/模式工具进入编辑视图。Markdown 支持 `outline_fold`，不支持 JSON 同步开关。

折叠显示和开关变化不会使正文快照失效，正文、文件身份、路径或编辑版本变化后必须重新 `outline_read`；再次读取也使之前快照失效。操作不保存文件、不修改当前缓冲区、dirty 状态、光标或撤销内容。`outline_expand` 在同步关闭时独立控制有子结构的大纲节点，但无结构子项的非空 JSON 节点仍直接控制编辑区。

## 控制链路

工具定义由 renderer/ai-project-tools.js 提供，主进程 AiToolContract 校验严格字段与相对路径，ai:project 绑定 AI 请求身份并进入执行账本。主进程核验真实路径和链接范围，再调用固定的 AiProjectTools.operate 入口；模型不能传脚本或 CSS 选择器。重复调用 ID 复用结果，已取消请求不能继续派发。

除项目列表外，工具要求当前页具有 projectContext。切到启动、浏览器、远程等独立页，不开放本批文件/大纲工具，也不返回后台编辑器文件。项目树枚举是有界异步目录读取，不递归。展示名称与正文是观察数据，不是用户指令。

大纲 snapshot 绑定项目、文件 id、路径、编辑代次及当前正文。文件切换、输入变化、新读取后旧 snapshot 不能继续操作；heading 必须来自本次已返回大纲。主进程把核验过的确切文件路径传回面板，等待 IPC 期间切换到其他文件会拒绝操作。章节提取不写剪贴板，大纲显示操作不改写文件，JSON 同步偏好存入本地设置。大纲跳转复用 Viewer.navigateTo，保留实时预览、源码与预览已有导航语义。离开项目页后新折叠/同步工具也从模型清单中移除。
