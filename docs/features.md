# MyIDE 完整能力与边界 / Capabilities

MyIDE 的能力围绕三个方向组织：AI 协作、本地文档与项目管理、开发与运行工具。浏览器和阅读器用于把资料带回工作现场。

## AI 协作 / AI-assisted work

普通助手可连接 OpenAI 兼容模型服务；DSH 模式连接本机 DeepSeek Harness。消息可引用文件、选区和工作台上下文，模型与推理选项以当前后端实际提供的能力为准。

AI 工具覆盖当前界面、项目与文件树、文档缓冲区、大纲、浏览器、翻译、Git、启动面板、SSH/SFTP、数据库、任务、阅读器、设置与会话。工具使用实际状态和稳定标识，修改与执行受权限及上下文归属约束。DSH 切项目后可在原项目会话中继续后台运行。

工具接入不等于所有操作可以无条件成功。未保存内容、过期快照、连接或权限问题可能阻止动作；应读取执行结果与实际状态。目前未提供独立公共 HTTP API/MCP 服务。

## 本地文档与项目 / Documents and projects

| 能力 | 实际用途与范围 |
| --- | --- |
| 项目目录与会话 | 打开、切换本地目录，保留各项目标签与工作状态；普通文件仍可由其他软件使用 |
| 搜索与导航 | 项目内容搜索、快速打开、文件树和结构大纲，定位后继续编辑 |
| Markdown | 实时预览、源码、只读预览、源码对照、标题大纲、代码高亮、表格与图片操作 |
| 代码与 JSON | CodeMirror 6 编辑、查找替换、语法高亮；JSON 对象/数组大纲及折叠同步 |
| 多格式查看 | HTML、图片、PDF、DOCX、XLSX、PPTX 等预览；格式支持不表示具备对应专业软件的完整编辑能力 |
| 输入与保存 | 文本编码和换行处理、未保存状态、磁盘版本冲突反馈；重命名、移动等路径操作与打开文档联动 |
| 编辑布局 | 左右或上下两组，支持同一文档双视图与不同文件；共享正文、独立导航和滚动，不递归拆成四组 |

文本编码支持 UTF-8、UTF-16LE/BE、GBK 相关操作；自动推测不覆盖所有字符集。PDF 在编辑区预览，与阅读器的 EPUB/CBZ 处理是不同路径。

<a id="development-tools"></a>
## 开发与运行工具 / Development tools

| 模块 | 可完成的工作 | 使用条件 |
| --- | --- | --- |
| Git | 状态、历史、差异、暂存、提交、分支与同步；检查待提交和待推送内容 | 部分能力依赖系统 Git；认证、冲突与未保存内容可能阻止操作 |
| 启动面板 | 配置程序、启停、批量操作、端口、就绪检查和日志 | 需要正确的工作目录与启动命令；进程启动、端口响应与业务就绪分别判断 |
| SSH/SFTP | 已配置服务器的终端、远程目录、上传与下载 | 需要网络、账号与主机指纹确认；连接状态及传输结果以实际返回为准 |
| 数据库 | 连接与结构浏览、查询和结果查看；AI 查询任务 | 需要服务及相应驱动/权限；写入与结构变更应经明确授权 |
| 任务 | 记录工作项、状态、日期、依赖和文件链接 | 面向项目任务管理，不是多人协作服务 |
| 快速启动 | 打开常用应用、目录、文件和网页 | 管理入口；与负责进程和日志的启动面板分开 |

## 浏览与阅读 / Research and reading

内置浏览器支持网页标签、历史、收藏、保存的标签组、选区翻译，以及面向 AI 的正文读取与交互工具。翻译配置可独立保存厂商、模型、Key 与目标语言。网站登录、扩展和自动化能力以实际页面及 Electron 支持为准。

书架管理 TXT、基础重排 EPUB 和 CBZ 的最近阅读、位置与书签。书籍无需各自创建项目。未提供通用 PDF 转换、DRM 解密或漫画 OCR。

[阅读器范围](小说与漫画阅读器.md) · [书架](书架与最近阅读.md) · [浏览器工具范围](AI浏览器剩余接口补全.md)

## 自定义与扩展 / Customization

主题、字号、阅读宽度、布局和快捷键可配置。渲染器插件可注册文件类型；当前扩展接口见[插件指南](../plugins/README.md)，架构见[开发者说明](architecture.md)。

## 评估前需要了解

Windows 是主要验证平台，界面以中文为主。当前不包含完整语言服务、调试器、多用户协作后台或成熟 IDE 的扩展生态。代码采用 MIT，第三方组件仍遵循各自许可。

本地编辑可独立于 AI 使用。启用远程模型、翻译、网页、SSH 或数据库服务后，相关操作可能联网。性能需结合版本与项目规模测量，当前不提供固定的性能倍数保证。
