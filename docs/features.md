# MyIDE 功能与限制 / Features and limitations

MyIDE combines local Markdown/code editing, project navigation, Git, an embedded browser, and AI workbench tools in a Windows desktop application.

## Markdown 文档工作台 / Markdown workspace

支持实时预览、源码、只读预览和源码对照，配合标题大纲、查找替换、表格编辑、wiki 链接、图片复制及尺寸调整。适合笔记、项目说明和技术文档。

[图片复制与尺寸](Markdown图片复制与缩放.md) · [实时预览实现](开发文档-083-Markdown实时预览与预览对齐.md)

## 同文档双视图 / Split editors for the same document

向右或向下拆分时两组先显示同一文档，共用正文与保存身份；编辑同步，光标、滚动、Markdown 模式及组内文档切换独立。工具栏固定，焦点不应改变正文排版。

可以在右栏打开另一文件并保留左栏原文，或查看长文的两个位置。关闭共享标签只移除本组引用，最后一份关闭仍处理未保存内容。当前支持两组，不递归拆成四组。

[分屏操作与验证](编辑区左右与上下分屏.md)

## 代码、JSON 与多项目 / Code, JSON, and projects

语法高亮、查找替换、项目内容搜索、多项目会话与文件树。JSON 大纲显示对象/数组结构并支持折叠联动。文本提供 UTF-8、UTF-16LE/BE、GBK 相关读写操作，自动推测不保证覆盖所有字符集。

磁盘版本变化可能拒绝旧版本保存，以保留输入并比较。目录移动、撤销等受路径、版本与规模限制。

[JSON 大纲与折叠](JSON大纲与分级折叠.md)

## Git 与启动 / Git and launch

Git 状态、历史、差异、提交、分支与推拉入口，部分能力依赖系统 Git。启动面板管理已配置程序的进程、端口和日志；快速启动用于打开应用、文件、目录或网页，是独立模块。

“进程已启动”“端口响应”“业务就绪”含义不同。已有入口或专项通过不保证任意仓库、网络、认证或配置下成功。

## 浏览器与翻译 / Embedded browser and translation

提供浏览器标签、收藏、保存的标签组、历史与选区翻译。翻译可选择独立厂商、模型和目标语言。内置浏览器不承诺兼容系统浏览器全部扩展，站点能力以实际页面为准。

## 小说、漫画与书架 / TXT, EPUB, CBZ reader

书架管理最近阅读和进度，阅读器支持 TXT、基础重排 EPUB、CBZ。书籍不必各自创建项目。目前不提供通用 PDF 转换、漫画 OCR、DRM 解密或任意电子书格式支持。

[阅读器范围](小说与漫画阅读器.md) · [书架与最近阅读](书架与最近阅读.md)

## AI 操作 / AI workbench actions

AI 可在配置与授权范围内使用编辑器、项目、大纲、浏览器、翻译、Git、任务、启动、远程、数据库、设置与阅读器等已接入工具。先读实际状态，操作可因状态变化、取消、未保存内容或权限被拒绝。

接口供应用内助手使用，不是现成的公共 HTTP/MCP 服务。实现路径与特定外部服务实测是不同结论。

[工具指南](ai-api.md) · [模块清单](开发文档-171-AI操作接口模块清单.md)

## 使用前的三个问题 / Evaluation FAQ

**替代完整 IDE 吗？** 侧重文档与项目工作台，不承诺完整 PyCharm/VS Code 的调试器、语言服务或扩展生态。

**全部离线吗？** 本地编辑和远程服务是两回事，AI、翻译、网络浏览与 SSH 可能使用网络。

**保证性能倍数优势吗？** 性能结论需可复现基准、项目规模和版本条件，首页不使用未经复核的固定内存倍数宣传。
