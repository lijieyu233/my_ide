# 开发文档 009 —— 设置页面与自定义快捷键

> 状态：已完成 · 对应 ROADMAP P2（快捷键自定义，提前）

## 一、需求

- 工具栏 ⚙️ 设置按钮 → 设置页面（PyCharm Settings 风格：左分类 + 右内容）
- 目前唯一设置项：**快捷键**（参考 PyCharm Keymap：动作列表、点击修改、恢复默认、冲突提示）
- 快捷键可持久化（localStorage），重启生效

## 二、设计

### 快捷键系统重构（架构级）
硬编码 if 链 → **动作注册表**：

```
Shortcuts.register(id, { desc, keys: ['ctrl+p'], run })   // 注册动作
组合键归一化：ctrl/alt/shift + key → 'ctrl+shift+c'
keydown 统一分发：combo → id → run()
自定义：localStorage 'myide-keys' = { id: combo }，启动时覆盖默认
冲突：setBinding 检测已占用 combo，返回冲突动作名提示
```

- Esc（关弹窗）不参与自定义（防止无法取消）
- textarea 内已处理的组合（defaultPrevented）不重复触发

### 设置页面
- 入口：工具栏 ⚙️ + `Ctrl+Alt+S`（PyCharm Settings 同款）
- 布局：左侧分类（快捷键）+ 右侧动作列表
- 每行：动作名 + 描述 + 当前快捷键按钮（点击 → "按下新组合键…" → 按键即改）+ 恢复默认（仅自定义过的显示）
- 顶部"恢复全部默认"
- 冲突时提示"与 X 冲突，已覆盖"

### 结构
```
renderer/shortcuts.js  重构为注册表 + 全部动作迁移
renderer/settings.js   设置面板
index.html             ⚙️ 按钮 + settings.js
styles.css             .set-* 样式
```

## 三、测试计划

1. 现有快捷键测试全部照常通过（注册式分发等价）
2. Ctrl+Alt+S 打开设置面板
3. 修改绑定：点行 → 按 ctrl+q → 生效（按 ctrl+q 触发动作）
4. 恢复默认：还原原快捷键
5. 冲突：绑定到已占用组合 → 提示
