# HTML 独立源预览

旧预览使用 srcdoc，继承 IDE 的 CSP；宿主禁用内联脚本会使 HTML 演示页的按钮、分页等失效。改用独立的 myide-preview 文档源，仍在文件标签内预览，无需切到内置浏览器。

主进程为每次预览创建随机主机名和临时内容租约，加载编辑器当前正文，保留 DOCTYPE 与相对资源路径。项目内 CSS、图片、字体、JS、模块脚本和 fetch 按原目录解析。独立源无法读取 IDE 的 preload API；主界面 CSP 只新增 frame-src，不放宽其脚本策略。

资源仅限所选项目范围（文件在项目外时限所在目录），同时验证真实路径，拒绝目录遍历、盘符和符号链接越界。切换/关闭文件、宿主导航或销毁时释放租约；迟到的异步创建也会立即释放。该功能是静态 HTML 预览，不代替需要服务端路由/API 的开发服务器。

验证：

- HTML 服务单测 6 组：中文/空格/#/% 路径、未保存正文、资源 MIME、越界、符号链接、租约/所有者隔离及无效请求。
- 隐藏 Electron 生产窗口：内联与模块脚本、按钮交互、相对 CSS/SVG、fetch、标准文档模式、未保存预览及旧租约失效；检查实际截图。
- DOM 522 通过 / 0 失败；打包资源检查 84 通过 / 0 失败。

通用回归记录：npm test 在 Git 检查停止（60 通过 / 2 失败：worker 临时目录 EPERM、status 普通扫描与完整核验不一致）；通用 UI 检查 456 通过 / 13 失败 / 3 跳过，失败涉及 Git 过滤/日志/暂存、自动检测状态、H3 和 Mermaid 颜色。浏览器与 HTML 专项 6 组全部通过，不能将通用回归标记为全绿。
