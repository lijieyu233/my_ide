# Markdown 图片复制与缩放

## 使用

- 在实时预览中悬停图片，拖动右下角角点，按原比例调整显示宽度。松手后才修改 Markdown；Esc、指针取消或切换文件会取消拖动。
- 右键图片选择“复制图片”，复制原图像素到系统剪贴板，可粘贴进聊天或图像编辑器。复制不会写入文档。
- 右键选择“恢复默认大小”移除显式宽度；Ctrl+Z / Ctrl+Y 可撤销、重做尺寸变更。自动保存及普通保存仍由现有文档写入流程负责。
- 静态预览、分屏预览支持复制并显示已保存的宽度；只读预览不提供尺寸修改手柄。

## 格式与边界

使用 Obsidian 风格的宽度后缀，标准图片如 `![说明|360](<中文 图片.png> "原题")`，wiki 图片如 `![[图片.png|360]]`。保留原图片路径、标题、说明及文档换行符，不修改原图片文件。默认尺寸仍受正文列宽限制；显式宽度也不会撑破正文列。

此功能调整文档中的展示尺寸，不做裁剪、压缩或图片文件重采样。宽度范围24–8192；缺失图片不可复制或拖动。代码块和行内代码中的图片语法不作为图片操作。

拖动在本地 DOM 中预览，松手时检查编辑器身份、可编辑状态和原始图片语法范围，单次事务提交，保留撤销历史。组件销毁清理指针监听，不能把迟到事件写入另一文档。

复制通过主窗口限定的 `clip:copyImageAt` 调用 Chromium 原生复制，避免 Canvas 跨域限制；不以传入URL发起额外网络请求或任意文件读取。
