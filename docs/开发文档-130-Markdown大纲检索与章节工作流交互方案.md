## 1. 当前已有与本轮目标

大纲是独立工具窗口，已有层级树、箭头独立折叠、展开/收起全部、单击跳转、上下左右及Enter导航、章节/正文/标题复制、右键编辑器层级折叠。源码/实时预览使用CM跳行，预览/分屏尝试滚动到标题。Markdown正文已有实时预览、源码、预览和分屏，不能把这些算成本轮新增。

长文工作流仍需要：看清大纲属于哪个文件和版本；快速搜标题；知道当前读到哪一节；隐藏、折叠、定位不相互混淆；复制的是刚选择的原文范围；生成目录、整理章节有预览和撤销。先补语义、归属和焦点，再交付可见体验，不以增加按钮掩盖跳错章节。

## 4. 面板布局与状态

保留「大纲」名称、独立停靠方式和现有线性SVG；不再挂回项目树下方。窄栏默认由标题栏、文件归属行、搜索框、树列表组成。标题栏保留展开/收起及更多动作；其他新增项进入更多菜单，避免一排按钮挤掉名称。

文件归属行显示文件名，必要时附最短可辨路径；同名文件、项目外文件能直接区分。显示“当前文件”或“固定文件”的范围。首版跟随当前文档；固定某个文件大纲为后续能力，必须连同目标打开和版本核验交付，不能只有一个图钉。

| 状态 | 显示与可执行操作 |
|---|---|
| 未打开文件 | 打开Markdown的引导，无伪选择和无效层级操作 |
| 非Markdown | 说明当前文件类型不提供本大纲，不能继续显示前一文件标题 |
| 正在读取/解析 | 目标文件、进行中；若保留旧树则明确旧来源并暂停该树的跳转/复制 |
| 已完成 | 标题数量和当前范围，查询/定位/复制可用 |
| 解析未完整 | 已知标题可读，标记尚未解析完；不能提示“无标题”或永久删除未确认节点状态 |
| 完整文档无标题 | 无标题，可回编辑器；与搜索无匹配分离 |
| 查询无匹配 | 保留查询词、清空搜索入口；不改变正文和原折叠 |
| 读取/解析失败 | 原因、重试及可保留的最后可信版本；不把失败缓存成永久空树 |

菜单中的“展开/收起大纲”只影响导航树；“在编辑器中折叠到H…”影响正文显示。层级过滤的名称固定为“显示到H…”，只能过滤大纲，不能调用编辑器折叠服务。

## 5. 标题语义、检索与阅读

所有模式使用099的同源标题与章节范围，带文档身份、版本、完整度和稳定节点锚点。默认收录当前文档语法认定的Markdown标题，包括列表/引用中的标题，并标明容器归属；原始HTML标题和嵌入文件标题不并入当前文档主大纲。后续若提供隐藏容器标题的视图选项，只过滤展示，不改变定位、章节范围和链接索引。

大纲显示标题的纯文本，内联链接/代码/强调按文本理解，复制原文章节保留原标记。空标题显示“空标题 · 第N行”，重复标题附父链或行号，标题级别跳跃按最近更浅的实际祖先组织，不凭空生成会被复制的标题。

搜索只查标题文本及可选父链，不搜全文，不与105内容搜索重复命名。中文组合期间不触发Enter导航；查询大小写不敏感，按文档顺序展示，精确/前缀命中可有标识但不默认打乱章节顺序。正则和项目级标题搜索留独立后续需求。

首版采用保留祖先的过滤树：命中高亮，祖先作为上下文显示，必要的临时展开仅在查询期间生效。显示“匹配M / 当前已解析N”，部分解析时标明范围未完整。清空查询恢复查询前展开集合、焦点及滚动锚点。搜索结果中的展开/收起行为明确归查询视图，不能悄悄永久重写原树。

层级过滤可显示到H1～H6，仍可解释被隐藏的命中。不要同时静默应用搜索和层级过滤导致“明明存在却找不到”；提示范围并提供清除层级限制。平铺模式可列父链，列为P2，不要求首版同时实现两套组件。

## 6. 当前章节、定位与导航返回

新增当前章节标记：实时/源码按光标所属章节，预览按阅读位置，分屏按最后主动操作的编辑面。映射来自当前版本与渲染位置；图片/图表异步变高时重新核对阅读位置，不用标题序号猜测。正文开头尚无所属标题时显示“文档开头”。

当前位置标记、键盘焦点和用户选择是三件事。用户正在搜索或键盘浏览时，滚动正文只更新当前位置标记，不自动滚动侧栏夺走浏览位置。提供手动“定位当前章节”；自动跟随为可配置模式，切换文件才切相应状态。

点标题按身份跳目标。源码/实时模式定位标题源码并展开必要正文范围；预览定位当前文档的对应渲染标题；分屏保留当前模式，定位两面对应位置，输入焦点回最后编辑面。纯预览不为跳转偷偷创建可编辑文档。目标失效先重新核对并提示，不能跳到最后一个标题或另一个同名标题。

正文折叠中的目标只展开必要范围，不全篇展开；导航后短暂提示目标，可关闭动效。展开动作不修改正文、不打断撤销历史。隐藏大纲树中的当前章节手动定位时临时展开祖先，用户能恢复原折叠。

跳转进入105的位置历史，用户可返回跳转前文件、模式和位置。连点同一目标不无限堆历史；文档重命名/迁移沿112身份协调，目标删除时说明失效，不以旧行号静默定位其他内容。章节面包屑为P2，必须复用同一索引与返回模型。

## 7. 键盘、焦点与状态恢复

树提供明确Tab入口及可见焦点；方向键仅在树有焦点时处理。首次进入选择/聚焦首个有效可见节点，刷新后原节点失效则转相邻或父级。没有选中时左右键不抛异常、不吞其他控件按键。搜索框与上下文菜单各有独立键位边界，禁用全局document接管。

| 按键/动作 | 预期 |
|---|---|
| ↑↓、Home/End | 在当前可见顺序移动焦点，滚动保证节点可见 |
| → / ← | 展开或进入子级、收起或回父级；隐藏/过滤节点遵循当前树 |
| Enter | 导航当前有效目标，组合输入/解析过期时不执行 |
| 搜索框↓ | 转到首个有效匹配，保留查询；无匹配继续留输入 |
| Escape | 先关闭菜单或搜索状态，再回原入口，不顺手切模式/清空其他面板 |
| Shift+F10 / 菜单键 | 打开当前焦点节点菜单；关闭后返回同节点 |
| Tab / Shift+Tab | 可离开大纲，不形成焦点陷阱 |

tree/treeitem、层级、展开/选择和忙状态可读；搜索结果变化通知适度，不每次输入朗读整篇。真实读屏、OS焦点和输入法必须另验，12项JSDOM观察仅验证逻辑调用。

展开、查询、显示层级、当前位置和滚动锚点按项目/文档分别保存；“跟随当前文件”属于面板偏好，“正文折叠”属于文档EditorState，不能混存。跨文件不共用line|text键，全文未解析完不清记录。编辑映射、同名歧义及迁移沿099/112；重启恢复沿128，不声称现有会话已经保存所有这些状态。

## 8. 章节复制、链接与目录生成

保留三个复制名字和含义：“复制本章节（含子章节）”“只复制本节正文”“复制标题文本”。菜单执行绑定刚打开菜单时的文档与版本；切文件/编辑导致范围失效时重新确认，不用A的标题行号切B的正文。Setext正文不得包含下划线行，容器、同名和文末范围与索引一致。

章节复制按编辑缓冲原文，而非过期磁盘文件或预览HTML；仅去除范围边缘空白的现有行为在提示/验收中明确。剪贴板写入完成后再报成功，失败支持重试；这一失败路径为需求，本轮内存桥不证明系统写入成功。

新增“复制章节链接”：提供当前文档内部链接与项目相对文件链接，说明使用Markdown还是wiki格式。锚点生成与预览/导航/补全同源，中文、标点、重复标题、大小写和空标题有明确规则；预览内节点ID与导出的外部URL不能混为一谈。无法生成可稳定定位的链接则停用并解释。项目外路径或尚未保存文档不得伪造项目相对链接。

新增“生成目录”首包以只读预览及复制Markdown为主：选择层级、是否包含当前一级标题、显示预计条目/链接；目录结构使用实际层级，不凭空造正文标题。插入到编辑器另分包，需要可写文档、当前版本/选区确认和单次可撤销交易。纯预览、只读、未解析完整或无法生成锚点时不写入。

“更新生成目录”只替换明确标记且能校验来源的范围，显示旧→新差异；没有标记、多份标记、范围被手写改动或嵌套损坏时让用户选择/确认，不能覆盖整篇或模糊匹配一个手工列表。生成目录自身不应被重复当标题加入。目录更新保留周围原文和既有编码/行尾合同，保存仍经过当前文档保存服务。

## 9. 章节重排与结构整理（P2独立需求）

Obsidian公开提供拖动章节调整，MyIDE可借鉴但必须先有可信章节范围。首版仅提出需求，不通过DOM拖动来直接剪切正文。

重排前预览源章节、包含子章节/正文的完整范围、目标位置以及是否改变层级。默认移动整节且不改标题级别；升/降级为另一个显式动作。拖到自身/后代无效，同一位置无操作，跨文件先列为不支持。容器标题是否可移动取决于语义范围，首包可明确禁用并解释，不能移出一半列表或引用。

确认时核对文档与内容版本，移动应用为单次CM交易，可Undo/Redo；不直接写盘、不打断dirty缓冲、不以重新载入文件绕过撤销。外部磁盘变化仍由111保存冲突保护。重命名标题和升降级导致的引用变化显示影响清单，批量改其他文件需独立事务/预览，不能假装“已自动修复全部链接”。

键盘提供移动到上一/下一同级位置的等效操作，不把拖动当唯一入口。目标指示显示章节名及之前/之后，不只一条模糊横线。长文及自动滚动、折叠父级、搜索过滤期间的目标行为补验；不把几行内存夹具当可靠长文重排。
