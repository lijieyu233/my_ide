# Harness 侧栏原生执行与 MyIDE 工具桥

## 入口与界面

AI 助手仍停靠右侧，执行模式选择 DeepSeek Harness。主编辑区、文件标签、项目树和当前启动/远程/浏览器页面继续可操作。已移除整页 Harness Web 视图、专用活动栏入口和独立启动页面。

在侧栏打开时异步连接本机 Harness，取回原生模型/推理选项，不消耗模型调用。普通助手的地址/模型/API Key 不替换 Harness 的配置。模式分别保存历史；复制已发消息只放回输入框，修改后追加，避免将本地删除气泡伪装成原生历史回退。

## 原生引擎

调用安装的 dsh.cmd 对应运行时，使用官方 --profile acp。默认继承用户 DSH_HOME 或 ~/.dsh；使用安装提供的 ACP profile、原生模型提供方、凭据、工具、Skills 和插件。没有 MyIDE 禁用列表、模型桥 patch、persona 替换、8/24 轮 Agent 限制或任意任务运行时限。

同一 MyIDE 会话、项目与页面绑定持久原生会话。新请求只送最新用户输入及当前界面观察信息、明确附带的文件/选区/贴图；Harness 自己维护历史、工具循环与上下文压缩。MyIDE userData/dsh-sessions.json 保存原生会话 ID 映射，进程重启通过 session/resume 恢复，不回放旧工具或把历史重新拼成请求；恢复失败不偷偷新建会话。停止取消当前轮并清除待批准工具，正常取消保留连接与会话。

关闭 MyIDE 时给自有 ACP 进程 stdin EOF，让官方 profile 停止并刷新持久记录；2 秒未退出才终止这个自有进程。未使用 Harness 时无启动成本。不得终止用户另开的 DSH Desktop 或其他进程。

## MyIDE 集成

每个原生会话挂载认证的 loopback MCP 服务，按会话随机 header 绑定。暴露 ide_state 和已有 MyIDE 文件、启动面板、SSH、浏览器工具。ide_state 读取当前页面，项目页可读取未保存正文；其他独立页面不返回后台编辑器。

MCP 调用回到当前侧栏请求，仍走 MyIDE 的工具契约、确认、执行账本和取消校验；原生工具状态/输出/思考/上下文占用通过 ACP 更新显示。MyIDE MCP 状态不重复绘制原生工具行。原生权限请求在侧栏显示工具与参数，只允许单次允许/拒绝；不自动批准、不提供永久授权。原生工具遵循 Harness 自身策略，MyIDE 工具遵循本应用策略，两者不能互相冒充授权。

切离项目停止在途 DSH 请求。新页面绑定独立原生会话和空白工作目录，不发送旧项目正文、文件工具历史或规则；返回项目后再恢复其原生会话。普通助手现有的页面上下文策略保持。

## 接口边界

使用本机 0.2.0-rc.2 提供的官方 ACP：initialize、session/new、session/resume、session/set_config_option、session/prompt、session/cancel 和权限响应。原生文件/Shell/Skills/子代理/工作流的可用项由实际 profile 和用户插件提供，MyIDE 不删减。

官方 ACP 是自动化接口，不等同于桌面 UI：没有桌面预设切换、session/load、历史回退/fork、斜杠命令 UI、计划卡片或桌面终端视图；插件配置仍由 Harness 原生配置管理。此处不声称把这些未公开的 UI 协议完整搬进侧栏。ACP 发布提交后的语义消息，思考/工具状态可以展示，但不承诺每个模型 token 的原始增量回放。

## 验证

宿主协议测试包含原样 profile、原生工具状态、续聊只追加、MCP 返回真实结果、旧归属拒绝、单次权限、取消后保留会话、页面工作区隔离、跨重启恢复、模型预取/发送并发及贴图。AI 面板测试覆盖模式切换、迟到工具拒绝、离开项目取消、原生权限按钮失效、两种历史隔离与复制继续。

真实隐藏 MyIDE + 本机 DSH 使用隔离 home 和本地确定性模型夹具：验证未保存正文、原生 read 工具读取实际文件、持久续聊、切页不发送后台文件、MCP 读取启动配置、原生模型预取零模型请求。未读用户凭据，未调用付费模型。截图确认右侧停靠且主编辑区可用。

本轮结果：语法 89 文件、DOM 523 项、打包检查 87 项、宿主协议 8 组、AI 面板 45 项、真实 DSH 侧栏 4 组通过；AI 工具/权限/启动/SSH/浏览器全套通过。npm test 在 Git 阶段停止（60 通过 / 2 失败：worker 临时目录 EPERM、merge 夹具被判脏）；通用 UI 为 465 通过 / 4 失败 / 3 跳过，失败在 Git hunk 分区、H3 颜色和 Mermaid 底色。未将通用回归标为全通过。
