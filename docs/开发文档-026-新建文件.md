# 开发文档 026 —— 新建文件/文件夹

> 状态：已完成 · 编辑器基础能力补全

## 一、需求

目前只能打开/编辑已有文件，无法新建（笔记、草稿、新模块都要靠外部）。
目标：**文件树右键「新建文件 / 新建文件夹」**，建在选中目录（或文件所在目录/根）。

## 二、设计

- 右键菜单两项：✨ 新建文件 / 📁 新建文件夹 → 名称输入弹窗
- 主进程 `fs:mkdir`（recursive）；新建文件复用 fs:writeFile
- 完成后失效缓存 + 刷新树 + Git 刷新
- 位置：选中目录 → 内；选中文件 → 所在目录；无选中 → 根

### 结构
```
main.js        fs:mkdir IPC
preload.js     桥接
tree.js        右键菜单两项 + 创建逻辑
```

## 三、测试计划

1. 右键 → 新建文件（选中目录内）→ fake fs 出现 + 树刷新
2. 新建文件夹 → 目录出现
3. 名称冲突 → 提示
