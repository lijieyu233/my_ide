# 内置浏览器全屏

地址栏右侧增加线性 SVG 全屏按钮。点击或按 F11 进入浏览器全屏；保留导航、地址栏和退出按钮，临时隐藏 IDE 顶栏、侧栏、AI 面板、状态栏及玩宠。再次点击、F11 或 Esc 退出；切换工具或关闭浏览器自动退出。

全屏调用原生窗口显示模式，并把浏览器面板固定到整窗。原生网页视图继续使用 CSS 像素到 DIP 的边界映射，尺寸变化后重新上报。退出时恢复原先的窗口全屏状态，不改变用户侧栏、AI 开关和持久化布局；普通最大化状态由 Electron 原生全屏还原机制保持。

网页聚焦时 F11/Esc 由真实 WebContents 的 before-input-event 回调转发给宿主；地址栏或工具栏聚焦时由渲染层处理。弹窗和菜单可见时不抢其 Esc；建议列表打开时 Esc 优先关闭建议。宿主重新加载或系统退出原生全屏后也同步清理浏览器全屏状态。

- `npm run test:browser`：5 项通过，覆盖原生全屏切换/还原、原先已全屏、系统退出、原生失败及参数校验。
- `npm run check:browser`：3 组真实生产窗口和 IPC 验证通过，覆盖建议按需展开、视图尺寸随整窗布局变化、按钮/F11/Esc、网页快捷键转发、切页还原、持久布局不变；已查看截图。
- `npm run check:js`：85 个文件通过；DOM 520 项通过；生产包资源 83 项通过。`--check-ui` 为 457 通过 / 8 失败 / 3 项 headless 跳过，失败仍在既有 Git、H3 亮度及 Mermaid 底色断言。
- 自检始终隐藏，不切换桌面原生全屏或显示窗口。原生接口调用的状态还原使用独立窗口适配器测试；网页快捷键回调在隐藏窗口中送入真实 WebContents 事件验证，不能据此声称已做 OS 键盘焦点测试。
- DOM 回归、语法检查和生产包资源校验另行运行；全量测试存在既有 Git worker EPERM，不能算全部通过。
