# 阅读笔记、摘录与章节总结

更新日期：2026-10-22。

## 使用流程

工具条的“摘录”和“笔记”打开各自的记录列表，不再共用一个新建表单：

- **摘录**：选中 TXT/EPUB 正文，浮动工具条提供“保存摘录 / 添加笔记 / 复制”，右键选区也可调出。保存摘录直接落盘并高亮正文，不强制展开编辑面板；“添加笔记”打开引用原文的笔记编辑，输入正文后才保存，空白关闭不新增摘录。重复保存同一版本、同一位置的选文复用原记录。
- **笔记**：统一查看原文笔记、独立笔记与章节总结；原文笔记保留原文和来源，摘录列表仍可查看同一条记录，不重复存储。也可不选原文直接新建笔记或“章节总结”；不用先选原文。新建时标题与正文为空，未输入就关闭不会生成记录。
- 列表支持分类数量、关键词搜索、查看原文/正文摘要和“回到原文”。点记录进入编辑，再“返回列表”；Esc 先退出编辑，再关闭面板并返回入口焦点。
- 摘录编辑区显示只读原文和可选笔记；独立笔记编辑区显示类型、可选标题和正文。关闭面板、切换分类或标签前提交输入，约400ms自动保存。
- **删除笔记**需确认，只清除这条摘录的笔记；**删除摘录**需确认，删除该原文摘录与其笔记；删除独立笔记不会删除摘录。
- 新摘录保存起止段落和字符偏移，正文高亮及返回来源使用实际范围，重复文字不会都被标亮。原书版本变化后保留记录，但不显示旧高亮，禁用失效来源跳转。旧版没有精确范围的记录只在单段中原文唯一匹配时高亮，避免误标。
- CBZ 可写独立笔记，图片不提供文字摘录。宽阅读区并排显示记录，窄区覆盖正文并保留关闭按钮；紧凑工具条通过“更多”访问目录、书签等操作。阅读界面不再提供“返回编辑”入口。

笔记保存到所属工作区的 `.myide/reader/books/<书籍ID>/notes.json`，与书架的稳定书籍 ID 对应。移动整个工作区后可继续读取。工作区外的临时书籍仍可阅读；需要将书放入工作区后才能记笔记。

关闭笔记面板、切换标签、切换项目和关闭窗口都会提交尚在防抖中的输入；不会把旧书的输入保存到新项目。面板草稿由书籍模型持有，返回原书可继续编辑。

## 保存失败与冲突

写入沿用磁盘版本校验和原子替换，失败不截断原文件：

- 权限或磁盘问题：面板保留输入和错误，排除问题后点「重试保存」。
- 外部程序已改动笔记：拒绝覆盖磁盘内容。先点「复制」保留本地修改，再点「重新载入」，确认后才用磁盘内容替换当前笔记。
- 坏 JSON、未知格式或超限文件：读取失败，不当作空文件重建，也不覆盖。
- 有未保存的笔记时，项目切换与正常关闭会等待保存成功。

每本书最多200条笔记；标题120字符、正文10000字符、摘录4000字符，笔记文件最多4MiB。正文及摘录按纯文本显示，不把书内或AI返回的HTML作为界面执行。

## AI 接口

接口仅作用于当前已打开且属于工作区的阅读书籍，不接受任意路径：

| 工具 | 参数与行为 |
| --- | --- |
| `reader_notes` | offset / limit 分页读取，每批最多10条；kind=all/excerpt/note/summary 按类过滤，note 同时包含原文笔记和独立笔记；原文笔记仍返回 excerpt 类型及原 ID，query 按标题/原文/笔记/章节搜索，并返回 reader 模块快照 |
| `reader_note_write` | operation=save/remove；note 不传时新建，传入当前书籍的笔记 ID 时仅更新提供的字段；kind=excerpt/note/summary，title/body/quote 可选；excerpt 必须有非空 quote |

写操作需要最新快照并沿用批准、幂等和过期检查。用户后来输入、换书、换项目都会使旧操作失效。未知笔记 ID 不会被当作新建；AI 写入成功前等待真实文件保存。

例如用户可以在 AI 助手中提出：

> 总结当前章节，并保存成这本书的章节总结，保留已有笔记。

助手先用 `reader_read` 读取当前章节，再用 `reader_notes` 取得笔记及快照，最后用 `reader_note_write` 新建 summary。超过正文分页预算时需继续分页，不能把局部内容当成全章。本版提供这套读写接口和记录面板，尚无一键整书分析任务或自动全书总结按钮。

旧版 kind=note 且带 quote 的记录按摘录读取，不丢标题、想法或来源，后续保存使用明确的 excerpt 类型。沿用 schema=1，新版兼容读取旧记录；可选 source.range 包含 startBlock/startOffset/endBlock/endOffset。新增笔记的来源固定为当前章节与位置；更新已有笔记时保留原来源、创建时间和未提供的字段。原书只读，笔记文件不会写回或覆盖原书。

## 阅读外观

“阅读设置”支持默认衬线、黑体、宋体、楷体、仿宋；使用系统字体，缺失时使用对应系统后备字体，不下载字体文件。字号12–36px、行距1.2–2.6倍、列宽320–1400px用滑杆即时预览，也可按加减按钮微调；纸张/深色/跟随主题直接点选。连续调整合并保存，工作区偏好关闭重开可恢复；“恢复默认”一键重置。漫画只显示背景和翻页方向，避免展示不生效的文字排版项。

`reader_control(operation="preferences")` 新增 fontFamily=serif/sans/song/kai/fang，沿用快照和授权；`reader_state.preferences` 返回当前字体。设置修改保持阅读位置；点击外部或Esc关闭弹层。

## 阅读右键菜单（2026-10-22）

阅读工具条、“更多”以及隐藏的编辑动作栏均移除“返回编辑”按钮。

- 正文或留白：上一屏/下一屏、添加书签、新建笔记、查看摘录和笔记、阅读设置与阅读目录；第一屏和末屏对应翻页项禁用。
- 选中文本：复制选中文字、保存摘录、添加笔记。菜单保存打开时的选文与来源，不依赖点击菜单后还存在的浏览器选区；超过4000字仍可复制，摘录/笔记入口禁用。工作区外的临时阅读可复制，工作区记录项禁用。
- 已有高亮或记录卡片：复制、编辑想法/笔记、回到原文、确认删除对应记录。删除保持版本和修订检查，取消不修改记录。
- 输入框保留原生右键，避免阻断文本复制粘贴。

菜单支持上下方向键、Home/End、Enter/空格执行，Esc/Tab关闭并恢复焦点；点外部、滚动、窗口失焦/缩放、切章节或切文档均关闭。菜单操作绑定原标签、会话、版本和章节，旧回调不得作用到后来打开的书籍。使用窗口浮层并限制位置和高度，不受窄阅读区裁剪，不被右侧AI面板遮挡。

`npm run check:reader-context` 使用隔离profile的隐藏Electron窗口，实际右键/点击/键盘验证菜单动作及真实IPC落盘；剪贴板IPC在测试进程内截获，不改用户剪贴板。专项还检查菜单顶层命中、超长选文限制、切章旧按钮失效、删除确认、输入框原生右键及无原书写入。

## 2026-10-22 统一笔记操作

- 取消“想法”这一层独立操作名称，统一使用“添加笔记 / 编辑笔记 / 删除笔记”。
- 选文保存摘录立即收藏；添加笔记先打开带原文的空草稿，正文未输入就关闭不会创建记录。已有同位置摘录复用原 ID。
- 笔记列表可找到原文批注，显示笔记正文并支持回到原文；摘录列表展示原文及“已有笔记”提示，两处操作同一条记录。
- 从笔记列表删除附属笔记只清除正文，保留摘录。删除摘录仍有独立确认，说明会一并删除附属笔记。原书和旧记录无需迁移。

AI 读取 `kind=note` 可找到原文笔记，返回原摘录 ID 与 excerpt 类型。清除该笔记使用 `reader_note_write` 的 save 操作和空 body；remove 仍表示删除整个记录，不能用来只清除批注。
