# 阅读笔记、摘录与章节总结

更新日期：2026-10-22。

## 使用

- 阅读工作区内的 TXT、EPUB 或 CBZ，点工具条「笔记」打开面板。
- 点「新建笔记」后输入标题和正文，约400ms后自动保存。也可以把类型设为「章节总结」。
- 选中小说正文后点「摘录」，保存选中的原文、书籍版本、章节和起始段落；可以继续写自己的想法。
- 点「返回来源」跳回记录时的位置。原书版本变化后保留笔记和摘录，但禁用旧位置跳转，避免跳到错误正文。
- 面板支持切换笔记、复制和确认删除。未输入的空白新建表单不会生成文件。

笔记保存到所属工作区的 `.myide/reader/books/<书籍ID>/notes.json`，与书架的稳定书籍 ID 对应。移动整个工作区后可继续读取。工作区外的临时书籍仍可阅读；需要将书放入工作区后才能记笔记。

关闭笔记面板、切换标签、切换项目和关闭窗口都会提交尚在防抖中的输入；不会把旧书的输入保存到新项目。面板草稿由书籍模型持有，返回原书可继续编辑。

## 保存失败与冲突

写入沿用磁盘版本校验和原子替换，失败不截断原文件：

- 权限或磁盘问题：面板保留输入和错误，排除问题后点「重试保存」。
- 外部程序已改动笔记：拒绝覆盖磁盘内容。先点「复制笔记」保留本地修改，再点「重新载入」，确认后才用磁盘内容替换当前笔记。
- 坏 JSON、未知格式或超限文件：读取失败，不当作空文件重建，也不覆盖。
- 有未保存的笔记时，项目切换与正常关闭会等待保存成功。

每本书最多200条笔记；标题120字符、正文10000字符、摘录4000字符，笔记文件最多4MiB。正文及摘录按纯文本显示，不把书内或AI返回的HTML作为界面执行。

## AI 接口

接口仅作用于当前已打开且属于工作区的阅读书籍，不接受任意路径：

| 工具 | 参数与行为 |
| --- | --- |
| `reader_notes` | offset / limit 分页读取笔记、摘录与总结，每批最多10条，并返回 reader 模块快照 |
| `reader_note_write` | operation=save/remove；note 不传时新建，传入当前书籍的笔记 ID 时仅更新提供的字段；kind=note/summary，title/body/quote 可选 |

写操作需要最新快照并沿用批准、幂等和过期检查。用户后来输入、换书、换项目都会使旧操作失效。未知笔记 ID 不会被当作新建；AI 写入成功前等待真实文件保存。

例如用户可以在 AI 助手中提出：

> 总结当前章节，并保存成这本书的章节总结，保留已有笔记。

助手先用 `reader_read` 读取当前章节，再用 `reader_notes` 取得笔记及快照，最后用 `reader_note_write` 新建 summary。超过正文分页预算时需继续分页，不能把局部内容当成全章。本版提供这套读写接口和记录面板，尚无一键整书分析任务或自动全书总结按钮。

新增笔记的来源固定为当前章节与位置；更新已有笔记时保留原来源、创建时间和未提供的字段。原书只读，笔记文件不会写回或覆盖原书。

## 验证

- `npm run test:reader`：包含笔记后端与jsdom交互，覆盖磁盘版本、错误文件、字数限制、项目隔离、输入保存失败和重试、外部冲突、工作区搬迁与异步项目切换。
- `npm run check:reader-notes`：隔离profile的隐藏Electron窗口，走真实选择范围、按钮、IPC、AI审批/过期快照、章节总结部分更新、项目往返、窄布局与关闭落盘。
- `npm run test:package`：归档必须包含笔记后端与前端资源，遗漏会拒绝。
