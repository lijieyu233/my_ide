# Markdown 列表 Shift+Enter 续行对齐

问题：嵌套待办末尾按 Shift+Enter 后，新行没有列表结构缩进，正文退回左边。仅保留源码空格仍不足以解决实时预览，因为嵌套缩进和勾选框已经被替换为比例字体下的视觉组件。

修复以当前语法树的 ListItem 为依据：Shift+Enter 插入 Markdown 硬换行和列表结构缩进，保留同一条列表项，不重复勾选框或增加编号。普通正文、围栏代码和表格单元格继续使用原有行为；只读编辑器不执行此命令。

实时预览将续行缩进显示为原列表层级宽度及隐形标记占位，复用首行勾选框、圆点和编号的尺寸，全部使用 em。最外层自带前导空格时保留其实际宽度。解析器尚未将空白续行纳入段落时也补齐占位，并避免将这行按空段的半字号渲染，确保输入前的光标和输入后的正文起点一致。
