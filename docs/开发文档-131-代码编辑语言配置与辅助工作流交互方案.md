## 1. 当前已有与目标

CodeEditor使用仓库CM6，已有行号、活动行、语法高亮、历史撤销、括号匹配/自动闭合、输入缩进、语法折叠、查找替换、保存、Git Blame gutter及AI行内建议。自定义补全源供SQL等调用方使用；不能由此宣称所有代码文件已经有语言服务、跨文件补全、诊断或重构。

Viewer保存/恢复EditorState，代码文件变更连接dirty和自动保存；110已保留格式与行尾，111有磁盘冲突保护，112协调路径迁移。新增体验必须经过这些服务，不能旁路重写磁盘。矩形选择扩展存在，但多选区是否有效须看实际State配置，本轮观察到默认只保留一个范围。

目标是让用户清楚当前语言/缩进和可用能力，稳定编辑与辅助结果的对象，再增加可发现的编辑动作、格式化预览与语言服务。能力不支持、请求失败和真实“没有结果”分别显示，不把颜色高亮包装成完整IDE分析。

## 4. 语言与能力状态

状态栏提供语言和缩进入口；窄窗口只保留简短标签，菜单展示检测来源、文件关联及当前文档覆盖。编码/行尾继续使用110已有入口，不新增第二份格式设置。语言切换影响编辑视图与辅助提供者，不自动转换正文或扩展名。

语言自动检测顺序和作用域可解释：当前文档临时选择、项目文件关联、用户文件关联、内置扩展映射，必要时再考虑shebang。未知语言明确“纯文本”，仍可编辑，不伪造解析/诊断成功。切关联需说明作用于哪些文件，已打开文档可预览受影响列表，不能无声全工作区重配。

提供能力清单：高亮、括号/缩进、语法折叠、补全、文档符号、定义/引用、诊断、格式化、重构分别由谁提供及是否就绪。包内支持一种基础语言不等于完整支持其所有方言：JS/JSX、TS/TSX要区分；SCSS/LESS、Vue/Svelte、XML/SVG等不得只靠扩展名展示“完整支持”。方言/混合语言可先列部分支持，但仍需准确交付对应配置，不用降为纯文本规避本轮JSX/TSX缺口。

| 状态 | 用户看到什么 |
|---|---|
| 可用 | 语言、能力与规则来源；可执行对应动作 |
| 部分支持 | 高亮可用但某些分析缺失，说明具体能力 |
| 初始化/分析中 | 对应语言/文件，旧结果若保留标旧版本且限制写入动作 |
| 提供者缺失/未配置 | 动作不可用、原因和配置入口，不提示“没有定义/没有问题” |
| 失败 | 失败原因、重试/日志入口，保留可用文本编辑 |
| 暂停/大文件限制 | 明确暂停哪些辅助，可手动启用/调整范围；编辑和保存结果仍可信 |

恢复EditorState时保留正文、历史、选区、折叠等文档数据，实例专属回调、动态Compartment和提供者绑定属于当前实例生命周期。重新挂载后不能执行销毁view的请求或旧onChange/onSave，也不能为重新绑定丢掉Undo历史。切模式/关闭/重命名/切项目各自核对文档身份。

## 5. 缩进、显示与基础编辑动作

缩进菜单显示Tab/空格、宽度与来源；区分“后续输入使用”与“转换现有缩进”。检测失败采用可见默认，混合缩进提示范围，不自动整篇修复。用户/项目规则沿116，若读取.editorconfig则说明已支持的字段及生效层级；不能宣称支持整个规范却只读indent_size。

转换只作用于确认的文档/选区范围，先展示预计改动；Tab视觉宽度与实际字符分开。字符串、模板、Python多行文本等内容不能被粗暴全局替换；语言提供者不支持安全转换时说明边界。应用为单次可撤销交易，编码/未触及行尾沿110保留，保存仍走101/111。

新增软换行、空白字符、缩进参考线和列标尺为显示选项，不能插入真实换行/空格。切软换行保留源码行/列定位、选区与滚动锚点；行号仍表示逻辑行，长行横向阅读与软换行可互换。多主题/缩放验证参考线、选区与高亮可读，不只测试class存在。

编辑菜单或105命令面板发现：删除/复制/移动行、注释切换、扩大/缩小选择、选择下一相同文本、多个光标、矩形选择、折叠/展开。先复用仓库Commands/语言能力，再为未注册动作补入口，不重复实现文本操作算法。无语言注释规则时动作停用并解释，不把JS注释格式套JSON或Python。

多选区使用同一文档版本的范围模型，重叠去重，主光标明确；编辑/粘贴/缩进/撤销覆盖每个选择。粘贴多行是每光标复制全部文本还是逐行分配需明确模式，不能按不可见启发式改变内容。Escape退到主选区，不清其他面板。矩形选择、中文宽字/Tab/软换行的几何另验，不以R4状态修正宣布整个多光标工作流完成。

## 6. AI行内建议与普通补全

普通补全列表、片段占位跳转、AI行内建议和Tab缩进分别有焦点/优先级。优先处理当前正在输入/组合输入的状态及可见候选列表；AI接受只在有有效建议且接受键归属明确时执行；否则Tab按当前缩进或焦点规则处理。沿116提供有效键位，不在设置显示改过但CM仍硬编码。

行内建议请求绑定文档/实例、内容版本、光标/选区、项目与模型配置版本。迟到响应及接受时再次核对；只比较同一个数字光标位置不足。编辑、切标签、关闭、销毁、切配置、禁用、进入只读或组合输入时撤销该请求的显示资格。取消是否真正停止后端请求需看服务能力，UI不能只消失动画就宣称网络已停止。

每个编辑器保留最新有效触发，有界并发与取消/覆盖策略；多个CodeEditor实例不能共用busy无声吞请求。后台或已销毁实例不继续发起；SQL等嵌入编辑器是否允许AI由调用方能力/用户配置决定，不能因为AiPanel开着就默认所有文本场景都自动发送。

状态显示为轻量“请求中/有建议/暂停/失败”，不每次失败弹toast。提供手动触发、接受、拒绝、本文件暂停与配置入口；接受为一次可撤销编辑，不直接保存。多光标暂不支持建议时明确停用，但普通多选编辑继续可用。建议为普通文本，保留实际缩进和范围；长度/行数限制可解释，不能把模型解释文字未经核对自动插入。

来源、发送范围与模型配置沿118；本轮夹具只验证延迟与对象归属，不验证外部服务质量、费用或敏感信息过滤。新增开关需有真实配置代次，避免R6禁用后仍出现旧建议。

## 7. 格式化预览与语言服务（独立新增包）

格式化支持“当前文件”与提供者明确支持的“选区”范围。菜单列语言、提供者、配置来源和作用范围；多个提供者让用户选默认，不随机调用。缺工具、版本不支持、超时、输出错误分别处理。外部工具运行与参数沿启动服务的可定位进程合同，不把仓库命令自动作为可信格式化器执行。

首包手动触发并展示差异、改动数量、原/新版本；用户确认后把完整、已验证范围应用到编辑缓冲。响应绑定原文版本，期间继续编辑则重新生成预览或说明过期，不覆盖新输入。撤销一次恢复应用前内容，dirty和后续保存沿101/110/111。不先做默认格式化保存，避免一次新功能改变所有现有保存路径。

诊断提供常驻问题列表：严重级别、消息、路径/位置、提供者和版本；编辑器标记与列表同源。旧诊断标记过期，失败不清成“0问题”，可筛当前文件/项目与级别。鼠标/键盘定位进入105历史，目标版本不匹配时映射或重新分析。语法树错误节点不能直接等同完整语言诊断，服务器版本与语言能力需独立验收。

语言服务分阶段明确首批语言和提供者：补全/悬浮信息/文档符号、定义/引用，再重命名/快速修复。没有服务时继续可用高亮编辑，不虚构候选。跨文件结果携带项目/路径/版本，迟到结果不能串项目；多目标可阅读列表而非静默跳第一项。130的大纲是Markdown专项，代码符号视图复用导航组件但由各语言提供者给语义，不用Markdown标题正则扫描代码。

快速修复/重命名/导入整理等写动作先预览逐文件变更，核对打开缓冲与磁盘版本，并有结果/部分失败记录。AI建议和确定性语言操作分开说明来源；跨文件撤销需要事务合同，不承诺把每个文件各自Undo等同整批原子撤销。首个格式化包只改当前文档，不能因此关闭全部跨文件编辑需求。
