# 左侧功能栏排序与跳转快捷键

2026-10-22。

## 使用方式

- 拖动左侧功能图标到另一个图标的上半或下半处，插入线表示松手后的落点；上方工具和底部日志之间可相互移动。收起侧栏的箭头固定在顶部。
- 拖动本身不切换面板、不重建功能实例。Esc、失焦或拖出后取消，不改变顺序。松手后的点击不会误触打开功能。
- 右键功能图标 → 设置跳转快捷键，直接定位该动作并等待按键。也可聚焦图标后按 Shift+F10 打开菜单。
- 使用 Ctrl / Alt 组合或 F1–F12 功能键，Esc 取消。本版右键菜单只提供快捷键设置；恢复默认和取消绑定在现有设置页内完成。
- 冲突时先确认，取消保留双方键位；确认只转移冲突的组合键，保留其他按键。保存失败时提示错误，原有效键位保留。
- 跳转键始终显示目标工具；重复按下不会收起。点击图标仍保持原来的打开 / 收起行为。
- 编辑器、终端输入区、地址栏及内置网页均可跳转，输入法组合输入和上层弹窗不触发跳转。单字母不允许绑定为跳转键。
- 图标悬停提示同步显示当前有效键位。原先没有默认键的书架、远程服务器、启动面板也能设置。

## 保存与实现

顺序保存在全局本地设置 `myide-tool-strip-order`，包含分组间隔标记；不同项目共用顺序，重启恢复。未知/重复项被过滤，新版本增加的图标按默认位置补齐。Git 日志默认仍在底部，用户可自行拖动。保存写入及读回确认成功后才移动节点。

快捷键沿用 `Shortcuts` 注册表和 `myide-keys`，由现有设置镜像与导出流程保存。右键设置复用 `Settings.editShortcut`，没有第二份按键配置。浏览器原生视图通过 `browser:tool-keys` 接收宿主主框架登记的工具白名单与有效键位，使用 `browser:tool-shortcut` 回传动作 ID，宿主再经过原动作可用性检查。网页不能登记任意动作。

实现文件：`renderer/tool-strip.js`、`renderer/shortcuts.js`、`renderer/settings.js`、`src/main/browser/tool-shortcuts.js`。本版只支持同一左侧功能栏内部排序。
