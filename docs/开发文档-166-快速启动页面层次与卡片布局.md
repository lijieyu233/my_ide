# 快速启动页面层次与卡片布局

顶部原先把搜索和七个操作按钮挤在同一行。现在搜索与添加入口为主操作，分组、管理、导入导出、快捷键和重载为独立辅助操作行，返回编辑器配箭头。入口数量使用弱边框标签。

分组使用同源主题色、统一边框与对齐方式；入口改为横向卡片，图标、名称、类型和快捷键各有位置。空分组使用线性文件夹图标和简短引导，添加入口按钮统一图标与间距。管理、拖动、系统打开与权限等执行逻辑保持原样。

按主区宽度适配，而不是按整个窗口判断：小于 520px 时收紧内边距与标题高度，添加入口使用有明确可访问名称和提示的加号按钮，把空间留给搜索。分组在窄主区排列为一列。
