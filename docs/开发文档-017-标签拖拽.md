# 开发文档 017 —— 标签拖拽排序

> 状态：已完成 · 对应 ROADMAP P2

## 一、需求

标签顺序固定，想按工作流排列只能关闭重开。
目标：**鼠标拖拽标签调整顺序**（PyCharm/浏览器习惯）。

## 二、设计

- **手动拖拽**（mousedown/mousemove/mouseup，不用 HTML5 DnD——jsdom 难测且行为可控）
- 交互：
  - mousedown 记录起始位置；移动 >5px 进入拖拽（标签半透明）
  - 拖拽中按鼠标 X 与各标签中心实时插入（DOM 顺序即最终顺序）
  - mouseup：按 DOM 顺序重建 tabs 数组 → 重渲染（自动触发会话保存）
  - 未移动（<5px）→ 视为普通点击（activate 正常）
- 标签元素加 `data-path` 供排序回写

### 结构
```
viewer.js   dragState + mousedown/mousemove/mouseup + finishDrag
styles.css  .tab.dragging
```

## 三、测试计划

1. mock 标签矩形 → 拖拽 tab0 到 tab1 后 → 顺序变为 [1,0,2]
2. 未移动的按下/抬起 → 顺序不变，点击正常
3. 拖拽后会话保存（顺序持久化）
