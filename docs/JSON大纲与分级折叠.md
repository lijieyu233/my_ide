# JSON大纲与分级折叠

日期：2026-10-17。

## 使用

JSON默认以可编辑源码打开。大纲只显示对象和数组的结构名称，不显示普通字段、字段值和 `{…}` / `[…]` 后缀。数组中的对象、数组保留原始下标，例如 `[1]`，不因隐藏普通元素而重新编号。点击结构定位原文；支持Unicode/转义字段名、同一行多个对象与CRLF；编辑后约300ms更新，未完成JSON尽量展示已识别结构。

只包含普通字段的对象、只包含普通元素的数组也显示折叠箭头，例如 `emotion`、`scores`。这类节点没有大纲子项，箭头直接折叠/展开编辑区对应块；双击、左右键和大纲控制接口遵循相同行为。关闭同步开关时也可操作，箭头始终反映该块的实际状态；其他含结构子项的节点仍遵循同步开关。没有内部内容可折叠的紧邻空容器 `{}`、`[]` 不显示无效箭头。Markdown 叶子标题保持原有行为。

大纲右键的四项作用于选中块：

| 操作 | 内部状态 |
| --- | --- |
| 折叠本级 | 保留 |
| 展开本级 | 保留 |
| 折叠本级及内部 | 所有内部块也折叠 |
| 展开本级及内部 | 所有内部块也展开 |

右键修改选中块时同步大纲树。JSON 大纲顶部 `+ / −` 左侧有“同步折叠”按钮，默认关闭；开启后图标高亮并记住选择，先采用当前编辑区的折叠状态。之后大纲箭头、双击、左右键、顶部展开/收起全部与编辑区的折叠箭头、快捷键双向联动。关闭后大纲箭头和“大纲列表”菜单恢复独立操作。该按钮只出现在 JSON 大纲，Markdown 保留原有行为。

同步保留内部折叠状态，不改正文或移动编辑光标；编辑区折叠仅更新现有树行的箭头、可见性和无障碍状态，不重新解析 JSON 或重建大纲。通知必须绑定当前编辑器、文件身份和编辑版本，切页后旧编辑器的通知不接管新大纲。普通标量没有代码块，不显示无效的折叠菜单。预览模式下需要切到源码编辑视图才能联动折叠。

## PyCharm Windows快捷键

官方来源：[PyCharm Code folding](https://www.jetbrains.com/help/pycharm/working-with-source-code.html#code_folding)。NumPad指小键盘。

| 范围 | 折叠 | 展开 |
| --- | --- | --- |
| 当前块，内部状态保留 | Ctrl+NumPad − | Ctrl+NumPad + |
| 选区内全部块；无选区时全文 | Ctrl+Shift+NumPad − | Ctrl+Shift+NumPad + |
| 当前块及内部所有层级 | Ctrl+Alt+NumPad − | Ctrl+Alt+NumPad + |

焦点在编辑器时，本级指光标所在块；焦点在大纲树时指选中结构，Shift作用于全文。兼容主键盘减号/等号与Shift产生的下划线/加号，作用范围按实际Shift/Alt修饰键区分，不能把没有Shift的小键盘加号误当全局展开。组合输入、快捷键捕获、其他输入框和弹窗不接管。JSON和Markdown共用规则，仅展开父级保留内部折叠状态。

全文折叠后，光标可能仍留在隐藏的内部位置。本级操作优先命中遮住光标的最外层可见折叠块；连续展开逐级向内，递归展开只处理当前可见块及其内部，兄弟块保持原状态。在折叠行末的闭括号之后按展开，也按可见行定位，避免对原来的逻辑行操作而没有反应。

这一回归用例不能预先把光标移回根节点。`tests/json-outline.test.js` 分别保留 JSON 内部字段和 Markdown 内部正文的光标；`scripts/check-json-outline.js` 另外通过 Chromium `Input.dispatchKeyEvent` 验证主键盘、小键盘的本级、递归和全文按键路径，避免仅靠合成 DOM 事件漏掉真实输入问题。

## 实现与验证

JSON使用现有CodeMirror的语法解析器保留原文偏移，不用JSON.stringify重排内容来定位。菜单绑定文档身份及编辑版本，切页或编辑后的旧菜单不能改动新文档。递归操作收集全部语法块，不使用只遍历可见外层的原生foldAll。

运行 npm run test:outline-keyboard 验证JSON结构、定位、作用范围、快捷键隔离、过期菜单、单行多对象与Markdown保全；运行 npm run check:json-outline 在隔离profile的隐藏真实窗口中验证键盘事件、右键操作、实时更新和截图。测试不改用户文档。
