# JSON大纲与分级折叠

日期：2026-10-17。

## 使用

JSON默认以可编辑源码打开。在“大纲”工具窗口中按对象、数组、字段及数组项显示层级，点击条目定位原文。支持Unicode/转义字段名、同一行的多个字段与CRLF；编辑正文后约300ms更新大纲。正在编辑的不完整JSON尽量展示已能识别的结构。

大纲右键的四项作用于选中块：

| 操作 | 内部状态 |
| --- | --- |
| 折叠本级 | 保留 |
| 展开本级 | 保留 |
| 折叠本级及内部 | 所有内部块也折叠 |
| 展开本级及内部 | 所有内部块也展开 |

右键修改选中块时同步大纲树；箭头和“大纲列表”菜单只控制树的显示。普通标量没有代码块，不显示无效的折叠菜单。预览模式下需要切到源码编辑视图才能折叠代码。

## 快捷键

| 范围 | 折叠 | 展开 |
| --- | --- | --- |
| 本级，内部状态保留 | Ctrl+- | Ctrl+= |
| 当前文档所有层级，包括隐藏的内部块 | Ctrl+Shift+-（Ctrl+_） | Ctrl+Shift+=（Ctrl++） |

焦点在编辑器时，本级指光标所在块；焦点在大纲树时，本级指选中项。组合输入、设置中的快捷键捕获、其他输入框和弹窗不接管。JSON和Markdown采用同一递归折叠规则；仅展开父级不会清除子级已有的折叠状态。

## 实现与验证

JSON使用现有CodeMirror的语法解析器保留原文偏移，不用JSON.stringify重排内容来定位。菜单绑定文档身份及编辑版本，切页或编辑后的旧菜单不能改动新文档。递归操作收集全部语法块，不使用只遍历可见外层的原生foldAll。

运行 npm run test:outline-keyboard 验证JSON结构、定位、作用范围、快捷键隔离、过期菜单、单行多对象与Markdown保全；运行 npm run check:json-outline 在隔离profile的隐藏真实窗口中验证键盘事件、右键操作、实时更新和截图。测试不改用户文档。
