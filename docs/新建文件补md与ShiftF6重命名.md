# 新建文件补 .md 与 Shift+F6 重命名

2026-11-14。两处小的编辑体验对齐，不改 IDE 布局。

## 新建文件自动补 `.md`

在项目树右键「新建文件」或 `Alt+Enter` 新建文件时，如果输入的名字**完全没有扩展名**，自动补成 `.md`：

- `周记` → `周记.md`
- `周记.md`、`notes.txt` → 原样（已有扩展名不再追加）
- `.env` → 原样（点开头是文件名本身，不改成 `.env.md`）
- 新建**文件夹**永远不补后缀
- 只输入空白 → 不创建任何东西

规则放在[树的新建入口](../renderer/tree.js)，因此右键菜单、`Alt+Enter`、AI 的 `create` 操作三条路径一致；主进程的排他创建与撤销仍然按**实际名称**工作，撤销记录和打开的标签都用补过后缀的真实路径。

## Shift + F6 重命名

- `Shift + F6`：重命名。目录树里有选中项就改它；没有树选中项时，改**当前打开的文件**（和 PyCharm 一致，不用先回树里点一下）。
- 原来的 `Ctrl + Shift + F6` 继续可用，旧习惯不受影响。
- 远程文件（`remote://`）不会退回本机路径去重命名；当前文件不在本项目内时同样拒绝，只提示先在树里选择。
- 键位可在「设置 → 快捷键」里改；`rename-file` 也进了命令面板。
