# 开发文档 010 —— 文件复制/粘贴（Ctrl+C / Ctrl+V）

> 状态：已完成 · 对应 ROADMAP P1 增补

## 一、需求

- 文件树中选中文件/目录 → `Ctrl+C` 复制（记录路径），`Ctrl+V` 粘贴到目标目录（生成副本）
- **外部互通**：资源管理器里复制的文件，在 IDE 里 Ctrl+V 也能粘贴（读系统剪贴板 FileNameW）
- IDE 里复制的文件，也能粘贴到资源管理器（写系统剪贴板）

## 二、设计

### 剪贴板互通（Windows）
- 写：`clipboard.writeBuffer('FileNameW', utf16le(路径列表))` + `writeText`（兼容普通文本粘贴）
- 读：`clipboard.readBuffer('FileNameW')` → 解析路径 → 过滤不存在的
- 内部复制同时维护内存态（粘贴优先用内部态，保证可靠）

### 复制（fs:copy）
- 文件 → copyFileSync；目录 → cpSync(recursive)
- **重名自动改名**：`name (1).ext`、`name (2).ext`…

### 交互
- 快捷键 `Ctrl+C` / `Ctrl+V`：**textarea/input 聚焦时不拦截**（文本复制优先）
- 粘贴目标：选中目录 → 该目录；选中文件 → 其所在目录；无选中 → 项目根
- 文件树右键菜单：复制 / 粘贴到此处
- 粘贴后：刷新树 + Git 状态 + toast

### 结构
```
main.js            clip:copyFiles / clip:getFiles / fs:copy
preload.js         桥接
tree.js            copySelected/pasteTo/getPasteTarget + 右键菜单
shortcuts.js       注册 copy-files / paste-files（文本区豁免）
```

## 三、测试计划

4. 右键菜单复制/粘贴
5. 外部剪贴板路径粘贴（fake getFiles 返回外部路径）
