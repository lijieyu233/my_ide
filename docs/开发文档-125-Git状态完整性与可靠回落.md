## 实施合同

状态带snapshotId/backend/completeness/changed/tracked/errors；失败不虚构clean或deleted，最近可信结果按仓库有界保存。UI保留可信列表及勾选/草稿，持续显示失败原因，完整状态依赖的提交/回滚等动作暂停，阅读/刷新仍可用；换项目与异步补充请求不能串旧结果。

正常路径保留stat捷径与忽略剪枝，系统Git可用时用其规范属性/过滤及porcelain v2 -z结果并获取对应索引tracked来源。所有普通/改名/冲突/未跟踪记录完整解析，NUL路径不按行/空白切分；原生输出/时间超预算和stderr扫描警告须明示，不能接受截断或部分枚举为完整。改名保留两端归属，兼容已有按文件选择，不凭一条目标路径丢失原路径删除。

缺Git时保留纯JS简单仓库能力，忽略规则在遍历前失效、目录失败向上报告、不可靠legacy stat不能作为回落。v4/冲突stage/特殊索引及复杂属性能力不足明确返回unknown；不能让legacy失败的空数组进入成功链。手动完整刷新/写前判断要真实哈希或原生保证，不能只塞未消费的force选项；原index/工作区字节不因扫描改变。

验收094-G1/G6–G9与C1、真实v4、有/无Git、同尺寸且恢复mtime、第一次忽略规则变更、目录故障、原生失败/警告/截断、普通/改名/冲突/中文空格及控制字符NUL解析。保留未选index条目与全部文件字节。实际万文件夹具核对完整路径/计时，完整应用CPU/RSS不从单命令推断；UI隐藏Electron与截图、发行包有/无Git走查，后台npm test、独立提交推送/远端核对与重启。

官方格式依据：[git-status](https://git-scm.com/docs/git-status)、[git-update-index](https://git-scm.com/docs/git-update-index)。本包不关闭094-G-C EOF/删除/filter块应用、整份提交外部并发及全仓库最后竞态；命名来源、错误和能力必须如实报告。用户023/068/119五项文档改动保留，不纳入本包。
