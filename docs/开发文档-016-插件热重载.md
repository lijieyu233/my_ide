# 开发文档 016 —— 插件热重载

> 状态：已完成 · 对应 ROADMAP P2

## 一、需求

开发插件（plugins/ 目录）时每次都要重启应用验证，效率低。
目标：**监听 plugins/ 目录变化 → 自动重新加载用户插件 → toast 提示**，无需重启。

## 二、设计

- 主进程 `fs.watch(plugins/)` → `webContents.send('plugins:changed')`
- preload 桥接 `plugins.onChanged(cb)`
- 渲染层：收到通知 → `MI.loadPlugins()` 重载
- **防重复注册**：loadPlugins 首次记录内置渲染器数量，重载时先截断用户插件再重新注册

### 结构
```
main.js              fs.watch + 通知
preload.js           onChanged 桥接
plugin-loader.js     重载去重（builtinCount 截断）
app.js               订阅变更 → 重载 + toast
```

## 三、测试计划

1. 模拟插件文件变更通知 → 重载执行
2. 重载后渲染器数量不变（无重复注册）
3. 现有 csv 插件功能不受影响
