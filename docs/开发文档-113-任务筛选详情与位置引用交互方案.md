## 1. 用户任务与四个交付包

用户打开任务工具，需要知道“现在能做什么、哪些任务为什么看不到、当前操作会影响谁”；选择一项后要能看完整备注、处理阻塞，再回到相关文件继续工作。建议 **A筛选/选择一致性 → B详情与阻塞定位 → C文件位置引用 → D常用视图保存**。A/B为P1，C/D为P2候选；091读端与恢复P0继续优先，阅读体验可以独立分包。

| 方向 | 看得见的变化 | 减少的操作 |
|---|---|---|
| UI设计 | 当前模式/清单筛选范围/匹配数可见，选中与隐藏数明确；任务详情显示完整备注与前置/后继 | 少靠hover和右键逐项找字段，知道空清单是筛选还是没有数据 |
| 交互 | 子任务筛选语义与图一致；隐藏选中项不参与无提示Delete；批量完成顺序确定；键盘可选任务并开详情 | 不误操作看不到的任务，不因点击顺序改变完成结果 |
| 新功能 | 任务附文件/行/章节引用，返回原编辑位置；命名保存常用视图 | 从任务直接回到工作内容，不反复手填路径或重新配筛选 |

## 3. 原模块复现与正向对照

方法：真实index去掉脚本标签后，jsdom outside-only加载完整原tasks.js；以`fixture-A`为内存localStorage键，无真实路径。通过setRoot/原可见度菜单/输入事件/原行点击/键盘Delete/公开批量API取证；图节点存在也有正向断言，避免把“图未渲染”误当筛选正确。实例结束close。R5两个fixture，8类观察；N1/N2另2类当前保存桥观察。

| 编号 | 操作 | 当前实际结果 | 结论与边界 |
|---|---|---|---|
| R1 | parent含child，child依赖未完成blocker；选“只看可执行” | 清单parent/child/blocker都显示，child带blocked；图含parent而不含child | 清单顶层判ready，但递归子行未判；图按每项判。不是阻塞数据丢失 |
| R2 | todo父任务含done子任务；选“不显示已完成” | 清单仍含done子，图含父而不含done子 | 子行绕过顶层hideDone判断；与模式文字不一致 |
| R3 | 选独立done-A，切“不显示已完成”，按Delete | A在清单/图均不可见，selection仍A；Delete移除A，undo可恢复且已实际恢复 | 隐藏选择仍参与删除；证明内存任务操作，未证明用户磁盘数据丢失 |
| R4 | 过滤Alpha，用新建输入框创建Gamma | Gamma创建并选中，输入清空；清单只见Alpha | 当前图仍可见Gamma，不是“创建失败/全界面消失”；缺清单之外创建的提示/揭示动作 |

| R6 | 检查原行/勾选与tasks源码键盘处理器 | 行DIV和勾选SPAN的tabIndex=-1、无role；未找到行Arrow/Enter入口 | 直接键盘选行/勾选入口缺失；已有快捷新建/复制/撤销/Delete不可写成“完全无键盘支持” |

## 6. A包：筛选、层级与操作对象一致

先统一“命中任务集合/上下文父节点/可操作集合”三种身份：ready/doing/hideDone应按每个任务计算，匹配子任务需要父节点时，父节点只作带说明的上下文，不能混进可执行/匹配数量。保留标题+优先级只作用清单的默认；可见度与聚焦沿现有范围，图数据和阻塞计算始终依全量数据。不要让一个总filter函数顺手改变用户已有图布局行为。

模式文字和清单匹配/总数可见；优先级/关键词、全局可见度、关联聚焦分别显示作用范围和清除入口。空状态区分项目无任务、加载/失败、无匹配、被模式/折叠隐藏；“清除清单筛选”不改变隐藏已完成等其他模式。创建后若被筛选挡住，持续提示“已创建，当前清单筛选隐藏”及“显示该任务”动作；不要自动永久清空用户的筛选。

主选择与操作选择绑定视图版本。模式/折叠让任务不再可见时，首包移出快捷操作集合并在必要处显示隐藏选择数；若详情仍展示该任务，详情内显式删除可保持有效。多选从两个区累计时，批量栏显示本次影响项和隐藏数；普通Delete只操作当前工具中可见/明确展示的有效选择，不能复用不透明的全局selIds。

R5建议采用**同批依赖拓扑顺序**：冻结root/generation和原任务版本，对选中集按既有deps排序；已完成外部前置可满足，未选中且未完成前置保持阻塞；A、B同批时先A后B，输入顺序不影响结果。先在草稿模型算出成功/跳过和原因，再单次提交历史/保存/渲染；不把未选中的前置自动标完成，不承诺全批原子落盘已经实现。若实际保存失败，沿091展示目的地/未保存状态。

**验收**：R1/R2子任务与嵌套3层、父过滤/折叠/父done子todo；R3模式/清单筛选/聚焦/折叠隐藏后的Delete与右键/详情；R4创建/重命名移出筛选；R5所有排列、外部前置/重复ID/跳过原因、单次undo/redo；切项目时旧批确认不能作用新任务。保留C1/C2与既有写队列快照。

## 7. B包：详情、阻塞定位与键盘

保留单击选择、双击改名、右键菜单。新增明确的“查看详情”动作/键盘Enter，打开当前图内可收起详情区域，避免默认再占一个常驻侧栏。详情按标题→状态/优先级/预计耗时→完整备注→未完成前置/全部依赖/后继→位置引用排列；首包只复用现有字段。长中文换行和多行备注可读；窄屏可用暂时覆盖的详情，关闭恢复原图视口与焦点，未保存编辑需明确处理。

阻塞列表显示名字和状态，点击先用原任务ID在当前根定位；若被过滤/折叠隐藏，显示可解释的临时揭示，退出后恢复条件。区别“前置未完成”和“依赖不存在/数据被清洗”，后者不能自动叫已完成。所有改动入口走已有setStatus/setDeps等统一校验并补root/generation，详情显示成功不替代保存确认。

清单引入单一键盘焦点项：↑↓在实际可见顺序移动，Enter详情，Space对焦点任务走已有完成守卫，Shift范围选择与Ctrl追加不被重写；备注/输入/IME时按键归输入。分组/子组折叠控件、状态控件有按钮或适当ARIA；视觉选择与焦点区别，隐藏后移到相邻可见行。图首包可通过清单等价操作任务，图自身空间导航另测，不凭添加tabIndex宣称全可访问。

新增列表/工具条图标采用现有1.4px内联SVG；右键emoji前缀保留。可见度/布局文字可在正常宽度显示，窄屏图标也必须有可读名称。撤销入口显示实际最近动作，“撤销最近一次删除”更新为与统一历史一致的说明。

**验收**：完整备注/同名任务/高低优先级/无依赖/多阻塞；键盘新建→选行→详情→改状态→返回，失败和关闭焦点可知；编辑期间切任务/项目不串写；Ctrl+9/Ctrl+Enter/Ctrl+C/Ctrl+Z/重做原绑定保留。深浅主题、窄侧栏、100/125/150%缩放截图；实施后headless check-ui看图，IME/原生焦点/读屏单独记录，DOM不代替它们。

## 8. C包：新增文件、行与章节引用

先交付“从当前文件/选区附位置”与“从文件树附文件”两入口。引用结构建议`refId / projectIdentity / relativePath / kind / lineRange / headingAnchor / versionHint / snippet`，不要只在note塞一条绝对路径。任务名/备注已有内容不自动改写，引用列表能打开/移除/重新定位，不自动创建新的任务依赖。

定位冻结任务根与引用对象，打开后等待Viewer ready再跳行；返回用105位置历史。文件重命名/移动由097与112路径合同发出映射，章节锚点依099真实标题索引（重名有身份）；正文变化后先按版本/锚点重定位，无法确认则显示“位置可能已变化”，不悄悄跳到相同行号的另一段。文件删除保留失效引用和查找/解除动作，不把任务也删掉。

新字段需version迁移，validate显式保留/检查；旧任务文件可读，新增引用不能被旧清洗函数静默丢掉。项目外路径首包不支持，用户选择外部对象时解释范围；打开引用只是导航，不执行命令或任意协议。更复杂的附件、截止日期、提醒、团队分配和云同步不列本批。

**验收**：真实临时文件/行/同名章节、编辑版本变化、文件迁移/删除/恢复、项目路径移动、用户移除项目；打开失败不丢任务/当前编辑输入，反复附/删引用各单次undo。结构化存储失败可重试，旧版本数据不会失去note/deps/parentId；三项文件合同仍待接入时不以样机导航当产品完成。
