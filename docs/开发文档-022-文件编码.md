# 开发文档 022 —— 文件编码支持（GBK/UTF-16 识别与回写）

> 状态：已完成 · 体验打磨

## 一、需求

中文 Windows 环境大量 GBK/GB2312 老文件，当前按 UTF-8 读 → **乱码**，且无法保存。
目标：**自动识别编码（UTF-8/GBK/UTF-16），编辑后按原编码写回**。

## 二、设计

### 编码检测（主进程 readFile）
1. BOM 检测：UTF-8 BOM / UTF-16LE / UTF-16BE
2. 无 BOM：尝试 UTF-8 严格解码（fatal）→ 成功即 UTF-8
3. 失败 → GBK 解码（内置 TextDecoder('gbk')，零依赖读取）
4. 返回 `{ content, encoding }`

### 写回（writeFile 增加 encoding 参数）
- utf8 → 默认
- utf16le/utf16be → 内置 Buffer 转换
- **gbk → iconv-lite 编码**（唯一新增依赖，纯 JS 零原生）

### UI
- 状态栏显示当前文件编码（如 `GBK`），与版本号并列
- tab 保存携带编码

### 结构
```
main.js         readFile 检测 / writeFile 回写
viewer.js       tab.encoding + 保存透传 + 状态栏
styles.css      状态栏编码徽标
```

## 三、测试计划

1. fake readFile 返回 encoding:'gbk' → 打开正常 + 状态栏显示 GBK
2. 保存时 writeFile 收到 encoding 参数
3. UTF-8 文件不受影响（encoding 默认 utf8）
