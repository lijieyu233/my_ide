# DeepSeek Harness 执行模式

> 历史受限实现，当前侧栏连接见文档 148。本文的工具禁用、每请求进程、历史重放和模型覆盖已取消。

## 使用

AI 面板的“执行模式”可选择“普通助手”或“DeepSeek Harness”。默认仍是普通助手。Harness 模式沿用 MyIDE 中配置的服务地址、模型和 API Key，不读取 Harness 桌面登录凭据。设置 → AI 助手中可以选择 `dsh.cmd`、检查安装并指定模型实际上下文容量（未填时按 65536 配置）。

本机验证安装为 `D:\programfie\deepseek`，版本 `0.2.0-rc.2`，入口 `resources\runtime\cli\bin\dsh.cmd`。适配器按该启动器的公开安装布局，以参数数组直接启动其 Electron Node 运行时和 CLI 入口，不拼 shell 字符串。

首次发送才启动运行引擎；应用打开时不启动 DSH，不打开 Harness 桌面窗口。每次用户请求拥有独立进程与 ACP 会话，完成后关闭。下一次请求从 MyIDE 已保存的对话和实际工具记录构造上下文，第一版不恢复 DSH 内部会话。独立 `DSH_HOME` 位于 MyIDE userData 的 `dsh-myide`，不改用户 Harness 的 desktop profile。

## 执行链路

MyIDE 消息 → 主进程 ACP 客户端 → 本机 DSH agent loop → 认证的回环 MCP 工具桥 → MyIDE 现有工具执行/授权 → ACP 语义回复。

- ACP 首次握手验证 v1、HTTP MCP 和独立会话关闭能力，能力不兼容时明确失败。
- 模型通过 `llm-pi-ai` 的 OpenAI-compatible 路由访问原模型地址。API Key 仅通过本次子进程环境传递；覆盖配置只保存凭据变量名，完成后删除临时覆盖文件。
- 文件、命令、启动面板、SSH 和内置浏览器均复用 MyIDE 的工具契约、调用身份、可信授权、写入差异和撤销卡片。DSH 原生文件/Shell/子代理/动态插件/PTC 执行入口在本 profile 禁用，避免出现两套权限和不同的文件写入路径。
- `ide_state` 返回当前页面。只有项目页面返回当前文件正文、dirty 状态和截断标记，最多 30000 字符。编辑器原有 3 秒自动保存机制继续生效。
- 独立页面不附带项目文件、目录、规则及历史项目工具内容，也不发布项目文件工具。项目任务进行中手动离开项目页会停止 DSH；模式切换、项目切换、停止、新会话和宿主销毁同样终止旧任务。
- 运行工具结果保存为仅供参考的历史事实，不能重新解析回复里的文本工具示例而再次执行。迟到或不同请求的事件和工具结果被拒绝。

## 运行边界

ACP 输出是提交后的语义消息及工具生命周期，不保证逐 token 推送。状态区显示启动/处理/思考状态和工具执行进度。DSH 模式不受普通助手 8 轮限制，本次运行上限为 20 分钟；达到模型输出上限或运行预算时明确标记未完成。上下文容量由用户按实际模型填写，不把配置值说成服务端核实的模型容量。

第一版只接入文本输入，图片输入明确拒绝并提示切换普通助手。模型工具调用能力仍取决于配置的模型和服务。测试不消耗用户 API 额度；尚未用用户线上模型验证任务质量。

回环 MCP 每次使用随机 Bearer 凭据，仅监听 127.0.0.1；请求体和输出有界，只发布本次允许工具。子进程继承环境时剔除其他密钥和 DSH 覆盖变量。进程退出/取消时拒绝待处理工具并回收连接、临时文件；MyIDE 已提交的文件操作保持现有停止语义，不承诺自动撤销。

- DSH 适配 8 组：逐行协议拆包/乱序/错误、配置无密钥、输入边界、MCP 结果、停止、进程退出和输出上限。
- AI 面板运行测试 43 通过 / 0 失败，包括切换模式、迟到工具、文本工具不重放和页面上下文隔离。
- `npm run check:ai-dsh`：隐藏生产 MyIDE 窗口 + 本机真实 DSH + 回环模型桩，6 组通过。覆盖当前编辑器正文、真实差异批准/拒绝/落盘/撤销入口、启动面板工具、非项目文件隔离、模型等待时停止及重开；设置检查/取消保持模式和模型地址；截图核对暗红主题。
- DOM 522 通过 / 0 失败；打包资源 86 通过 / 0 失败；语法 88 个文件通过。
- `npm test` 在既有 Git worker 临时目录 EPERM 处停止（Git 61 通过 / 1 失败），不能宣称全套通过。

接入依据是本机安装包内 `@deepseek-ai/dsh-acp`、`dsh-acp-app`、`dsh-mcp-client` 和 `dsh-llm-pi-ai` 的 README/公开配置；未调用私有 UI 接口或抓取桌面授权。

通用 UI 回归：461 通过 / 8 失败 / 3 跳过，失败涉及平铺名字宽度、Git 暂存、H3 和 Mermaid 颜色。DSH 真实窗口专项通过；不把通用回归称作全绿。
