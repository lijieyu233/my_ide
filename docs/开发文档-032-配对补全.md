# 开发文档 032 —— 编辑配对自动补全

> 状态：已完成 · 编辑体验

## 一、需求

输入 `(` `[` `{` `'` `"` 时自动补全配对符并把光标置于中间（主流编辑器默认行为），提升书写效率。

## 二、设计

- textarea keydown 拦截：
  - 输入开括号/引号：补全配对 → 光标置中；**有选中文本时包裹**
  - 输入闭符号且下一个字符是相同符号：跳过（光标右移），防重复
  - Backspace 且光标位于配对中间：一并删除配对
- 不干扰：Ctrl 组合键、功能键、中文输入法（仅 e.key 为单字符时处理）

### 结构
```
viewer.js   handlePairing（textarea keydown 调用）
```

## 三、测试计划

1. 输入 ( → 自动补全 () 且光标在中间
2. 光标在 ) 前输入 ) → 跳过不重复
3. 选中文本输入 ( → 包裹选中
4. Backspace 删除配对
