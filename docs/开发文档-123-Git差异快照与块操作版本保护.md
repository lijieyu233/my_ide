# Git差异快照与块操作版本保护

> 2026-10-01，基线8dbd87e；沿094-G-A，先写合同再实现。

当前stage/unstage/revertHunk重算差异后按idx操作，用户旧视图可能选择前面后来出现的新块。回退确认后还会读取全局root，换项目可以误操作；当前isomorphic-git的GitIndexManager源码只启用进程内mutex，磁盘锁代码被注释。本包保留已有双区/选块能力，实施展示身份和数据保全，不新增行级提交。

## 合同

- diff按真实仓库/项目请求归属、文件、side固定snapshotId和每块hunkId；主进程可信服务保留有界快照，读取前后核对HEAD/index/工作区原字节、存在/身份/mode/EOF与属性配置版本，不发放混合版本写入授权。不能用旧idx选当前块，缺少/失效令牌明确拒绝。
- UI按钮绑定该快照、diff请求代次与项目代次；确认、切项目、换视图或磁盘继续编辑后旧动作失效；未保存输入独立保留。提交期间防重复，operationId相同请求只执行一次；旧结果不能重开别的项目/文件。
- 同仓库应用内index写入排队，原生与worker通道共同参与。块index更新先wx获得真实index.lock，基于原index在独立副本合成，写前验证完整原版本，刷盘后排他发布；不全量还原用户原index去覆盖外部暂存，错误保留锁来源/明确事实。本应用队列不阻止外部进程，无全文件系统CAS承诺。
- 块回退先保留原字节/ADS/普通权限属性恢复来源，复用122/115持久文件操作；替换按展示版本与准备版本拒绝，协调编辑器dirty/在途保存/迟到输入；失败和部分副作用保留记录。从「恢复文件操作」可找回本次原字节，不能继续宣称不可恢复。
- 验收G11旧视图新增前块/原块改动/移动/外部add、staged侧变化、HEAD/属性变化、重复IPC/不同operationId、index.lock占用/写入故障；刷新选块只动所选，未选两侧与其他文件不动。真实提交核对HEAD、隐藏真实Electron确认等待/跨项目、包内恢复和截图。

094-G-B状态完整性/v4回落与G-C EOF/删除/过滤器语义仍是原合同，不以本包版本保护关闭。现有applyHunkToText的EOF/复杂属性缺口继续分包；本包须明确观察范围，不称所有Git语义/外部最终竞态已解决。后台npm test、独立提交推送、重启和临时产物清理，用户023/068/119现有五项文档变化排除。

## 实施与验收

代码基线8dbd87e，期间并行文档提交942fc45/e84a562，均不纳入本包改动。git-hunks保留展示的原始块而不重算ordinal；默认流20MiB、index64MiB、展示缓存128份/64MiB及30分钟期限，操作结果512条/30分钟。Windows命名流摘要使用流式读取，单次原对象含流256MiB上限。没有以这些缓存上限宣称完整进程RSS或延迟已达标。

每次版本采集在属性查询等待后再次核对正文/index/HEAD与命名流/权限属性，避免等待过程形成混合版本。Windows大小写.git路径及仓库外路径明确拒绝。有效系统Git时检查实际check-attr与配置来源输出摘要；无Git时核对本地属性/配置及常见用户配置文件。结果带side、存在、mode、EOF与原字节版本；UTF8不可逆/NUL和链接别名拒绝文本块授权。

块暂存/取消暂存先wx取得真实index.lock，库所有index读写转向该独占副本，基于原index保留其他条目，生成/flush/再核对后原生发布一次。外部锁不清；自己的锁身份变化不删除替代对象；清理失败明确返回pendingIndexLock。公开index已发布但核对失败返回committed事实，不回写整份旧index。同仓库主IPC队列涵盖原生和worker写通道，服务直接调用也排队。Worker正常exit/error与postMessage失败释放等待者，不自动重放可能已经执行的写入。

回退用可信userData恢复目录旁的私有同盘暂存，先克隆原字节及流/属性，再仅用r+句柄修改与截短默认流。真实试验确认Windows w/CREATE_ALWAYS会清除命名流，r+/ftruncate保留；新增回归同时核对回退结果及持久undo原字节/ADS。复用copy-journal准备全部来源、验证后发布，失败/部分副作用留恢复记录；Viewer.withCopyChange等待旧保存，阻止冲突新保存，dirty/迟到输入与旧磁盘基线保留。主路径并发协调不依赖渲染层单独记住成功。
