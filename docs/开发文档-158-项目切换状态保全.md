# 项目切换状态保全

## 问题

恢复旧会话时，一个已删除文件就会让项目进入保护状态。此前该状态同时禁止所有后续位置快照，用户新增的标签、当前文件和目录展开再也不会保存。切走再回来便重新激活已删除的旧文件。

临时预览标签此前也被会话过滤，当前页面因此会在切换之后少一个标签。恢复光标行时还可能把已经恢复的滚动位置拉回光标所在位置。

## 行为

- 原记录继续保留，部分恢复之后的最新状态另存到 `myide-session-current:<root>`。该快照绑定原记录的完整字符串；外部更换原记录后不套用旧快照。
- 项目切回和进程重启优先恢复匹配的最新状态。当前临时预览也记录并恢复原有类型，标签顺序、当前文件和目录展开保持一致。
- 新快照仍做项目归属、恢复代次和存储版本检查。恢复在途不能保存半份状态，存储失败会保留当前标签并拒绝切换或关闭项目。
- 状态详情继续提供原记录复制及明确备份入口。最新快照不替换文件正文。
- 文件树选中项回到当前文件。恢复光标之后等待编辑器布局结算，再恢复离开时的滚动位置。

- `tests/project-open.test.js`：11 组通过，包含保存状态失败阻止清标签、旁存保存成功允许切换。
- `scripts/check-session-switch.js`：真实隐藏Electron窗口，往返10组、独立新进程4组通过。复现已删除的旧活动文件，打开12个普通标签及`10_14.md`临时预览，关闭旧失效标签、展开子目录，并在光标仍在开头时滚动700px。实际A→B→A及新进程重开均恢复13标签、活动文件、临时预览、目录展开和滚动位置。
- 比较 `session-switch-before.png` / `session-switch-after.png` 截图，当前文件、目录结构和可视正文保持一致；所有测试使用隔离profile，不写用户配置。
- DOM 全套：523 通过 / 0 失败；语法：95 个文件通过。多项目交互测试等待实际恢复终态，避免用20ms固定延时误判编辑器布局尚未完成的切换。
