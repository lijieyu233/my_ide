# 开发文档 007 —— 图片预览

> 状态：已完成 · 对应 ROADMAP P1-7

## 一、需求

文件树里点开 png/jpg/svg 只能看到"二进制文件"提示。
目标：直接预览图片（`file://` 加载，零解码成本——图片解码交给 Chromium）。

## 二、设计

- **内置渲染器**（plugin-loader.js）：`['png','jpg','jpeg','gif','webp','svg','bmp','ico']` → `<img>`，src 用 `file:///` + 正斜杠路径
- **viewer 分支**：图片扩展名跳过 readFile（二进制会误报），直接 preview 模式
- **CSP**：`img-src` 增加 `file:`
- 样式：居中、`max-width/max-height: 100%`、透明图棋盘格背景

### 结构
```
plugin-loader.js   image 渲染器（演示"插件式加格式"）
viewer.js          IMG_EXTS 分支
index.html         CSP img-src file:
styles.css         .img-view
```

## 三、测试计划

1. 打开 .png → `<img>` 渲染，src 为 file:// 路径
2. 无"查看源码"按钮（二进制无源码可看）
