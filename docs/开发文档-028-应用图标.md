# 开发文档 028 —— 应用图标

> 状态：已完成 · 发布体验

## 一、需求

打包版使用默认 Electron 图标，不体面。
目标：**自定义图标**（深蓝圆角方块 + 白色 M + 绿色提交条），纯代码生成（手写 PNG 编码器，零图像依赖）。

## 二、设计

- `scripts/make-icon.js`：程序化绘制 256×256 RGBA → 手写 PNG 编码（IHDR/IDAT(zlib)/IEND + CRC32）
  - 圆角矩形 + 垂直渐变底、点阵 M 字模、底部绿色条
- 产物 `build/icon.png`（electron-builder 自动转 .ico，win.icon 指向）
- 重新打包接入图标

### 结构
```
scripts/make-icon.js   生成器
build/icon.png         产物（gitignore）
package.json           build.win.icon
```

## 三、验收

- [x] PNG 生成有效（文件头/尺寸校验）
- [x] 打包成功且使用自定义图标（用户 GUI 验证外观）
- [x] npm test 全绿
