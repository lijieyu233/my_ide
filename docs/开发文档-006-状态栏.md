# 开发文档 006 —— 状态栏

> 状态：已完成 · 对应 ROADMAP P1-6

## 一、需求

缺少全局状态感知：当前分支、当前文件、行列号都要靠猜。
目标：底部一条状态栏，一眼看到关键信息（PyCharm 状态栏的轻量版）。

## 二、设计

- `#statusbar` 固定在底部（22px），左侧 Git 状态（分支+修改数），中间当前文件，右侧行列号
- 更新时机：
  - Git 状态：`GitPanel.refresh()` 后（App.updateStatusbar）
  - 文件信息：viewer 渲染标签后（路径 + 行数）
  - 行列号：textarea 的 input/keyup/click（编辑光标位置）
- 非 Git 仓库显示「非 Git 仓库」

### 结构
```
index.html        <footer id="statusbar">
styles.css        状态栏样式
app.js            updateStatusbar(info) 统一入口
git-panel.js      refresh 后上报分支
viewer.js         标签渲染后上报文件；textarea 事件上报行列
```

## 三、测试计划

1. 打开文件后状态栏含文件名与行数
2. Git 面板刷新后状态栏含分支
3. 光标移动更新行列号
