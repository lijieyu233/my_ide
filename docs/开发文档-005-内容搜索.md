# 开发文档 005 —— 内容搜索 Ctrl+Shift+F

> 状态：已完成 · 对应 ROADMAP P1-5

## 一、需求

项目里找一段文字（配置项、函数名、笔记关键词），目前只能靠记忆+肉眼翻文件。
目标：**全项目内容搜索**，Ctrl+Shift+F 打开，输入即搜，点击结果打开文件。

## 二、设计

### 主进程 `fs:grep`（不阻塞 UI）
- 异步递归遍历（每文件 `setImmediate` 让出事件循环）
- 跳过：`.git`、`node_modules`、隐藏文件、>1MB 文件、二进制（含 NUL 字节）
- 结果上限 200 条（超出标记 truncated），超时 10s 截断
- 返回：`{ file, line, text }[]` + 耗时

### 渲染进程 `search.js`
- 模态面板（复用快速打开样式，加宽到 720px）
- 输入 **300ms 防抖** → 调 grep
- 结果列表：`文件:行号` + 内容片段；点击 → 打开文件 + 提示行号
- Esc 关闭，Enter 打开第一条

### 结构
```
main.js            fs:grep IPC
preload.js         桥接
renderer/search.js 面板 + 防抖 + 结果渲染
shortcuts.js       Ctrl+Shift+F
```

## 三、测试计划

1. Ctrl+Shift+F 打开面板
2. 输入关键词 → 防抖后结果渲染（含文件/行号/片段）
3. 点击结果 → 打开文件标签 + 面板关闭
4. Esc 关闭
