# 开发文档 015 —— Git 分支切换

> 状态：已完成 · 对应 ROADMAP P2（Git 能力补全）

## 一、需求

当前只能看当前分支（`⎇ main` 静态显示），无法切换分支。多分支工作流（feature/dev）是开发常态。
目标：**点击分支名 → 弹出分支列表 → 点击切换**（PyCharm 右下角分支选择器的简化版）。

## 二、设计

### 后端
- `git-service.branches(dir)`：listBranches + currentBranch（排序返回）
- `git-service.checkout(dir, ref)`：isomorphic-git checkout
- main IPC + preload 桥接

### UI（git 面板分支栏）
- `#git-branch` 从静态文本改为可点击（cursor + hover 提示"点击切换分支"）
- 点击 → 模态弹窗：分支列表（当前分支 ✓ 标记 + 高亮），点击即切换
- 切换成功：关弹窗 + 刷新状态 + toast；失败：toast 错误（如未提交更改冲突）

### 结构
```
git-service.js   branches/checkout
main.js/preload  IPC
git-panel.js     分支弹窗
styles.css       .br-item
```

## 三、测试计划

1. 点击分支名 → 弹窗列出分支，当前分支有标记
2. 点击其他分支 → checkout 调用 + 弹窗关闭 + 状态刷新
3. 切换失败 → toast 错误且弹窗保留
