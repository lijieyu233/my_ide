# 开发文档 023 —— 编辑器行号

> 状态：已完成 · 体验打磨

## 一、需求

编辑器目前是裸 textarea，没有行号——"编辑器感"的核心缺失（PyCharm 最基本形态）。
目标：**文本编辑视图加行号 gutter**，滚动同步，行数实时更新。

## 二、设计

- 结构：`.editor-wrap`（flex row）= `.editor-gutter`（行号列）+ textarea
- 同步：textarea `scroll` → gutter.scrollTop 同步（同字体/行高/内边距保证对齐）
- 更新：input 时行数变化才重建行号文本（避免无谓重绘）
- gutter 样式：等宽、右对齐、不可选中、panel 底色

### 结构
```
viewer.js     edit 分支改造（wrap + gutter + ta）
styles.css    .editor-wrap/.editor-gutter
```

## 三、测试计划

1. 打开文本 → gutter 存在且含行号 1
2. 输入换行 → 行号数量增加
3. textarea 滚动 → gutter scrollTop 同步
