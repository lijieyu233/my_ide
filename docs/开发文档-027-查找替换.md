> 状态：已完成 · 编辑器基础能力补全
> 当前实现补充（2026-10-01）：源码/live/source已走CM6原生搜索，Markdown split仍用本文textarea条；新取证、归属/匹配版本与UI/范围改进见[124](./开发文档-124-文档查找与替换范围交互方案.md)。下文保留早期设计与验收记录，不代表所有当前模式。

## 一、需求

编辑文本时无法查找/替换（长文档翻找痛苦）。
目标：**编辑视图内查找（Ctrl+F）与替换（Ctrl+H）**——浮动查找条：计数、上下跳转、循环、替换/全部替换。

## 二、设计

- 查找条（toolbar 下方浮动条）：
  - 查找输入 + 计数（x/N）+ ⬆⬇ + 替换行（替换/全部替换）+ ✕
- 匹配收集：indexOf 循环（区分大小写，上限 1 万）
- 跳转：设置 textarea selection（自动滚动到可见）+ 计数更新；Enter 下一个 / Shift+Enter 上一个（循环）
- 替换：替换当前匹配（setRangeText）→ 重新收集；全部替换用 split/join
- 关闭：✕ 或 Esc（textarea keydown 捕获）
- 快捷键：Ctrl+F / Ctrl+H（仅编辑视图有效，非编辑提示）

### 结构
```
viewer.js       openFind/findState/collectMatches/替换逻辑 + 导出
shortcuts.js    注册 find / replace
styles.css      .find-bar
```

## 三、测试计划

1. Ctrl+F → 查找条出现；输入词 → 计数正确；Enter 循环切换
2. Ctrl+H → 替换行展开；替换当前 → 内容更新；全部替换 → 全部更新
3. Esc 关闭
