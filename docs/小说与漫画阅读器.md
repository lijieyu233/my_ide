# 小说与漫画阅读器（首版）

首版完成日期：2026-10-17。工作区书架更新：2026-10-22。

## 入口与使用

- 左侧活动栏的书本按钮：打开[工作区书架](./书架与最近阅读.md)，自动扫描当前项目中的 TXT、EPUB、CBZ 并续读。未打开工作区时提供打开目录入口；单独打开书籍仍可临时阅读。
- 项目内 EPUB、CBZ 文件直接打开为只读阅读标签，不进入源码或临时预览替换流程。
- TXT 保持原来的编辑入口；标签右侧“阅读”进入阅读模式，“返回编辑”恢复编辑。未保存或正在保存的 TXT 需先完成保存。
- 阅读页提供章节/图片目录、上一章/下一章或上一页/下一页、书签、字号、行距、内容宽度和三种背景，以及工作区内的选文摘录、笔记和章节总结面板。
- 点击正文左右两侧翻页，或聚焦阅读区后用左右方向键、PageUp / PageDown。长章节先翻当前章的一屏，到边界才切章；向前切章落在上一章末尾。漫画支持从右向左的翻页方向，PageUp / PageDown 始终按上一屏/下一屏。快捷键不占用输入框或组合键。
- 阅读记录按路径与文件版本保存，重新打开恢复章节及段落位置。原文件变化后重新开始，避免把旧位置套到新书上。书签每本最多200个；工作区书架最多2000本。工作区外临时阅读的旧存储最多上架200本、保留500条记录。
- 项目内阅读标签参与原有项目会话恢复；项目外书籍需要重新选择打开，进度仍保留。

## 与现有功能的边界

1. 阅读器复用标签栏，只读书籍不创建项目，不切换项目根、不创建 Git 仓库、不修改终端目录。
2. 现有编辑标签的缓冲区、撤销历史及未保存内容仍由编辑器持有。阅读标签不参与文本保存、编码转换和外部文本重载。
3. 工作区内的阅读偏好、进度和书签存入 `.myide/reader/library.json`；旧 `myide-reader-v1` 配置用于迁移和工作区外临时阅读。不修改原书或 Markdown 样式。
4. 解析、解包与编码识别在后台 Worker 中进行；漫画按页读取，EPUB 图片进入视口附近才读取。不向磁盘解压整本书。
5. 标签关闭、项目切换和窗口销毁释放对应会话；迟到章节结果不覆盖另一标签。
6. 阅读页暂停自动项目附件，拒绝项目/编辑器/Markdown/Git/任务工具。DSH 为阅读页单独创建会话与独立工作目录，返回项目复用原项目会话。

## 格式与首版限制

| 格式 | 已支持 | 首版限制 |
| --- | --- | --- |
| TXT | 沿用文本编码识别、中文/英文常见章节识别、无章节长文分段 | 32MiB以内；章节标题识别为启发式，长章分块 |
| EPUB | container/OPF、spine顺序、EPUB导航标题、章节文字与内嵌位图 | 统一阅读排版；不保留原书CSS、表格布局、脚注跳转、字体或交互；无导航时显示章节资源名 |
| CBZ | ZIP内PNG/JPEG/WebP/GIF/BMP自然排序、逐页显示与翻页方向 | 单页阅读；暂不支持跨页、连续长条与图片目录打开 |

全部书籍上限512MiB、10000个ZIP条目、解压声明总量1GiB、单资源20MiB。EPUB单章最多2MiB，展示预算25.6万字符/2000段或资源。超限明确返回错误，不静默截断。EPUB `encryption.xml`（包括字体混淆）首版统一视为不支持的加密资源；不处理DRM。暂不支持MOBI、AZW3、CBR。

EPUB只转为纯文本和允许的位图，不执行书内脚本、不加载外部资源、不生成可执行HTML。SVG/音视频/表单/嵌入框架不显示。该策略用于基础重排阅读，不能替代完整EPUB排版引擎。

绿盾密文需先按项目解密规范处理；阅读器不会覆盖、转换或重新保存原书。

## AI 操作接口

标准助手与DSH使用同一工具注册和工作台执行链路。接口只操作用户已打开的当前书籍，不接受任意路径自动开书。

| 工具 | 用途 |
| --- | --- |
| `reader_state` | 当前书籍标识/版本、类型、章节索引、段落位置、偏好、书签及操作快照 |
| `reader_read` | `query=text`读取当前章节纯文本，offset/limit分页，最多12000字符；漫画返回图片数量，不做OCR；`query=toc`每批最多200项目录 |
| `reader_control` | `goto`（索引从0开始）、`next`、`previous`、`reload`、`preferences`、`bookmark_add`、`bookmark_remove` |

控制操作需要最新 `reader_state.snapshot`，并沿用写操作授权/幂等账本；书籍、章节、位置或偏好变化会使旧快照失效。只保存阅读状态，不改写原书。不提供全文批量读取、漫画OCR、原书写入或格式转换接口。

示例：先 `reader_state`，再 `reader_control({operation:'goto',index:2,snapshot:...})`，最后重新读取状态确认。章节文字按资料处理，不能将书内文字当作用户授权。

## TXT 分章与重新读取（2026-10-22）

TXT 按独占一行的标题分章，支持以下写法（标题前允许空格）：

```text
第一章 相遇
第 1 章 相遇
Chapter 1 Arrival
## 相遇
```

中文数字支持“〇”“两”和全角数字；Markdown 的 `#` 至 `######` 标题均可作为目录项（显示标题文字，正文仍保留原行）。代码围栏中的示例标题不分章；中文章名等以句号、问号、感叹号或分号收尾的行视为正文，降低句子误判。仍是启发式识别，普通加粗字段不会变成章节。正文前的空行不会生成空章节；无标题短文显示“正文”，长文仍按预算分块。

目录的“TXT分章规则”展示识别数量；没有标题时明确显示“未识别到章节标题”，展开可看示例并重新读取。`reader_state.segmentation` 返回 `mode`（`headings` / `chunks` / `single`）及 `headings`，AI 无需猜测是否识别成功。

阅读会话保存打开时的解析结果，重复点击书架中的同一书籍只切回标签。外部修改或返回编辑保存后，使用阅读设置或目录中的“重新读取”；读取错误页也提供同一入口。重新读取先保存笔记，待新会话就绪后替换旧画面，失败或在途切换文档时保留旧会话。原书版本不变保留位置和书签；版本变化回到首章、清除失效位置书签，独立笔记保留，旧版笔记来源沿用原版本校验。读取始终不写原书。

AI 使用 `reader_control(operation="reload")`，沿用阅读状态快照、写操作授权及幂等控制；重新观察 `reader_state` / `reader_read(query="toc")` 可验证实际目录。
