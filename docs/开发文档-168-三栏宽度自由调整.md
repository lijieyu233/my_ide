# 三栏宽度自由调整

取消项目栏 260–480px、AI 栏 320–520px 的固定范围，以及 AI 拖动时为编辑器预留 360px 的约束。保留 340/380px 初始宽度与双击恢复默认操作。

两侧可缩到零宽，也可扩展到窗口实际剩余空间，中心编辑区可缩至零。两侧宽度不足时随窗口自然收缩，拖动前读取另一侧实际宽度，避免旧宽度偏好导致分隔线偏离鼠标。只在拖动结束时保存两侧宽度，恢复配置接受零宽和原范围外的值。

AI 分隔线保留可拖动面积，拖动过程使用临时覆盖层，避免 HTML iframe 截走移动和释放事件。极窄侧栏内部控件裁在本栏内。
