# 开发文档 011 —— 多项目支持（单窗口切换）

> 状态：已完成 · 对应 ROADMAP P2（多根工作区，提前）

## 一、需求

- 一个窗口内打开多个项目（不新开窗口）
- **顶部工具栏显示已打开的项目**（按钮列表），点击快速切换
- 切换时：文件树 / Git 面板 / 快速打开 / 搜索 全部切到目标项目
- **每个项目独立的标签页记忆**（会话按项目隔离）

## 二、设计

### 项目栏（顶部工具栏）
```
[📂 打开文件夹] [demo] [my_ide] [docs] | 当前路径 | ... | 按钮们
```
- 当前项目高亮（accent）；点击切换
- 右键项目按钮 → 从列表移除（不影响磁盘）
- 列表持久化：localStorage `myide-projects`

### 切换语义
- `setRoot(p)`：核心切换（树/Git/QuickOpen 缓存失效/恢复会话），自动登记项目
- `openProject(p)`：切换语义——先检查 dirty 标签（确认丢弃）→ `closeAll` 关闭全部标签 → `setRoot(p)`
- `openFolder()`：选择新目录 → 加入项目列表并切换

### 会话按项目隔离
- session key：`myide-session:<root 路径>`（原来全局单 key）
- 每个项目记住自己的标签/活动标签/工具窗口

### 结构
```
app.js        projects 状态 + renderProjectBar + openProject/addProject
viewer.js     closeAll()
session.js    按项目 key
index.html    #project-bar
styles.css    .proj-btn
```

## 三、测试计划
