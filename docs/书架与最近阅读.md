# 书架与最近阅读

完成日期：2026-10-17。

## 入口与行为

左侧活动栏的书本按钮打开独立的“书架”页面，再次点击返回工作区。阅读页工具栏也提供“书架”入口。

- “继续上次阅读”显示最后阅读的书名、真实章节/页码位置和阅读时间，点击直接续读。
- 书籍卡片展示格式、位置及时间；未打开的书标记“尚未阅读”。进度条表示章节/页码位置，不表示已读完正文。
- 支持小说/漫画分类、按书名或路径搜索、按最近阅读或书名排序。
- “添加书籍”校验文件并读取目录元数据后释放后台会话，留在书架，不创建阅读标签或切换项目。重复路径忽略大小写与分隔符，不生成重复条目。
- “移出书架”只隐藏条目，不删除文件、关闭已打开的标签或清除进度/书签。页面提供“撤销”；重新添加相同版本也能保留进度。
- 文件不存在或损坏时保留条目并提示具体错误，不把无法打开当成成功。存储写入失败时，添加和移出操作回滚。

书架使用格式配色的文字封面，当前不提取原书封面或扫描整个磁盘。添加只能通过用户文件选择，AI不能按任意路径导入书籍。

## 项目与阅读记录

书架与项目独立共享；保留项目根、侧栏收起状态、文件树/大纲与编辑器实例，主区中的旧编辑器暂时不可交互。返回工作区恢复原实例，打开项目文件时书架自动让位，不清除未保存输入。

沿用 `myide-reader-v1`：旧阅读历史补稳定书籍ID后自动显示，原有版本、章节、段落位置和书签不变。新增格式、总章节数、章节名、添加时间及上架状态。旧记录没有总章节数时显示“总数待读取”，不靠猜测生成百分比；再次阅读后补齐元数据。

最多上架200本，最多保留500条阅读记录；超过记录预算时优先保留上架条目。原书修改导致版本变化时重置位置和书签，沿用首版规则。记录不复制书籍正文。

阅读页与书架共享独立的DSH原生会话/工作目录；项目会话保持原映射。书架不附带项目文件、规则与隐藏缓冲区，项目/编辑器/Markdown/Git/任务工具在此页拒绝执行。

## AI接口

| 工具 | 参数与结果 |
| --- | --- |
| `reader_library` | `query`、`offset`、`limit`（最多50）、`includeRemoved`；返回稳定book标识、格式、总数、位置、上次阅读时间与操作快照。路径展示限512字符并标注截断。 |
| `reader_library_control` | `operation=show/open/remove/restore`、`book`、`snapshot`；打开书架、续读上架书籍、移出或恢复记录。不得传文件路径猜测目标。 |

控制操作沿用写授权、状态快照和执行账本。书架变化后旧快照拒绝执行；先查询条目再使用稳定book标识。`reader_state`/`reader_read`仍只读取当前已就绪的阅读标签，不会读取书架后面的项目编辑器。
