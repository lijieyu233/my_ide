# 浏览器网页强制深色与收藏入口精简

移除工具栏的收藏夹图钉按钮及其重复菜单。左侧收藏列表、地址栏收藏星号和收藏管理继续保留。

原深色按钮只设置进程级nativeTheme，使网站收到prefers-color-scheme偏好；固定白底的网站不会响应。现在对内置网页WebContents使用Chromium的网页绘制深色能力，并同时设置网站媒体偏好。IDE主题不随网页切换。

实现使用[Chromium DevTools Protocol Emulation](https://chromedevtools.github.io/devtools-protocol/tot/Emulation/)的setAutoDarkModeOverride与setEmulatedMedia，按网页视图生效，不开启全局反色开关、不注入任意网站脚本。深色强制变暗，浅色关闭转换，跟随系统按nativeTheme当前值和updated事件更新。网页导航/刷新后重新应用；请求串行处理，快速切换以最后选择为准，失败会反馈。

验证：

- 语法96个文件通过。
- DOM全套525通过 / 0失败；生产资源完整性93组通过。
- browser-color-scheme.test.js覆盖三态、未创建视图、系统变化、重导航、快速切换、协议错误和监听清理。
- 浏览器全屏5组通过。
- check-browser.js真实隐藏Electron浏览器7组通过，含重复按钮移除、真实媒体偏好IPC、固定白底绘制变暗与切回、刷新保留、全屏导航及HTML预览。
- 同一生产深色控制器绑定隐藏顶层网页核对截图像素：固定白底浅色RGB为255，强制深色约18，关闭后恢复255；页面原始CSS仍为white。宿主原生子视图在隐藏窗口中不能提供可靠的独立绘制截图，故像素断言使用同一控制器的独立隐藏网页，真实IPC与面板另行验证。

本次不改变网站正文、表单或登录状态。深色转换属于绘制效果，页面DOM的computedStyle不代表最终屏幕颜色。
