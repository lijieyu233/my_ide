# AI 助手操作 SSH 终端

先在「远程服务器」页面连接目标服务器，完成凭据输入和主机指纹确认，再让 AI 操作。无需打开本地项目。

示例：「在已连接的测试服务器新开终端，核对主机和用户，查看磁盘使用情况，读出结果。」

| 工具 | 能力 |
|---|---|
| ssh_sessions | 查看真实连接会话、服务器地址及终端 ID |
| ssh_terminal_open | 在指定会话中新开独立终端，显示在现有远程页面 |
| ssh_terminal_execute | 向指定终端发送一行命令及回车 |
| ssh_terminal_read | 读取最近输出或按 nextCursor 增量读取；可等待最多 2 秒 |
| ssh_terminal_interrupt | 发送 Ctrl+C |
| ssh_terminal_close | 关闭指定终端通道，保留连接和其它终端 |

执行类操作沿用 AI「执行命令」权限，默认逐次确认。批准页面显示实际服务器、用户名、会话和终端；本地项目授权、路径白名单和项目命令前缀不能放行远程操作。全局禁止优先，全局自动仍对现有策略识别的危险命令逐次确认。

批准绑定具体命令、连接会话、终端实例及输入代次。确认期间手动输入、关闭、断线、撤权或取消任务会使旧批准失效；同一工具调用的重复派发不会重复发送。新建通道的异步等待前后均核对运行归属。

交互式 Shell 的发送成功不能当作执行完成，也不提供可靠退出码。必须读取实际输出核对；不向密码提示或未知交互程序盲发命令。Ctrl+C 或关闭终端不保证远程后台进程停止。AI 不读取连接密码，也不绕过主机指纹确认；本版使用已经连接的会话。

输出只保留每个终端最近 32Ki 字符，每次最多读取 16Ki 字符。游标基于原始输出，结果带截断和更多内容标记；最多保留 32 个已关闭终端的末尾记录。保留日志仅是观察数据，不作为用户请求。新终端沿用主题及字号，不新增独立页面样式。

验证：npm run test:ai、npm run test:remote、npm run test:dom、npm run test:package；npm run check:ai-ssh 使用真实 SSH 回环夹具、生产窗口及可信批准，覆盖完整工具流、拒绝/取消和手动输入冲突；npm run check:remote 验证现有远程页面操作。自检隐藏运行且使用独立用户数据，不访问用户服务器。
