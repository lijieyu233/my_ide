# 开发文档 048 —— 任务界面迭代方案（重点：右侧依赖图）

> 目标：在现有任务工具（清单 + DAG 依赖图）基础上规划三轮迭代，把依赖图从「能画、能编辑」
> 升级为「会说话的作战图」。本文档为调研 + 方案设计，是后续开发的唯一依据。

---

## 1. 背景与现状盘点

- 用户需求原话：「生成任务界面的迭代方案 尤其是右侧依赖图的设计」。
- 047 落地后依赖图已具备的能力：

| 能力 | 现状 |
|------|------|
| 布局 | 拓扑分层自动布局（`dagLayout` 纯函数）+ 拖动过的节点自由位置覆盖（`x/y` 字段） |
| 编辑 | 节点拖动移位、底部锚点拖到目标建依赖、双击改名、双击空白/右键新建 |
| 选中 | 单选 / Ctrl+点击多选 / 框选（045823c 修复：起点可在 svg 下方空白） |
| 过滤 | 可见度四态菜单（全部 / 只看可执行 / 不显示已完成 / 隐藏完结链路）、聚焦模式（上下传导） |
| 防护 | 成环检测（wouldCycle）、已完成依赖约束、脏数据载入自愈 |
| 其他 | 一键整理回自动布局、就近落位（新建前/后继出现在源任务周围）、阻塞徽章 + tooltip、图例 |
| 撤销 | **仅删除**可撤销（undoStack 十步回收栈） |

- 清单侧栏：三状态组独立收起（不影响图）、优先级、Ctrl+Enter 快捷创建、清空已完成。

## 2. 问题诊断（为什么迭代）

1. **画布没有缩放**：任务一多（>30）就出现滚动条长距离拖动，看不了全局结构。
2. **图不「说话」**：看不出哪条链是关键路径、某任务卡住会影响谁——阻塞信息只在徽章数字里。
3. **撤销残缺**：误拖节点位置、误建依赖只能手动改回。
4. **节点信息薄**：优先级、备注、完成时间都要开右键菜单才看到。

## 4. 总体设计思想

- **数据与渲染解耦**：`dagLayout` 保持纯函数（输入任务数组、输出 nodes/edges/width/height），
  泳道/时间线只是新的 mode，渲染层按输出画即可。
- **滚动容器即平移**：`dagBodyEl` 本来就是滚动容器（框选 band 已按 scrollLeft/scrollTop 补偿），
  平移不引入新机制，只加「空格/中键拖拽模拟滚动」。
- **缩放 = 布局尺寸缩放**：svg 的 `width/height` 属性 = 内容逻辑尺寸 × z，`viewBox` 固定为逻辑尺寸。
  滚动条随缩放自然出现，grow 扩画布、band 定位逻辑全部零改造。
- **新字段全部可选**：旧 `tasks.json` 直接兼容，不做版本迁移。
- **每项带验收标准 + 测试用例**，回归基准：dom 测试全绿。

## 5. P0 —— 画布基本功（0.9.0）

### 5.1 缩放 + 平移 + 适应画布（一次提交）

**交互**：
- Ctrl+滚轮：以光标为锚缩放，z ∈ [0.25, 2]，步进 1.1 倍；状态栏显示百分比。
- 空格按住 或 中键按住：光标变抓手，拖拽 = 滚动（平移）。
- 工具栏新按钮「⛶ 适应画布」：z = min(cw/W, ch/H, 1)，内容居中；**打开任务工具时自动 fit 一次**。
- 无修饰滚轮：保持原生垂直滚动（不劫持）。

**技术方案**：
```js
// tasks.js 模块级
let zoom = 1; // localStorage 持久化 myide-tasks-zoom
// 渲染：svg.setAttribute('width', Math.ceil(lay.width * zoom));
//       svg.setAttribute('height', Math.ceil(lay.height * zoom));
//       viewBox 固定 `0 0 ${lay.width} ${lay.height}`（逻辑尺寸不变）
function applyZoom(z, anchor) { // anchor = {x, y} 容器内像素
  const br = dagBodyEl.getBoundingClientRect();
  const ax = anchor.x - br.left + dagBodyEl.scrollLeft; // 光标当前指向的内容像素（缩放前）
  const ay = anchor.y - br.top + dagBodyEl.scrollTop;
  zoom = Math.min(2, Math.max(0.25, z));
  renderDag 保持节点 DOM 不重建，只改 svg 宽高属性;
  // 锚点补偿：缩放后把光标指向的内容点滚回光标下
  dagBodyEl.scrollLeft = ax * (zoom / zOld) - (anchor.x - br.left);
  dagBodyEl.scrollTop  = ay * (zoom / zOld) - (anchor.y - br.top);
}
```
- `svgPt` 改造一处：读 **viewBox 宽高**（而非 width 属性）做换算——缩放后两者不再相等。
  拖节点 / 框选 / 建依赖连线 / 双击新建全部经过 `svgPt`，改一处全通。
- 拖动节点时的 `grow()`：画布逻辑尺寸扩到 `x + NW + PAD`，实际属性 = 逻辑 × zoom，同步乘。
- 抓手平移：mousedown（空格按下或 button===1）记起点 scrollTop/Left，mousemove 直接写 scroll。

**涉及文件**：`renderer/tasks.js`（renderDag / svgPt / grow / 新 zoom 状态）、`renderer/index.html`（⛶ 按钮）、`renderer/styles.css`（抓手光标 .tk-pan）

**验收**：Ctrl+滚轮缩放时光标下的内容点不动；缩放后拖节点/框选/建依赖坐标精确命中；
z=0.25 时 200 节点图全貌可见；打开工具自动 fit；空格拖拽平移流畅。

### 5.2 统一撤销/重做栈

**现状**：`undoStack` 只存删除（`{tasks: 快照, refs}`）。
**方案**：快照式命令栈（数据量小，全量深拷贝最简单可靠）：
```js
let hist = [], histIdx = -1; // 上限 50
function pushHist(label) { // 每个写操作入口（rename/setStatus/setDeps/moveNode/add/remove...）save 前调用
  hist = hist.slice(0, histIdx + 1);
  hist.push({ label, tasks: JSON.parse(JSON.stringify(tasks)) });
  if (hist.length > 50) hist.shift();
  histIdx = hist.length - 1;
}
// Ctrl+Z：histIdx-- 恢复快照；Ctrl+Shift+Z：histIdx++（tasks 引用替换 + save + render）
```
- 旧 `undoStack`（删除回收）合并进来：删除也是一次 pushHist，toast 文案统一为「已撤销：<label>」。
- 连续同类微操作合并：拖动同一节点 300ms 内的 moveNode 只留一个快照（拖完 mouseup 时 push，不在 move 中逐帧 push——现有实现本来就是松手才 moveNode，天然满足）。
- 快捷键在 shortcuts.js 注册（任务工具激活且非输入态时劫持），帮助页可见。

**验收**：改名 → Ctrl+Z 恢复；建依赖 → 撤销恢复；拖位置 → 撤销恢复；删除 → 撤销恢复（含依赖引用）；重做对称；栈满 50 淘汰最旧。

### 5.3 小地图

- 触发：可见节点数 > 30 时右下角出现（与图例同位，图例让位上移），160×96px。
- 实现：独立小 `<svg>`，只画节点矩形色块（状态三色）+ 当前视口虚线框；
  容器 scroll/zoom 变化时同步（requestAnimationFrame 节流）。
- 交互：点击/拖拽小地图 → 设置 scrollTop/scrollLeft（大图导航）。
- **依赖 5.1**（有缩放后小地图才有意义），P0 内最后做。

**验收**：31 节点出现 / 30 节点不出现；拖动视口框大图同步滚动；点击小地图定位。

## 6. P1 —— 信息表达（0.9.x）

### 6.1 关键路径高亮

- 定义：源到汇的**最长链**（P1 无耗时字段 → 按跳数；P2 加 `estimateMin` 后换工期加权）。
- 算法：拓扑序 DP `dist[v] = max(dist[u] + 1)`，O(V+E)，回溯取链——复用 `chainHiddenIds` 已有的全量 tasks 拓扑遍历骨架。
- 交互：工具栏开关按钮「⛓ 关键路径」；开启时链上节点边框 + 链上边加粗着色（强调色），
  统计栏追加「关键路径 N 步」。
- 排除已完成节点后计算（done 不参与，否则整图关键路径永远指向历史任务）。

### 6.2 hover 上下游链路高亮

- 节点 mouseenter：沿 `deps` 向上游 BFS + 沿反邻接（succs）向下游 BFS，集合内 `.hl`，
  集合外 `.dim`（opacity .18，CSS 过渡 120ms）；mouseleave 复原。
- 实现挂 renderDag 内（节点 g 上绑定，随重建，无泄漏）；`relatedOf(id)` 已有，直接复用。
- 清单行 hover 同样触发（R12）：清单 mouseenter → 图上对应节点 + 关联链高亮。

### 6.3 节点信息密度 + 内联操作

- 角标：优先级 high → 左上角红色 `!`；有 note → 右上角 `📝`（浅色，不喧宾）。
- hover 卡片：节点下方浮层（div 绝对定位在 dagBodyEl 内）显示 note 全文、创建/完成时间、依赖清单。
- 内联操作：节点 hover 时右上浮现「＋」（原地在节点下方建后继任务）与「☑/○」（切换状态），
  复用 `openDagNewInput` 与 `setStatus`。

**验收（P1 汇总）**：关键路径链路稳定（换数据即换链）；hover 淡出后其余操作不受影响；
角标不与标题文字重叠（NW=160 内布局）；内联按钮不误触（出现有 150ms 延迟）。

## 7. P2 —— 结构与智能（1.0 方向）

| 项 | 设计要点 |
|----|----------|
| 泳道布局 | `dagLayout(tasks, mode='topo'\|'status')`：status 模式 y 按三状态行、x 按拓扑序；工具栏加布局切换；自由位置节点在泳道模式下回落自动布局（位置无意义） |
| 子任务/折叠组 | 任务加 `parentId`；同父兄弟在图上聚为一个组节点（聚合徽章显示 N），点击展开/折叠（展开时子节点围绕组位置就近排布，复用就近落位）；清单侧栏缩进显示 |
| 标签 | `tags: []` + 预设色板；节点左边缘色条；可见度菜单追加「按标签…」过滤项 |
| 甘特视图 | 加 `estimateMin`（预计耗时分钟）；第三视图 mode：按拓扑最早开始时间排横条，关键路径直读；无耗时的任务按固定 30min 占位 |
| AI 联动 | ① 图工具栏「AI 分析」按钮：DAG 序列化（id/标题/依赖/状态）喂 ai-service，prompt 让其找瓶颈/建议拆分，结果渲染到对话面板；② 自然语言建图：「先A后B再并行C」→ 解析为任务+依赖批量创建（走 function calling 工具协议）；③ 周报：完成率 + 关键路径进展生成 markdown |

## 8. 兼容性与风险

| 风险 | 对策 |
|------|------|
| 缩放后坐标换算错位（拖拽/框选漂移） | `svgPt` 统一入口 + 专项测试（z=0.25/1/2 三档下拖节点、框选、连线命中） |
| 撤销栈与快速连续操作竞态 | pushHist 在 save 前同步调用；saveChain 串行写不变 |
| 快照栈内存 | 50 × 深拷贝（万级任务才超 10MB），上限足够 |
| 旧数据 | 新字段（tags/parentId/estimateMin）全可选，load 时缺省即可 |
| jsdom 无布局 | svgPt 已有 `getBoundingClientRect` 全 0 守卫，缩放测试用 mock rect（同框选用例模式） |
