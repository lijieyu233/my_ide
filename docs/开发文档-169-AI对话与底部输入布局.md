# AI 对话与底部输入布局

顶部连续的模式、模型、推理和用量行更像设置表单，占据对话空间。改为让标题后直接显示消息流，输入区负责本次消息相关选项。

- 模型与推理放在输入卡片底部，与发送按钮同一排；保留原生下拉的键盘操作和明确的可访问名称，省去重复的可见字段标签与表单边框。
- 模式、DSH 连接状态和重连入口放在卡片下方；普通模式隐藏 DSH 状态与推理控件。
- 上下文用量移到附件附近，仍可点击查看明细；后台任务提示沿用原有位置关系。上下文、附件和输入配置集中在底部，不进入顶部消息流。
- 保留暗红主题及其他主题变量、会话操作按钮、发送/停止、模型配置来源和任务执行逻辑。

窄侧栏下优先保留模型、推理与发送按钮；模型名称省略显示，完整名称可在下拉中选择。模式与连接状态可换行，大字号时模式高度随文字自适应，避免文字裁切。
